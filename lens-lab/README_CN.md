# 凸透镜成像 · 自己找规律

[English](README.md) | 简体中文

**[在线打开](https://aliceljy.github.io/playground/lens-lab/)**

一张光具座，一个主线问题：放大镜和投影仪用的都是凸透镜，为什么一个看到正的像，一个投出倒的像？

先打开平行光，拖光屏找到最小最亮的光斑，那就是焦点。再猜一猜蜡烛放远时像是什么样，然后拖蜡烛、拖光屏，把像对清楚：缩小、等大、放大、不成像，最后蜡烛放到焦点以内，光屏上接不到了，点「用眼睛看」才看到放大镜的虚像。每找到一种，表格就自己填一行，八步走完揭晓规律。

- 薄透镜公式实时计算，光屏离像距越远越模糊；三条特殊光线和虚像的反向延长线随拖动重画
- 蜡烛拖到 f、2f 附近会卡住；像落在光具座外时如实说「够不着」
- 手机竖屏和电脑都能用，单文件离线可看
