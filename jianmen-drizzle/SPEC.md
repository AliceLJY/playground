# 细雨剑门 · 规格

一页规格。实现、测试、截图都对照这一页；规格改了，验收条目跟着改。
v1（2026-10-23）。数值的唯一出处是 `src/core.js` 的 `FEEL` 与 `TARGETS`，本页只写要点。

## 1. 一句话体验

走进高剑父 1926 年的《山水》。这幅立轴题的是陆游《剑门道中遇微雨》，落款「写剑南诗意」，画里有个骑驴的人正往剑门关走。画化开以后，玩家站在峡谷上方那人的位置，四下是细雨和流动的云。转头去找画里的东西，每看准一处，诗笺上就写出一句：低头看来路，「衣上征尘杂酒痕」；往远处望云海，「远游无处不消魂」；转过身去，「此身合是诗人未」，那一面高剑父没有画；抬头看雨里的关楼，「细雨骑驴入剑门」。四句写全，镜头转回关楼，画收回成立轴。

核心操作只有一个：**拖动转头，看准停一秒**。一次 2–4 分钟，走一遍就完（弧型）。

参考：@gkxspace《走进梵高》（Viggle JST-2 经 PINOC 生成场景，2026-10-22 X 帖；开源仓 yuwen-cool/walk-into-van-gogh，MIT）。只借「一张画生成场景、转身看画家没画的那一半」的理念，代码自写。

## 2. 主美学与场地

- 主美学：**感官**（水墨、细雨、云雾在动）+ **探索**（找出画里的四处）。验收跟着这两样选：画面在动、四处都找得到。
- 场地：陌生访客多半用手机、单手拖、静音；电脑上用鼠标拖。静音也要看得懂：所有提示都是文字，声音只是加分（雨声、找到时的一声琴、结尾驴铃）。
- 弧型：验「没玩过的人第一次能不能找全四处、能不能说出诗是怎么写出来的」，用盲玩复述，不套通关率。卡住 25 秒就给一句文字提示。

## 3. 操作

| 动作 | 键鼠 | 触屏 |
|---|---|---|
| 转头 | 按住拖动 / 方向键 / WASD | 单指拖 |
| 望远望近 | 滚轮 | 双指捏 |
| 声音开关 | 右上角「声」 | 同左 |

看准判定：视线中心与目标方向的夹角小于目标半径，持续 `FEEL.dwell` 秒（1.0 s）；移开后进度按 `FEEL.decay` 回落。屏幕中心有一圈墨环随进度描满。

认路（2026-10-23 Alice 试看后加：「看不出动到哪儿了」「右上角那块空白是作业本吗」）：
- **方位条**：屏幕底部一条刻度，每 15° 一格，转头时刻度跟着滚；四处地方各有一个标记（路、云、身后、关），在视线上方的标「↑」、下方的标「↓」，转不到的钉在两边（‹ ›），找到的变朱红。显示范围是视线左右各 `FEEL.compassSpan`（100°）。
- **诗笺描红**：开局四句就以淡朱色描在诗笺上，下面一行「看准一处，描出一句」；找到一处，那一句一个字一个字变成墨字，落一方印，下面改成「已得 n / 4」。

## 4. 场景与目标

场景：PINOC `generate_environment`，参考图为该画裁去题款（1358×2048），英文美术方向一句，`quality: high`，再补洞一次（共 8 积分）。原点是拍摄点，Y 朝上；单位未换算成米，本玩意不走路，所以不需要。机位固定在原点，转头时眼睛绕颈部支点小幅移动（`FEEL.neck`），给出真实视差。

四个目标（偏航 0 = 朝 -Z，向右为正；俯仰向上为正），方向由渲染截图读出：

| id | 诗句（在诗笺上的位置） | 方向 | 半径 | 提示 |
|---|---|---|---|---|
| path | 第一句 衣上征尘杂酒痕 | 偏航 8°，俯仰 -40° | 16° | 低头，看看来时的路 |
| far | 第二句 远游无处不消魂 | 偏航 -90°，俯仰 -5° | 20° | 往左望，云海那边 |
| back | 第三句 此身合是诗人未 | 偏航 180°，俯仰 10° | 30° | 转过身去 |
| gate | 第四句 细雨骑驴入剑门 | 偏航 19°，俯仰 47° | 11° | 抬头，关楼在雨里 |

找到的顺序不限，诗句写在各自的位置上。找到 back 时另出一行「这一面，高剑父没有画」。

**正后方的接缝**：全景首尾在偏航 180° 对不齐，留下一道竖缝，补洞补不掉（2026-10-23 补了一次洞，实测缝还在）。着色器把缝两侧约 ±7°–18°（宽度随高度和时间起伏）的泼溅渐渐化成浅色水流并变薄，正中完全盖住，带子里有往下流的竖纹，读作一道从云里落下的飞瀑。先试过直接化成纸色，看起来是一根白柱子，弃用。`?seam=off` 关掉遮挡，用作检查的已知坏例。

## 5. 美术与构图

- 配色（sRGB）：宣纸 `#EDE6D6`（页面底、诗笺底），场景纸色 `#E2DDCF`（清屏色与瀑布底色，取场景里亮而灰的泼溅颜色中位数 0.887/0.865/0.813），墨 `#2B2925`（文字、墨环），赭石 `#B5774A`（提示、强调），朱砂 `#B23A2E`（找到一处时的印）。字体用系统楷体（`STKaiti`、`KaiTi`、`Kaiti SC`），不加载网络字体。
- 开场：立轴原画居中（含题款），标题「细雨剑门」，下有一行出处与「入画」按钮。点了以后原画放大淡出，场景淡入，机位从偏航 19°、俯仰 8°、视场 88° 缓到视场 72°，关楼在画面上方三分之一附近、小路在下方，对上原画构图。
- 诗笺：画面右侧竖排四列，从右往左，每列七字；开局淡朱色描红，找到后变墨字。手机竖屏缩到宽 ≤ 32% 屏宽。
- 视野：`look.fov` 是屏幕**短边**方向的视场。横屏 72°（竖直方向）；竖屏 60°（水平方向），这样竖屏也能同时看到上面的关楼和下面的小路，构图接近原立轴。原先竖屏按高度算 72°，水平只剩约 37°，像贴着石头看，看不出转到了哪里。
- 细雨：屏幕上一层细短斜线，随转头整体平移（像远处的雨幕），雨丝密度按屏幕面积算，结尾时加密。
- 云雾流动：着色器里对亮而灰的泼溅（云雾）叠一层缓慢移动的噪声，调亮度与不透明度，不移动位置。

## 6. 性能预算

- 目标：桌面 Chrome 1080p 60 帧；手机（OPPO Find N6 展开）Chrome 30 帧以上。
- 场景两档：电脑用完整版（约 72 万个泼溅，SOG 8.3 MB），触屏设备默认用减半的轻量版（`--decimate-adaptive 50%`，约 36 万个，4.4 MB），`?q=full|lite` 手动切换。轻量版干笔略软，在手机屏上差别不大。首屏下载：电脑 ≤ 15 MB，手机 ≤ 8 MB。
- 非单文件：发布目录含 `index.html`、`main.js`、`assets/`；CI 打包后整目录拷贝。
