# 环形空间站

地球上空一座环形空间站：居住环由四根辐条连到中央枢纽，枢纽顶端是对接口，底部桁架挑出太阳翼、散热板、机械臂和对地天线。居住环匀速旋转，透过内壁的窗带看得见里面的花园甲板。一艘接驳艇按「接近、对齐、接触、停稳」四步对接，十二个挂钩依次锁紧。

十个机位可以逐个点开，也可以「一键连播」约 50 秒看完一轮：建立全景、桁架掠过、环区旋转、花园甲板、接近、对齐、对接口、停稳、地球日出、轴向俯视。拖动画面可以自由环绕。手机竖屏可用。

全部造型、材质、地球与星空都由代码生成，没有外部模型、贴图或生成图片。造型是示意，不代表任何真实航天器的设计，尺度与对接节奏都做过压缩。

## 运行与检查

```sh
npm ci
node tools/build.mjs            # 生成单文件 dist/index.html
node --test tests/*.test.cjs    # Node 测试：对接、旋转、构图、镜头连续、材质分层、预算
node tools/browser-check.cjs    # 真实 Chrome：20 张固定机位截图、手机布局、画面像素读数、鼠标拖动、页面报错
node tools/preview.cjs          # 没有 WebGL 时的 CPU 构图预览（不是渲染截图）
```

源码入口：`node tools/serve.cjs . 8941` 后打开 `http://127.0.0.1:8941/dev.html`。固定机位用 `?view=establish` 或 `?view=1` 到 `?view=10`，进入后暂停在该机位的定格时刻。`window.__PLAYTEST__` 提供 `ready`、`snapshot()`、`reset()`、`setSeed(n)`、`step(ms)`，快照回报实际机位、时间、对接读数、绘制次数与渲染器字符串。规格与验收条目见 [SPEC.md](SPEC.md)，文末有 2026-11-24 在真实浏览器和 GPU 下复核的记录，对应的截图在 `shots/`。Three.js 固定为 0.186.1，MIT 许可保留在生成页面里。

## 演示片

`tools/demo.cjs` 把页面自己的一键连播逐帧录成竖屏 1080×1920、30 帧的短片（360×640 手机视口、3 倍像素，不套手机外框）：页面自己的动画循环被拦住，每帧用 `__PLAYTEST__.step()` 推进 1/30 秒，所以不会掉帧；另外只在页面外放开了 1.5 倍像素比的上限，让三维画面按 1080×1920 原生渲染。默认录连播的 0–45 秒，收在地球日出；`--segments 0-15,20-45` 这样写多段可以跳过某一镜（黑场处接，看不出跳）。`tools/demo-sound.py` 加上代码合成的配乐和对接音效（接触、挂钩锁紧的时刻取自录像里的读数，没有采样素材）、接署名页、把响度做到 -12 LUFS 左右。`src/` 一行没改。

```sh
node tools/serve.cjs . 8962
NODE_PATH="$(npm root -g)" node tools/demo.cjs <目录>      # 几分钟，写 <目录>/screen.mp4 和 timeline.json
<装了 numpy、scipy 的 python> -I tools/demo-sound.py <目录> <成片.mp4> --endcard <署名页.mp4>
```
