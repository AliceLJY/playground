# 手撕日历 · 广州老黄历

[English version](README.md)

墙上挂一本老式手撕日历，翻到今天。捏住页脚往下拽：纸先跟着手弯起来、离开纸垛，再拽就沿顶上的齿孔一点点撕开，撕口参差、挂着纸纤维，撕下来那页飘落，露出明天。

每一页都是真的黄历：农历、干支、节气和节日、宜忌、冲煞，2026 年的法定休息日和调休上班日也标了出来（休的日子数字是红的，调休上班的周末是黑的）。最底下有一句广州话和普通话释义，冬至那天是「冬大过年」。

几个玩法上的细节：

- **轻轻掀不会撕**：只是把纸角掀起来看看下一页，松手它就落回去。
- **手停撕口就停**：撕到一半手不动，撕口停在那里；松手，半撕的纸就挂着，顶角微微卷起。
- **从哪边拽，哪边先开**：捏右下角往下拽从右边撕开；往旁边横拽会把整页拧过去，撕口可能从另一头开始。
- **残根越撕越毛**：每撕一页，就有一截碎纸留在日历头下面。
- 键盘按空格、回车或下方向键，自动撕一页。撕过以后右上角会出现「回到今天」。

手机竖屏、单手、静音也看得懂。声音是代码现场合成的撕纸声，没有录音文件。

## 怎么做的

借了 [Filament 织物实验室](https://play.liyue.io/filament/) 的两招：

1. **只算手底下那一片**：纸是 13×15 个节点的位置约束网格，按下时圈住手指周围一小片节点跟着手走，其余部分靠约束自己弯。顶排节点用软钉挂在齿孔上，钉子被拉开超过阈值就断；手指拽得比纸能跟上的地方还远，也算在撕。
2. **撕口画进贴图，不切网格**：每断一颗钉，就在这一页贴图顶边擦出一段锯齿、画几根纤维；同一段锯齿也画进日历头下面的残根。

撕下的纸靠「沿法线方向的空气阻力」加一点侧风飘落。整个页面用原生 WebGL 和 Canvas 2D 画，没有任何第三方库。

## 本地跑

```bash
cd tear-calendar && python3 -m http.server 8971 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8971/`。测试：`node --test tests/*.test.cjs`。浏览器检查：`NODE_PATH="$(npm root -g)" node tools/browser-check.cjs <输出目录>`。没有构建步骤，发布时原样拷贝 `index.html` 和 `src/`。

固定机位：`?view=hero`（平放带提示）、`?view=lift`（掀起右下角）、`?view=torn`（撕到一半手停住）、`?view=fall`（撕下的纸飘落）；`?date=2026-12-22` 指定从哪天开始。规格见 [SPEC.md](SPEC.md)，验证记录见 [VERIFICATION.md](VERIFICATION.md)。

黄历数据由 `tools/gen-almanac.cjs` 从 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT，1.7.8）预先生成到 `src/almanac.js`，覆盖 2026-01-01 至 2027-12-31；2027 年的法定调休等官方发布后再生成。

## 谁会点开、AI 素材

- 谁会点开：家里挂过手撕日历、小时候抢着撕那一页的人；想每天看一眼今天宜什么忌什么的人。
- AI 素材清单：没有 AI 生成的图片、模型或声音，日历、纸纹和撕纸声全是代码画出、代码合成的；黄历数据来自开源库 lunar-javascript；广州话俗语与释义、代码由人与 AI 协作完成。
