# 派活回放

回放真实的 Claude Code 工作，右上角能在两份之间切换。

- **事实核查（10-22）**：作者丢来一句「给一批公众号旧文做事实核查」，总调度 Claude Code 用 68 分钟把 15 篇文章拆给 21 个子 agent：15 个核查员，6 个复核员。每个子 agent 在自己独立的上下文里搜网页、读网页、写核查表，上下文涨到 14.4 万到 22.5 万 token；干完交回给总调度的报告只有 205 到 588 字。
- **英歌短片（10-21）**：作者用 `/goal` 交代做一支 70 秒的竖屏短片「英歌小戏台」，总调度用 2 小时 37 分做出第一版：派 2 个子 agent 查资料、6 个子 agent 审片（5 位从没看过的「新观众」盲看复述，1 位 Opus 逐镜审查），另外叫了 8 次外部 AI Codex 画纸偶和景片，其中 3 次因尺寸不符被脚本退回重画。Codex 在会话记录里是个黑箱，画成黑洞，只看得到派出、交回和用时。这次会话一共约 6 小时，后面作者回来改配乐、收工核对的两段没放进来，为什么只取这一段见 [SPEC.md](SPEC.md) 第 3 节。

在线：https://aliceljy.github.io/playground/dispatch-replay/

## 怎么看

画面是一片星空：中间的恒星是总调度，绕着它转的小星系是子 agent，落进星系的光点是工具调用，黑洞是外部 AI，彗星是交回的报告，左上角的十字星是作者。事实核查那份是蓝色深空，英歌短片那份是朱红、墨黑和暗金。

- 默认 1.5 分钟放完，可以换成 3 分钟。空格暂停，左右方向键快进快退，拖底下的时间轴跳到任意时刻。
- 点一个子 agent，看它自己的数字：模型、跑了多久、调了哪些工具、上下文峰值、交回多少字。
- 每条字幕出现时会慢放一会儿，停够读完的时间；这时右上角时钟前面标「慢放」。时钟本身始终是真实时间。
- 固定画面：`?view=hero`（同时在跑的执行者最多的时刻）、`?view=wide`、`?view=end`、`?t=<真实秒数>`；`?d=yingge-1021` 选数据，默认第一份。

## 画面里的数字从哪来

数据由 `tools/extract.py` 从作者本机的 Claude Code 会话记录里抽出来，只带任务标签、模型名、工具类别（网页 / 文件 / 写入 / 命令 / 外部工具 / 其他）、时间、token 数和字数，不带提示词、报告原文和文件路径。任务那句话和字幕是手写的。

- 星系的光晕面积和 token 数成正比，子 agent 和总调度（恒星）用同一把尺。token 是每个子 agent 自己上下文的峰值，也就是它单次请求读进去的上下文里最大的那一次，含缓存。
- 交回的报告按字数计，只算子 agent 自己写的那部分，不含系统套在外面的说明。token 和字数单位不同，所以交回的报告画成固定大小的彗星，旁边写字数。
- 结尾那个大星系是所有子 agent 峰值加起来的 token 数，和总调度这颗恒星放在一起比：事实核查那份是 376.7 万对 33.8 万，英歌短片那份是 194 万对 78.1 万（这次总调度自己写代码、做片子，读得比哪个子 agent 都多）。外部 AI 没有 token 数，不算进大星系。
- 外部 AI 交回的字数，是总调度读回结果的那一段：Codex 生图交回的是一张图加一行两百字上下的状态，图不计字数。

换一份会话：

```bash
python3 -I tools/extract.py <会话 jsonl> --from <开始时间> --to <结束时间> \
  --slug <名字> --title "<标题>" --task "<任务那句话>" \
  [--subtitle "<副标题>"] [--captions <字幕.json>] [--label-strip '<要删掉的标签片段>'] \
  [--external-labels <外部AI标签.json>] > data/<名字>.js
```

再在 `data/index.js` 里加一行，页面右上角的选择框里就会多一项。数据格式见 [SPEC.md](SPEC.md) 第 3 节。会话里用 `codex-image-gen.ts`、`codex-run.sh`、`kimi-run.sh`、`agy-gui-run.sh`、`grok-clean.sh` 这些包装脚本叫过的外部 AI，会被自动抽成 `kind: "external"`；只认真正执行的命令，提到名字不算；交回时间找不到就报错停下，不猜。英歌那份的参数见 `tools/captions-yingge-1021.json`、`tools/labels-yingge-1021.json` 与 VERIFICATION.md。

## 本地运行

```bash
cd dispatch-replay && python3 -m http.server 8963
```

打开 `http://127.0.0.1:8963/`，也可以直接双击 `index.html`。测试：`node --test tests/*.test.cjs`。没有构建步骤，发布时原样拷贝 `index.html`、`src/` 和 `data/`。

## 谁会点开、AI 素材

- 谁会点开：好奇「AI 派子 agent 干活到底是什么样子」的人，想看多个 agent 怎么分担上下文的人，以及想知道 Claude Code 叫外部 AI 时到底看得见什么的人。
- AI 素材清单：没有 AI 生成的图片、模型或声音，画面全部由代码绘制；回放的内容是一次 AI 工作的真实记录；代码由人与 AI 协作完成。
