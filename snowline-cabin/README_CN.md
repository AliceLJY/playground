# 雪线小木屋

雪夜山顶上一间亮着灯的木屋，能拖着转着看，也能玩一会儿。主屋、瞭望塔、柴房和茶摊挤在一座山头上，周围七座小山头各有一点人烟：一间红顶小屋、一盏门廊灯、一座小烽火塔、一个玛尼堆。两串经幡从木屋拉到远处的两个小村。

**[打开看](https://aliceljy.github.io/playground/snowline-cabin/)**

没有用任何模型和图片，形体、木纹、云、雪、月亮全是代码生成的。

## 能做什么

- **点灯**：七座小山头开场都黑着。点一座，镜头飞过去，那里的灯和窗亮起来，冒出一句那里的小故事。七座都亮了，经幡上的灯串亮起，天上有一场流星。
- **换时间**：底部的滑条从黄昏拖到深夜再到日出，天色、主光和亮着的窗跟着变。
- **进屋坐坐**：左下角门形按钮。进到主屋一楼，拖动环顾，点地上的光点在火炉边、窗前、桌边之间换位置。窗前那个位置正对月亮。
- **转着看**：不操作时镜头自己绕一圈。

## 操作

| 动作 | 电脑 | 手机 |
|---|---|---|
| 转着看 | 按住拖动 | 单指拖动 |
| 远近 | 滚轮，或左下角放大、缩小 | 双指捏合，或左下角按钮 |
| 回到开场 | 左下角复位 | 同左 |
| 自动环绕 | 左下角眼睛形按钮开关；开着时停手约 4.5 秒镜头自己接着走 | 同左 |
| 点灯 | 点一座暗着的山头；看完点「回木屋」或点主屋 | 同左 |
| 换时间 | 拖底部滑条 | 同左 |
| 进屋、出门 | 门形按钮；屋内点「出门」 | 同左 |

鼠标停在某栋房子上，它的窗会亮一点。系统设了「减少动态效果」时，自动环绕默认关着。

## 这一页从哪来

它是一次提示词的试用。起因是 YouWare 发的一条「云上城堡」提示词（一条指令做出一座能环绕的浮空城堡），读完归纳出一份去掉题材的填空稿，再换成雪山木屋这个题材做了这一页。填空稿与归纳在作者的提示词素材库：`tinkering-lab/prompts/interactive-3d-exhibit/procedural-scene-hero-prompt.md`。没有使用原帖的代码或素材，原帖也没有公开源码。

## 本地运行与检查

```bash
npm ci
node tools/build.mjs            # 打成一个文件：dist/index.html
node --test tests/*.test.cjs    # 镜头路线、接管与交还、山头布置等逻辑检查
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs /tmp/cabin-check   # 浏览器验收，需要本机已有 Playwright 和 Chrome
```

规格与验收条目见 [SPEC.md](SPEC.md)。固定机位：`?view=hero`、`?view=deck`、`?view=sat`、`?view=wide`。

## 已知的边界

- 场景是虚构的，页面上的坐标和海拔是设定，不对应真实地点。
- 没有在真手机上试过，手机排版只在浏览器的窄屏模拟里量过。
- 帧率在一台 Mac mini 的无头 Chrome 上量到 60；别的机器没量过，低帧率时会自动降渲染比例。
