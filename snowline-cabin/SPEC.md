# 雪线小木屋 · 规格

## 体验一句话

打开就是一张能拖着转的封面：雪夜山顶一间亮着灯的木屋，周围七座小山头各有一点人烟。不操作时镜头自己慢慢绕一圈，手一碰就交给你。

## 配色（sRGB HEX，材质基色；场景在线性空间里算，最后一步做 ACES 色调映射）

| 用途 | 颜色 |
|---|---|
| 夜空：地平线 / 中段 / 天顶 | `#313D5E` / `#273251` / `#161D39` 一带的深蓝，不是纯黑 |
| 雪 | `#DDE6F4` |
| 岩石 | `#2B303B` |
| 原木墙 / 深色木构 | `#8C5C38` / `#4A2F1D` |
| 灰泥墙 | `#ECE5D6` |
| 红屋顶 / 绿屋顶 | `#A3312B` / `#2F6650` |
| 小旗 | `#E9B93A` |
| 窗与灯（发光，暖色，约 2200–2700K 的观感）| 线性 `(1.0, 0.56, 0.2)` 乘 3.4，超过白的部分才泛光 |
| 月光（主光，冷色）| `#9FB9FF` |

## 构图

- 开场机位：斜上方看主屋，月亮在瞭望塔后上方。
- 宽屏：木屋整体落在画面右侧，左边约三分之一留给文字；木屋高度占画面 40%–80%。
- 手机竖屏：木屋在上半屏，文字在下方，互不压住。
- 光只有两种来源：一盏冷色月光，和画面里的窗、灯笼、灯串。泛光阈值设在白以上，只有发光体会晕开。

## 性能预算

目标是桌面浏览器 60 帧、手机可看。设备像素比封顶 2；帧率掉到 44 以下持续 1.5 秒就降一档渲染比例（共四档），回到 57 以上持续 12 秒才升回去。绘制调用上限 120，实测见下。

## 固定机位

| 入口 | 内容 |
|---|---|
| `?view=hero` | 开场机位 |
| `?view=deck` | 降到木平台高度，看灯串和窗 |
| `?view=sat` | 掠过红顶小屋那座山头 |
| `?view=wide` | 高空看全八座山头 |

带 `?view=` 时镜头停在那一点，场景时间固定在第 12 秒（可用 `&t=` 改），用来截图对比。不带参数就是正常入口。钩子是 `window.__cabin`：`ready`、`state()`、`info()`、`heroBox()`、`copyBox()`、`uiBoxes()`。

## 验收条目

逻辑部分在 `tests/core.test.cjs`，跑 `node --test tests/*.test.cjs`；画面部分在 `tools/browser-check.cjs`。

| 编号 | 内容 | 判据 | 在哪查 |
|---|---|---|---|
| 1 | 镜头路线首尾相接、不跳 | 起点终点重合；离木屋 30 米内每帧位移 < 0.05 米，远处 < 0.1 米 | Node |
| 2 | 镜头不穿进任何东西 | 全程离木屋各体块 ≥ 6 米，在每座山头外，高于云面 6 米 | Node |
| 3 | 路线有四拍 | 开场月亮在塔顶后上方；有一段降到平台上方 1–3.5 米；离红顶小屋 < 16 米掠过；最高点 > 36 米且此时七座小山头都在画面内 | Node |
| 4 | 小山头逐个不同 | 至少 6 座；各自带的东西组合互不相同；高度互不相同且跨度 ≥ 8 米；不排在网格轴线上；摆动相位互不相同 | Node |
| 5 | 窗有亮有暗 | 亮 40%–62%、暗淡 10%–28%、不亮 15%–35%、闪烁 3%–12%；常亮的窗不随时间变 | Node |
| 6 | 手一碰就接管，放手后平滑交还 | 接管那一帧镜头位移 < 0.08 米；手在时路线不前进；4.5 秒无操作后 3.2 秒内交还，过程离木屋 ≥ 5 米；关掉自动环绕后一直停在原处；任意拖动缩放都不会进到物体里 | Node |
| 7 | 木屋不压文字 | 16:9、16:10、21:9 下木屋投影在横向 0.36–0.97 之间；手机竖屏在上方 60% 内 | Node |
| B1 | 页面干净 | 无页面错误，不向外请求任何东西 | 浏览器 |
| B2 | 开场画面木屋不压文字 | 用页面真实排版量：木屋左缘在文字块右缘之右 | 浏览器 |
| B3 | 看起来是夜里、有暖光 | 开场截图平均亮度 0.08–0.30，暖色亮像素占 0.2%–6% | 浏览器 |
| B4 | 默认入口正常 | 1440×900、像素比 2：自动环绕在走；绘制调用 ≤ 120；帧率 ≥ 50（显示器本身跑不到 55 时记为判不了）| 浏览器 |
| B5 | 拖动接管与交还 | 拖动中是手动；放手约 8 秒后回到自动 | 浏览器 |
| B6 | 四个按钮 | 放大变近；关自动后 7 秒仍停着；复位回到路线起点 | 浏览器 |
| B7 | 悬停 | 鼠标停在木屋上，那栋的窗被标记变亮；指针仍是普通箭头 | 浏览器 |
| B8 | 手机竖屏排版 | 390×844：文字与按钮两两不重叠，木屋在文字上方 | 浏览器 |

这些检查只证明上面写的这些量。画面好不好看、转起来舒不舒服、近处细节耐不耐看，要人看了才算。B3 的亮度区间是照着这一版定的，没有拿一张已知是坏的图校准过。
