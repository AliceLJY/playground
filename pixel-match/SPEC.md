# 像素连连看 · 一页规格

## 1. 体验一句话

最普通的连连看：点两张一样的牌，中间能用拐弯不超过两次的线连上（线可以走到棋盘外面一圈）就消掉，消完过关。牌面是像素办公室里的小人，越往后长得越像。核心操作只有「单击选牌」；要的感受是认出「就是你」的那一下，和后几关差点认错时的一愣。

- **主美学**：挑战（认像不像、找能连的那一对），次要是感官（小人挥手、跳一下、过关合影）。
- **场地**：完全不懂 AI 的普通人，手机竖屏、单手、多半静音；一关 1–3 分钟。所以没有任何需要读说明的特殊规则，没有声音也不缺信息。
- **类型**：循环型（每关可以反复打），按通关率与时长验收。
- **牌面**：小人的代码一笔不改，从 `../ai-office/office.js`（站姿、挥手、11 种配饰、老板、无忧无虑）和 `office-core.js`（跳一下、挥手的弹簧）原样抽出，生成 `src/figures.js`。办公室改了长相，跑 `node tools/sync-figures.cjs` 同步；测试会比对，不同步就红。

## 3. 构图与版面

- 竖屏：顶栏（关数、计时条、剩几对）、棋盘、底栏（提示、洗牌、暂停）。可视高度不到 700 时顶栏 50、底栏 66 CSS 像素，否则 58 / 78。
- 棋盘居中，四周留 0.36 格给外圈连线（线画在棋盘边外 0.3 格）。一格宽高比 0.86，牌之间留 4 CSS 像素。
- 小人放大倍数取整数物理像素：大人含阴影 30 行、最宽 23 列，取放得下的最大整数倍；小孩是大人的 4/3 倍（取整）。像素比 2 的 390×664 手机上，第 5 关小人每个逻辑像素 1.5 CSS 像素，第 1 关 2.5。
- 支持的最小可视区 360×600；横放手机能玩但牌小，顶栏下提示「竖过来玩，牌更大」。

## 4. 像不像：读数与关卡

**读数**：把两种小人各画在同一尺寸的牌上（就是游戏里用的同一个函数），按像素比平均回 CSS 像素，数两张牌颜色差 ΔE76 > 20 的 CSS 像素²。读数越小越像。

- **底线 100**：每一关、每种测试视口里，同关任意两种的读数都不少于 100（最像的老板和 CC 在参考牌面上 109）。
- **前两关门槛 300**：参考牌面（390×664、像素比 2、第 5 关的牌，全游戏最小的牌）上读数低于 300 的两种算「长得像」，不许同时出现在第 1、2 关。
- 校准：同一个人比自己读数 0；把 Codex 的衬衫换成只差 ΔE≈5 的颜色，读数掉到 100 以下。

| 关 | 棋盘 | 时限 | 上场 | 参考牌面上最像的一对 |
|---|---|---|---|---|
| 1 | 4×6 | 120 s | Codex、Agy、Muse、无忧 | 差别都很大 |
| 2 | 5×6 | 140 s | + etwin-cc、Cobbler | 仍都在 300 以上 |
| 3 | 6×6 | 160 s | + 豆包、无虑 | 无忧/无虑、Cobbler/豆包 |
| 4 | 6×7 | 180 s | + Grok Bot、老板 | Codex/Grok Bot、老板/Cobbler |
| 5 | 6×8 | 200 s | + CC、Kimi、Dots（13 位全员） | 老板/CC 109、CC/豆包 114、Agy/Dots 166 |

每关开始前把这关的人排一排给玩家认一认（每人挥手），再点「开始」计时。

## 5. 规则与时长

- 单击选牌，再点同一张取消；点了不一样的，选中换到新点的那张；同样的但连不上，那张抖一下、红边，选中也换过去。
- 消掉一对：红线停 0.35 秒，两个小人挥手或跳一下（0.7 秒，金边），再 0.18 秒淡出。逻辑上一配上就拿掉，动画不挡下一次点击。
- 提示每关 3 次（给出能连的一对），洗牌每关 2 次（只换位置不换牌，洗完保证能消完）。走到死局（盘上还有牌但一步都连不上）自动洗牌，提示「没路了，帮你洗一下牌」，不扣洗牌次数。
- 每关初始盘保证能全部消完（生成后用深搜求出一条完整消除顺序才放行）。
- 时间到判输，「再来一次」是新的一盘，提示和洗牌补满。消完全部牌过关，0.9 秒后进合影：这一关的人在办公室里排一两排，挥手、喊「茄子 / 耶 / 比心」，小孩跳。第 5 关后是全员合影。
- 暂停按钮停表；切到后台自动暂停。

**自动驾驶三档**（`src/core.js` 的 `Autopilot`，跨种子跑整关）：

- 精准档：每次找第一对能连的，想 0.35 秒、两下点击隔 0.14 秒，不出错。
- 手抖档（按真人误差抽样）：找一对的时间 = (2.3 + 0.05 × 剩余牌数 + 3.0 / √可连对数) 秒 × 对数正态噪声（σ 0.35）× 每个玩家一个快慢系数（对数正态 σ 0.3）；两下点击隔 0.32±0.09 秒；落点偏差按格子 0.2 倍正态分布（会点到旁边那张）；找了超过 9 秒且还有提示就用提示；看走眼概率 = clamp((450 − 读数) / 1200, 0, 0.3)，读数取盘上和它最像的那种。
- 莽撞档：每 0.28–0.38 秒随便点一张。

**时长与难度要求**：

- 精准档：每关每个种子都通关，用时不超过时限 10%、每对至少 0.25 秒。
- 手抖档（每关 200 个种子）：每关平均通关用时 55–180 秒；第 1、2 关通关率 ≥ 95%；第 5 关通关率在 70%–95% 之间；第 5 关平均用时超过第 1 关 1.6 倍。
- 样本里真发生过：第 5 关平均每局点错 ≥ 3 次、至少是第 1 关的 5 倍，点错数逐关大致不降；用过提示；遇到过死局自动洗牌。
- 莽撞档：第 3–5 关全输；输了重开能正常打完。

## 6. 性能预算与固定机位

- 目标：手机浏览器 390×664（像素比 2–3）与桌面 1280×720，60 帧。二维画布，牌面预先画进缓存，每帧 `drawImage` 不超过约 50 次；测量场景是默认入口第 5 关手抖档自动驾驶连玩 9 秒，绘制平均 ≤ 4 毫秒、最长 ≤ 16 毫秒。

| 入口 | 状态 |
|---|---|
| `?view=hero` | 第 3 关，种子 4，手抖档打到第 40 秒定格 |
| `?view=wide` | 第 5 关，种子 2，开局满盘 48 张（最像的都在） |
| `?view=match` | 第 2 关，种子 3，手抖档第一次消掉后 0.3 秒，小人正在做动作 |
| `?view=photo` | 第 1 关，种子 1，精准档过关后合影第 1.4 秒 |
| `?view=final` | 第 5 关，种子 1，精准档过关后全员合影 |
| `?view=lost` | 第 5 关，种子 5，莽撞档打到时间到 |

可加 `&seed=` 和 `&t=`。`?level=3` 直接从第 3 关的认人页开始。钩子：`window.__PLAYTEST__ = { ready, snapshot(), reset(), setSeed(n), step(ms) }`；另有 `window.__pixelMatch`（`start(关, 种子)`、`autopilot('precise'|'human'|'reckless')`、`advance(秒)`、`freeze()`、`probe()`、`cellCenter(r, c)`、`likeness()`、`cardReadout(r, c)`）。不带参数就是正常游玩，机位钩子回报实际进入的状态。
