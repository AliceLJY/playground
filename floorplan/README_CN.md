# 户型图 · 三维小样

从一张网上找来的户型图出发：读出墙、门窗和房间，算出面积，拉成可以转着看的三维模型，再配上 CAD 平面图、两套光追效果图和冬至日照。四个标签页，手机竖着看最合适，电脑上会收成居中的一栏。

**[在线看](https://aliceljy.github.io/playground/floorplan/)**

## 四个标签

- 三维：简化体块，拖动旋转，双指或滚轮缩放；下面列着 8 个房间的面积，合计 263.1 ㎡。
- 平面：导出的 CAD 图纸（DXF）读回后渲染的首层平面图，1:100。
- 效果图：客餐厅同一机位，橡木和胡桃木两套材质，路径追踪 256 采样。
- 日照：假设北京冬至，地面每一点的直射时长热力图，和各房间被直射的时长排行。

## 怎么做的

- 起因是 [@AndyL5cc 的一支片子](https://x.com/AndyL5cc/status/2104917432825680278)：一张户型图变成 CAD、三维、光追效果图和手机页。这边先找了一张公有领域的户型图做小样，看看这条路到底缺什么，后来做成了一支 45 秒左右的完整流程成片。这一页就是成片里「手机页」那一段用的网页。
- 读图、家具标注、CAD 导出、日照计算和光追都在作者本地的出片工程里完成。平面、家具和日照数据已经打包进 `share.js`，`assets/` 里的四张图是那个工程的真实产物。这个文件夹只放发布用的成品。
- 和工程里的原版比，这里改了三处：标题、角标和页脚不再写「本地页面」；电脑上收成居中的一栏；屏幕比例比电脑窄时，三维机位按比例拉远（`share.js` 里的 `setView`），手机上整栋房子不出画。

## 素材

- 户型图：Wikimedia Commons 的 [Sample Floorplan.jpg](https://commons.wikimedia.org/wiki/File:Sample_Floorplan.jpg)，Boereck 绘，公有领域。

## 验证

2026-10-02 上架前在 Mac mini（Apple M4，WebGL 走真实 GPU）上用 Playwright 驱动的 Chromium 验过，源文件和按工作流组装出的发布目录各验一遍：1440×900 与 390×844 两种视口、像素比 1；四个标签逐个点开，四张图都加载成功，除了浏览器自己找网站图标的 404 没有别的报错。三维画布读了像素：手机宽度下，改之前画布最左、最右一列分别有 22 和 43 个像素落在墙上（房子出画），改之后两边都是 0，左右各留出 35–43 像素；电脑宽度下房子的位置和改之前一致，机位没变。

2026-10-02 上线后 Alice 用自己的手机试过，转动和缩放都顺滑。
