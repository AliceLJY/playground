# 西关大屋 · 推开看

一座可以点开的广州西关大屋，等距线稿。点一下：趟栊拉进墙里，大门朝里推开贴到墙上，屋面前坡翻过来扣在后坡上、再整块掀到后墙外，前墙往前倒，两面山墙往外倒，天井边的满洲窗往上推开。门官厅、挡中、天井、花罩、正厅的神楼和八仙桌，还有通到阁楼的 13 级楼梯，都露出来。再点一下，沿同一条时间线倒回去合上。

**[在线看](https://aliceljy.github.io/playground/xiguan-house/)**

English: [README.md](README.md)

## 操作

- 点屋子、点「推开 / 合上」按钮，或按空格、回车。触屏同样点一下。
- 一次展开约 3.4 秒，展开后停住不动，看多久由你；动画进行中再按会被忽略。
- 系统开了「减少动态效果」时直接跳到结果，不放动画。
- 固定机位：`?view=open` 打开后的样子，`?view=mid&t=1.9` 停在时间线第 1.9 秒（0 到 3.4）。

## 规格

- **体验一句话**：访客点一下，看一座西关大屋怎样「被拆开」，看清门口三件头和中轴上一进一进的厅堂；核心操作只有一个：推开、合上。
- **主美学**：探索（看见里面的东西）为主，感官（机械动作的手感）为辅。场地是手机或电脑，多半静音，一次看一两分钟；没有声音。
- **配色**（sRGB HEX）：底色绢米白 `#efe9dc`，墨线深灰绿 `#2c3833`；青砖 `#b7beb9`、花岗岩 `#dcd8cc`、瓦 `#a3a89f`、木 `#8d5f40`、大门坤甸木 `#6f4630`；强调色只给满洲窗的套色玻璃（蓝 `#3f74a8`、红 `#c2493a`、琥珀 `#e2b23e`、绿 `#4f8c5d`）和神楼红漆 `#9e3b2b`。
- **构图**：等距正交，方位 40°、仰角 37°，光从左前上方来。取景按整段动作的最大范围定（合上时屋子在中间偏上，打开后掀起的屋面和倒下的墙都在画内），推开、合上全程机位和缩放不变，只有窗口尺寸变化时重新适配；底部留按钮栏，顶部留一行说明。
- **性能预算**：Canvas 2D，约 470 个面、每帧排序一次；目标 60 fps，静止时不重画。

## 验收

| 条目 | 怎么查 | 结果（2026-10-27） |
|---|---|---|
| 全程没有部件互相穿插 | `tests/geometry.test.cjs`：每 0.025 秒和每段动作末尾的关键时刻，所有部件两两做凸体分离轴检测，容差 0.3 cm | 通过。拿一条已知是坏的时间线校准过：让前墙在屋面掀开前就倒，检查当场报出前墙上段穿进前坡（最深约 9 cm） |
| 铰链接得住 | 同上：前坡的屋脊铰线全程贴在后坡上，两扇大门的门轴全程不离门框 | 通过 |
| 收起归位准确 | 同上：时间线回到 0，每个顶点与初始位置误差 < 1e-9 cm；浏览器里推开再按空格合上，`s` 回到 0 | 通过 |
| 过冲不超过 2%，落到实物上的动作不越过目标 | 同上：屋面掀起、趟栊、满洲窗过冲约 2% 再回落；墙倒地、大门贴墙、前坡扣上是碰到后回弹 2% | 通过 |
| 屋高落在资料范围里 | 同上：檐墙 ≥ 5 m，屋脊 6–8 m | 通过（5.0 m、7.8 m） |
| 背景不漂移 | `tools/browser-check.cjs`：整段动作逐 0.05 秒取同一个世界点的屏幕坐标，偏移为 0 | 通过 |
| 五档视口不裁切、不压按钮和说明 | 同上：1920×1080、1280×720、390×664（iPhone 带 Safari 栏）、412×700（安卓）、844×390（横屏），整段动作里模型外框都在可视区内，按钮完整、中心点到的就是按钮 | 通过 |
| 动画期间重复触发被忽略、零报错 | 同上 | 通过 |

另外：`tools/shots.cjs` 拍各时刻截图，`tools/perf.cjs` 测帧率。无头 Chromium（软件渲染，没有 GPU）里 390 宽手机档约 60 fps，1920×1080 桌面档约 36 fps；真机没测过。这页好不好看、动作手感对不对，自动检查判不了，要人看。

## 怎么做的

- 2026-10-27 由 Claude Code 在 Mac mini 上写成。灵感来自 [Ian (@ianneo_ai) 的折叠庭院小屋](https://x.com/ianneo_ai/status/2114198360408326320)，他又参考了 Akshat Singh 的 404 页面（等距线稿老虎机）。借的是做法：部件之间连接关系固定、几组动作错开起步、末尾 2% 回落、按整段动作的最大范围定取景。没用他的代码。
- 和同仓的[南禅寺大殿](../nanchan-temple/)是同一类画风，但南禅寺用 Anatomy skill 做逐层装配（平移）；这里是铰链转动，部件姿势每帧都变，所以自己写了一个小渲染：所有部件是凸多面体，每帧按面的平面关系排前后（重叠的两面先用平面测试判谁在前，判不出再看深度），再拓扑排序画出来。同一份几何也给 Node 测试做穿插检查。
- 尺寸和构件的出处、哪些是示意，见 [`facts.md`](facts.md)。

## 已知简化

- 只截了门口到正厅这一段，省掉了轿厅、第二个天井和后面的头房、二厅、尾房。
- 屋脊只画一道压脊线，没做凸起的龙船脊、博古脊；门口没画台阶和凹斗门廊。这两样都会挡住折叠动作。
- 天井两侧只画了隔墙和满洲窗，书房、偏厅里只放了一张书桌和一张茶几。
- 脚门一直关着（查不到它朝哪边开）。

## 文件

- `index.html`：页面。
- `src/model.js`：尺寸、部件、铰链和时间线，浏览器和 Node 测试共用。
- `src/view.js`：等距投影、面排序、绘制和交互。
- `tests/geometry.test.cjs`：几何与机构检查，`node --test tests/*.test.cjs`。
- `tools/browser-check.cjs`、`tools/shots.cjs`、`tools/perf.cjs`：浏览器检查、截图、帧率，用法写在各自开头。
- `tools/demo.cjs`、`tools/demo-music.py`：竖屏演示片的逐帧录屏和按动作卡点合成的配乐。
- `facts.md`：事实表与出处。

## 谁会点开、AI 素材

- 谁会点开：在西关大屋门口站过、想知道门里面一进一进是什么样的人，也包括只想点一下看一座房子被拆开的人。
- AI 素材清单：没有 AI 生成的图片、模型或声音，页面没有音频。所有画面都是代码按尺寸算出来的线稿，代码和事实表由人与 AI 协作完成。
