# 可选玩法：找三件头

在原有页面点「找三件头」，看同一模型的闭合门面放大图，依次辨认脚门、趟栊、大门。点中门面上的标记后，该构件局部高亮，并显示一句已有资料中的说明；找齐后自动展开全屋，出现「请进，去天井坐坐」，恢复原有开合、三个标签与半途暂停。探索为主，适合手机静音单手或电脑键盘，约 30–60 秒，无倒计时（时长待试玩校准）。

- 点错或重复点已找到的构件：提示重试，不清除已找到的进度，不展开房屋；可随时返回全屋，保留进入前的姿势。退出后重进从零开始。
- 第三件说明停留 1.8 秒后自动展开（待试玩校准）；沿用原 3.4 秒开合时间线和减少动态效果设置。完成提示保留 6 秒，可关闭（待试玩校准）。
- 门面使用原几何、原材质的正面局部视图，不移动门或捏造被遮住的部分；三枚至少 44×44 CSS px 的标记用引线指向可见位置，找到后以原有红色 `#9e3b2b`（sRGB）强调。键盘 Tab + Enter / Space 和触控点按发同一选择意图。
- 说明限于 facts.md：脚门是外侧第一道屏风门；趟栊横向滑动；大门朝里推开、门后横闩扣门。资料未记载的防盗、通风等用途不添加。
- 复用 Canvas 2D、面排序和原生按钮 / dialog，不新增依赖、资产、通用框架或构建步骤。仅在进入、选择、窗口变化时重画局部图。

## 验收（五条）

1. 默认点击房屋、空格 / 回车、开合按钮、三个标签和「停在这儿」仍通过原 Node 与两份浏览器检查；未进入玩法时没有进度或高亮。
2. 真实触控 / 键盘依次选择三件，进度恰为 1、2、3；完成前门面保持闭合，最后自动展开到 3.4 秒并显示「请进」。Node 操作序列与浏览器真实输入均检查，明确计数确实发生了三次正确选择。
3. 至少一次误选及一次重复选择实际发生：进度保留、房屋不提前展开；说明可见，随后可继续完成。Node 与浏览器均检查。
4. 中途退出不改变原姿势；完成后进度、高亮、计时器清空，原标签可点、暂停可用、开合归零，重进为 0/3。包括退出发生在最后说明停留期间。
5. 发布拷贝在 390×664、320×568、844×340、1365×900 下走通；按钮至少 44 px、中心可点击、无相互覆盖、无页面错误，截图逐张读图。正常入口与开局操作录屏另验；真人辨认与手感、真手机、声音不作自动通过声明。
