# 粤剧六柱测试 · 一页规格

## 1. 体验一句话

访客在手机上答八道日常情境题，一分钟内得到「你是撑起粤剧团的哪一根柱」，顺带学到这一柱在粤剧里的几条真事，长按保存一张分享图发给朋友。

- 主美学：表达（测出来的是「我」）、社交（分享图、朋友打开分享链接看到的是这一柱的介绍，再自己测）。
- 场地：手机竖屏、微信内置浏览器为主，多半静音，单手，一次一到两分钟。没有声音。
- 弧型：每次走一遍。验收看陌生人能不能一次走完、能不能说出自己是哪一柱、记住一条粤剧知识，不套通关率。

## 2. 结果集与写法

- 结果用六柱制：文武生、小生、正印花旦、二帮花旦、丑生、武生（剧团里的排法）。按「六根梁柱撑起剧团」来讲，不排名次。
- 每个结果四块：名字与一句标签、「你的样子」（测试的趣味解读，我们设计的）、「这一柱在粤剧里」（每条带出处）、「你在《帝女花》里」演谁。
- 题目、选项、「你的样子」、标签一律不出现性别词（男、女、他、她、先生、小姐、哥、姐）；事实里讲反串（女文武生、男花旦）照写，那是史实。
- 页面底部说明：六柱是剧团编制，花脸、公脚、彩旦等行当没有收进来。

## 3. 题目与计分

- 八道题，每题四个选项，四个选项分别指向四根不同的柱；每根柱至少在五道题里出现。
- 每个选项给对应的柱一分；最高分并列时，取并列者里最后一次被选中的那根。
- 随机作答（4^8 种答法全部穷举）下，每根柱的出现比例在 12%–22% 之间。2026-10-26 实测：文武生 15.6%、小生 17.2%、正印花旦 17.2%、二帮花旦 15.7%、丑生 17.2%、武生 17.1%。
- 只朝一根柱选（有它就选它），结果必须就是它。

## 4. 事实依据

- 事实底稿与来源核对在 `sync-bridge/AI产出/2026-10-26-粤剧行当测试/research.md`（不在本仓）：69 条事实，每条注明来源与核对状态。页面只用其中有出处的，`src/core.js` 每条事实带来源编号。
- 研究戏曲的朋友 2026-10-26 逐条核对过：六柱名单、《帝女花》六柱角色、开笔写「吉」字、花旦四门齐、武生的写法、「十大行当里没有文武生」。来源编号 R1，不署名。
- 暂不上页面（`WITHHELD`，测试会拦）：武生「骑龙头」（朋友在查）、「文武生」由靓少华首创（朋友记不清）、「武生即京剧之须生」（来源互相矛盾）。
- 只有一个来源、未经朋友核对、但仍上页面的：小生的传统戏路（S3）、白驹荣「小生王」（S8）、正印武生在《六国大封相》表演「坐车」（S3）、「无丑不成戏」（S3）。

## 5. 配色与版式

- 底色宣纸 `#F3EAD9`（sRGB），墨 `#2B211C`，主红 `#B3261E`（按钮、开场），金 `#D9A93B` / `#F2D27A`（横楣、柱头、选中的柱）。
- 每根柱一个主色，用在结果页头部色块、分享图上半部：文武生 `#1F4FA8`、小生 `#6A4FD0`、正印花旦 `#D2245E`、二帮花旦 `#138A7A`、丑生 `#E07A12`、武生 `#2E2A28`。六色互不相同（测试会查）。
- 文字要大：结果名 68–104px 楷体粗，开场标题 30–44px。按钮高约 56px，选项卡片整块可点。
- 分享图 1080×1620：上 620 是色块（「我是撑起粤剧团的」、名字 210px、标签、六根柱、自己那根亮金），中间「你的样子」与《帝女花》角色，下方一条「这一柱在粤剧里」，底部 200 是红色页脚（「你是哪一根柱？」、网址、我的AI小木屋）。版面自下而上排，放不下就缩字，各块不重叠。

## 6. 性能

单个 HTML 加两个脚本，无依赖、无外部请求（插画到位后每张 webp 不超过 200KB）。目标：中端安卓手机微信浏览器首屏 1 秒内可点。
