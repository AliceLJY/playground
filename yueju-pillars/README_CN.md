# 你是撑起粤剧团的哪一根柱？

粤剧的剧团靠六位主演撑起整台戏，就像六根梁柱，所以叫「六柱制」：文武生、小生、正印花旦、二帮花旦、丑生、武生。答八道日常小题，看你是哪一根；结果页讲这一柱在粤剧里是什么样的，再告诉你在名剧《帝女花》里你会演谁。长按分享图就能发给朋友。返回上一题时，原选项会标出「上次选了这一项」，可以重新选择。

**[在线测一测](https://aliceljy.github.io/playground/yueju-pillars/)**

## 资料

「这一柱在粤剧里」每一条都有出处：香港记忆、香港教育大学非遗教育资源站的粤剧笔记、羊城晚报网转载的中国粤剧网条目、香港康文署、香港都会大学等，页面底部有完整来源列表；一位研究戏曲的朋友逐条核对过。还没核实清楚的说法（比如武生「骑龙头」）暂时不写。六柱是剧团编制，花脸、公脚、彩旦这些行当不在六柱里，这次没有收。

## 怎么做的

- 规格在 [SPEC.md](SPEC.md)。
- 题目、结果、来源和计分都在 `src/core.js`，没有页面代码，Node 里能跑。测试穷举全部 4^8 种答法，检查六个结果在随机作答下都在 12%–22% 之间、并列时的取舍规则、措辞不预设性别、每条事实都有来源。
- 页面是普通 HTML 加 `src/game.js`，分享图用画布现画。
- 分享链接 `?r=<柱>` 直接打开某一柱；`?view=q3` 直接看第 3 题。调试钩子 `window.__pillar`。
