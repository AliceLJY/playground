# 小橘飞车 · 珠江杯

通过人与 AI 协作完成的浏览器竞速游戏。毛茸茸的中华田园橘猫骑上自行车，与五只猫穿过西关骑楼、沙面绿荫和珠江大桥。

[在线试玩](https://aliceljy.github.io/playground/xiaoju-racing/) · [英文说明](README.md)

## 怎么玩

选择一至三圈和三档对手水平，倒数结束后按住加速。方向键或 WASD 控制加速、刹车与转向；按住 Shift 漂移蓄气，松开触发短暂小喷；空格使用氮气。C 切换镜头，J 跳跃，R 扶正，Esc 或 P 暂停。

小屏设备提供触屏按钮，建议横屏。触屏菜单和暂停页可开启“自动踩踏”（默认关闭），刹车优先；暂停页可“扶正后继续”。矮横屏收起完整名次榜到暂停页，保留名次、圈数、氮气和缩小的速度及地图。菜单里可以近看小橘，也可以切换到流畅画质。

首次来访点「开始比赛」先进入「沙面三弯漂移驾照」：45 秒内单车练三弯，真实小喷并安全出弯盖猫爪章，撞栏只重试本弯；自动踩踏照常可用。屏上可点「跳过，直接比赛」。考过或跳过会在本机记下，之后开始键直接进正式比赛；菜单驾照入口保留。存储不可用时，每次仍先进入短考。

## 这一版有什么

六猫同场比赛、约七百四十五米的原创广州风格环路、漂移、小喷、氮气、加速带、护栏、骑手接触、小地图、实时名次、冲线结算与重新比赛。小橘有虎斑短毛、绿眼睛、粉鼻子、胡须和摆动的尾巴，爪子跟随车把和踏板运动。

角色仍是拟人动画风格；赛道是艺术化组合，并非真实广州道路。没有多人联网或比赛进度存档，刷新会重新开始；仅记录是否完成或跳过首次驾照。

自动化可带 `?intro=skip`，让开始键直进原玩法且不写入来访记录；已有 `window.__race` 状态／指标钩子保持原样，移动端检查与触控录屏脚本已带上该参数。

## 本地与离线

在本目录运行：

```sh
python3 -m http.server 8774
```

随后用浏览器打开本机地址。也可以运行下面的命令，生成“小橘飞车.html”，直接用浏览器打开这个文件离线游玩：

```sh
python3 build.py
```

不需要注册、密钥或安装依赖。三维运行库、模型、毛发和纹理都在本地。

## 验证范围

二十二项核心测试覆盖完整比赛、胜负、暂停、重开、漂移和氮气、护栏恢复、跳跃、防重复计圈与接近同时冲线的排序。实际浏览器检查了加载、键盘移动、重开和桌面及手机尺寸布局；完整比赛胜负通过模拟验证。真实手机和 Safari 尚未实测，外观与手感仍可继续打磨。

本轮触屏回归与复现命令见 [VERIFICATION.md](VERIFICATION.md)。自动踩踏的真实双拇指舒适度和操控手感仍待真人试玩。

场景与角色为原创程序化模型。三维运行库保留原有许可，见第三方声明。

## 谁会点开、AI 素材

- 谁会点开：喜欢猫、喜欢漂移竞速的人，和想看广州街景做成赛道的人。
- AI 素材清单：没有 AI 生成的图片或模型，小橘的毛发和赛道是程序化的；代码由人与 AI 协作完成。
