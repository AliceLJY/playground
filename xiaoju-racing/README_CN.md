# 小橘飞车 · 珠江杯

通过人与 AI 协作完成的浏览器竞速游戏。毛茸茸的中华田园橘猫骑上自行车，与五只猫穿过西关骑楼、沙面绿荫和珠江大桥。

[在线试玩](https://aliceljy.github.io/playground/xiaoju-racing/) · [英文说明](README.md)

## 怎么玩

选择一至三圈和三档对手水平，倒数结束后按住加速。方向键或 WASD 控制加速、刹车与转向；按住 Shift 漂移蓄气，松开触发短暂小喷；空格使用氮气。C 切换镜头，J 跳跃，R 扶正，Esc 或 P 暂停。

小屏设备提供触屏按钮，建议横屏。菜单里可以近看小橘，也可以切换到流畅画质。

## 这一版有什么

六猫同场比赛、约七百四十五米的原创广州风格环路、漂移、小喷、氮气、加速带、护栏、骑手接触、小地图、实时名次、冲线结算与重新比赛。小橘有虎斑短毛、绿眼睛、粉鼻子、胡须和摆动的尾巴，爪子跟随车把和踏板运动。

角色仍是拟人动画风格；赛道是艺术化组合，并非真实广州道路。没有多人联网或进度存档，刷新会重新开始。

## 本地与离线

在本目录运行：

```sh
python3 -m http.server 8774
```

随后用浏览器打开本机地址。也可以运行下面的命令，生成“小橘飞车.html”，直接用浏览器打开这个文件离线游玩：

```sh
python3 build.py
```

不需要注册、密钥或安装依赖。三维运行库、模型、毛发和纹理都在本地。

## 验证范围

十七项核心测试覆盖完整比赛、胜负、暂停、重开、漂移和氮气、护栏恢复、跳跃、防重复计圈与接近同时冲线的排序。实际浏览器检查了加载、键盘移动、重开和桌面及手机尺寸布局；完整比赛胜负通过模拟验证。真实手机和 Safari 尚未实测，外观与手感仍可继续打磨。

场景与角色为原创程序化模型。三维运行库保留原有许可，见第三方声明。
