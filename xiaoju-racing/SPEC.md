# 沙面三弯漂移驾照（可选短考）

玩家从菜单进入单车短考，在现有沙面绿荫路段依次练三个弯，学会「加速、转向并按住漂移、松开小喷」，拿齐三枚猫爪章。主目标是挑战与掌握操作后的成就感；电脑键盘或手机双手触控，静音也能看懂。正式比赛的默认入口、圈数、难度、车辆手感与对手参数均不变，自动踩踏沿用菜单选择。

- 单次最多 **45 秒有效驾驶时间**，暂停不计时；预期初学者 30–45 秒，熟练者可提前完成。时间与以下弯区范围均 **待试玩校准**。
- 复用赛道中心线上的三个弯区（米）：第一弯 245–290，第二弯 315–360，第三弯 385–430；各从弯区前 25 米、静止居中开始，成功后转到下一弯练习。
- 在当前弯区内由真实漂移释放触发 `mini` 才记本弯小喷，安全驶过弯区末端才盖章；加速带和氮气不算。原有漂移条件保持：速度超过 7.5 m/s、同时转向、持续超过 0.32 秒后释放；界面提示可松开时机。
- 撞栏、漏喷出弯、逆向离开练习区或主动扶正，只重试本弯（回到该弯起点、清本弯小喷），保留之前的章与已用时间。三章齐即「稳稳过弯」；超时显示实际还差几弯，可重新短考或回菜单比赛。
- 沿用当前 sRGB 配色：深青 `#18343d` 为底、米白 `#fff8df` 为文字、琥珀 `#f5bf75` 为章与重点。沿用追逐机位及默认画质；目标提示放顶部、操控区放底部，保留中央车与道路。新玩法不增加模型或外部素材；复用六猫场景但仅显示和模拟小橘，draw calls 不超过同画质正式比赛。

## 验收（5 条）

1. 菜单明确可选；默认仍为两圈／认真／自动踩踏关。驾照只一辆车；完成、退出、重考后可回原流程，比赛无章、计时或输入残留。Node 状态回归 + 浏览器实际点击检查。
2. 真实输入序列完成三个弯，样本中每弯确有 `mini` 事件且安全出弯；直行、加速带、氮气不盖章。Node 固定步长模拟 + 浏览器键盘／触控走通，不用钩子直接盖章。
3. 样本中确有撞栏与漏喷；失败只重置本弯，之前的章与计时保留，重试可继续完成。暂停冻结，45 秒超时如实结算。Node 模拟覆盖莽撞驾驶与恢复。
4. 源码与离线构建在 390×664、320×568、844×340、1365×900 下新玩法可进入、完成和返回，页面错误为 0；关键按钮至少 44 CSS px、完整可见且中心可点击，截图逐张读。默认高画质、手机 DPR 2／渲染比 1.6、桌面 DPR 1，不锁定低画质；记录 GPU 与 draw calls。
5. 原有 Node 测试及触控浏览器回归全过；另录默认画质开局 30 秒操作，检查朝向、转向、漂移释放与切镜头。真人手感、真手机、声音不视为自动验收通过。

复现：正常 `index.html` 或构建后的「小橘飞车.html」，从菜单点「沙面三弯漂移驾照」。`?seed=1` 固定种子，现有只读 `window.__race` 回报实际阶段、驾照进度和渲染指标；不增加自动闯关的玩家入口。
