- Report 1: optional touch auto pedal, off on a fresh page. It enters the same throttle assembly as manual acceleration; brake overrides it. No steering, grip, drift, opponent or difficulty parameters changed.
- Report 2: at heights up to 440 CSS px, full standings move into pause; speed and map shrink and leave camera/pause and steering clear. Portrait nitro sits above the right actions, separate from speed. Touch driving and camera/pause targets are at least 44 CSS px.

## Red / green evidence

Before changing implementation, both tests in `tests/auto-pedal.test.cjs` failed: auto pedal did not move the bike or charge a two-input drift. They now pass and compare the resulting racers with manual-throttle simulation, including brake priority and pause. Other racers are marked finished in this isolated throttle test so existing contact speed transfer cannot masquerade as throttle.

`tools/mobile-check.cjs` failed on the old UI for overlapping speed/map/buttons and leaderboard/steering, missing auto pedal, missing recovery, and missing paused standings. The final source and rebuilt standalone page each pass **53 browser assertions** across 390×664, 320×568, 844×340, 844×300 and 1365×900. Checks measure actual rectangles, centre hit targets and simulation state; they also exercise pointerup, pointercancel, lostpointercapture, blur and visibilitychange releases, keyboard braking, and recovery progress.

All **22 Node tests** pass. Syntax checks and `git diff --check` pass. The bundled Three.js remains r160. Browser: local Chrome through Playwright, ANGLE Metal / Apple M4, phone emulation DPR 2 (normal render ratio 1.6), desktop DPR 1. Default high quality is retained. No page errors. Race/pause screenshots from every viewport were inspected. `tools/touch-smoke.cjs` records 30 seconds of actual CDP touch events on the built page: two fingers steer + drift while auto pedal is on, charge increases by 8.22, releasing gives the existing mini boost, brake stops at 0, and manual acceleration works after disabling auto pedal. The recording was reviewed as sampled frames for heading, response and camera change.

## Reproduce

From the repository root, start a local HTTP server, then:

```sh
node --test xiaoju-racing/tests/*.test.cjs
python3 xiaoju-racing/build.py
NODE_PATH="$(npm root -g)" node xiaoju-racing/tools/mobile-check.cjs http://127.0.0.1:8844/xiaoju-racing/ /tmp/xiaoju-source
NODE_PATH="$(npm root -g)" node xiaoju-racing/tools/mobile-check.cjs http://127.0.0.1:8844/xiaoju-racing/小橘飞车.html /tmp/xiaoju-built
NODE_PATH="$(npm root -g)" node xiaoju-racing/tools/touch-smoke.cjs http://127.0.0.1:8844/xiaoju-racing/小橘飞车.html /tmp/xiaoju-touch
```

The standalone file is ignored and regenerated by CI, not checked in. Local evidence is in `out-B4/xiaoju-{red,source,built,touch}` beside the B4 worktree. No deployment was performed. Physical phones, Safari, sound quality and human comfort/handling remain unverified; auto pedal comfort was originally an inference, not a confirmed phone defect. No optional gameplay modes were added.
