# P3 optional drift licence — 2026-11-03

The menu now offers **沙面三弯漂移驾照**, a solo exam on three existing Shamian bends. It reuses `RaceCore` physics, mini-boost events, input assembly and the existing renderer; no dependencies, models or handling parameters were added or changed. A mini inside the designated bend lights a pending paw; a clean exit commits it. A rail touch, missed mini, reverse exit or manual recovery retries only the current bend. Earned stamps and elapsed time survive retries. Three stamps pass immediately; 45 seconds without completing all three shows the actual number of missing bends. Returning to the menu recreates the original cup. The scope deliberately excludes ghost racing and changes to the default cup.
