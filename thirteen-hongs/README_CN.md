# 十三行江岸

约 1805 年前后，珠江北岸的广州商馆区：一排西式立面的商馆，馆前空地与旗杆，码头石阶和栈桥，江上是疍家艇、西瓜扁、花艇和帆船。可以从空中看，也可以第一人称走进去，或者跟着茶艇、挑夫、行商、小贩、轿子、官员、僧人、疍家艇、帆船看。天色能在午后、黄昏、入夜之间切换，入夜后商馆和巷子亮灯。

[在线看](https://aliceljy.github.io/playground/thirteen-hongs/) · [WebGPU 版](https://aliceljy.github.io/playground/thirteen-hongs/webgpu.html)（同一套场景，渲染换成 WebGPU；浏览器不支持时自动退回 WebGL2）

## 里面有什么

- 十三座商馆按史料次序排开，中间夹着靖远街和新豆栏两条能走进去的巷子。
- 桌面六百三十多个人（手机上约两百）：挑夫、行商、通事、账房、洋商、水手、小贩、疍家女、官员、僧人，各做各的事；身体圆润、手肘膝盖会弯，男子留辫，有真实投影。二十九条船，一顶绕着空地走的二人小轿。
- 屋瓦、砖墙、木板、篾席的纹路是着色器里算出来的。脸、衣服和夯土地面是开场时在画布上现画的（八张脸、八种衣型，每人各选一格），不读任何图片文件。远处有一层薄雾，对岸半隐。桌面上水面有岸、船和旗的倒影；帧率连续低于 28 会自动先关倒影、再关逐帧阴影。
- 靖远街的铺面各摆各的：茶桌、瓷器架、绸缎、扇子、外销画，招牌写着行当。
- 名场面「茶箱落艇」每四分多钟发生一遍：茶艇进港靠上栈桥，行商和大班在三脚秤旁验货，五个挑夫把十五箱茶一箱箱扛到栈桥头、弯腰递过去，艇上的人接住码好，升帆，开往黄埔。底栏那条会显示进度，点它就跟过去看；嫌慢点「×1」调成四倍。
- 水声、人声、橹声、锣、对岸的钟，以及按粤语声调走向做的拟声叫卖，都是浏览器现场合成的。

## 怎么操作

电脑：拖动转头，WASD 走动，Shift 快走，滚轮缩放。手机：左下摇杆走动，其余地方拖动转头，双指缩放。

## 哪些是真的

见 [facts.md](facts.md)。商馆次序、两条巷、挂旗的六国、茶叶过秤落艇有来源；各馆的颜色开间、摊档、人数、船的细节是示意，不是复原。
