# 骑楼雨夜 · 巨虫围街

雨夜的西关骑楼街，三个沙井盖被顶开，蟑螂从里面涌上来。拿一把杀虫喷雾和一只凉拖，把井盖逐个盖回去，再赶上渡口的末班船。

[在线玩](https://aliceljy.github.io/playground/qilou-rain/)

## 怎么玩

- 电脑：`W A S D` 走，鼠标看，左键喷，右键拍，按住 `E` 封盖，`R` 换罐，`Shift` 跑，空格跳，`Esc` 暂停。没有鼠标时右手用 `J` 喷、`K` 拍、方向键转头、`L` 封盖，左手只管走。
- 手机：左半边屏幕拖动是走，右半边拖动是看，右下角有喷、拍、换罐、跳四个按钮，走到井口会出现「封」。
- 爬的会抬起前身再咬；飞的先悬停再俯冲；带壳的正面喷不动，引它撞上柱子翻了肚再打。

## 怎么做的

街道、骑楼、招牌、雨、倒影、蟑螂、手里的喷雾枪和所有声音都由代码在打开页面时生成，没有图片、模型和音频文件；招牌和全息警示牌上的字、喷雾枪和手套的旧漆与织纹，都是运行时画在画布上的。街上有一层科幻的东西：罩住街区的封锁罩、巡逻无人机、全息警示牌、井口发亮的卵囊。蟑螂的外形和三足步态分组参照本仓 [gz-roach](../gz-roach/) 里那只美洲大蠊。渲染用 Three.js（MIT），打包成一个可以离线打开的 HTML。

```
npm ci
node --test tests/*.test.cjs      # 无头逻辑测试
node tools/build.mjs              # 打成 dist/index.html
node tools/serve.cjs . 8947       # 本地预览 http://127.0.0.1:8947/dist/index.html
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs http://127.0.0.1:8947/dist/index.html shots/check
```

规格、数值、固定机位和验收结果在 [SPEC.md](SPEC.md)。
