# 深夜杂货店

雨夜里一块街角的微缩模型，整条街只剩一家老杂货店还亮着灯。先在外面转着看，双指张开（或滚轮往前）放大，就会被「吸」进模型里，以真人的视高站在街上。进店值一个夜班，收银台上贴着一张《夜班须知》。

**[打开玩](https://aliceljy.github.io/playground/diorama-walk/)** · 不敢玩可以开[安心版](https://aliceljy.github.io/playground/diorama-walk/?calm=1)，不会有吓人的东西。

有惊吓，建议戴耳机、关灯玩。

## 操作

| 在哪 | 手机 | 电脑 |
|---|---|---|
| 外面看模型 | 单指拖动转，双指张开放大走进去 | 拖动转，滚轮往前放大走进去 |
| 店里走 | 左下按住出摇杆，其他地方拖动转头，轻点地面走过去 | W S 或 ↑ ↓ 前后走，A D 横移，← → 或 Q E 转身，Shift 跑，拖动也能转，单击地面走过去 |
| 看纸条 | 走近、看着它，点一下 | 同左，或按 F |
| 看整间店 | 双指捏合；再张开，落回对准的地方 | 滚轮往后；再往前，落回光标处 |
| 回到外面 | 在「看整间店」里再捏合 | 再滚轮往后，或任何时候按 Esc |

## 怎么做的

- 一个单文件网页，用 Three.js 渲染，没有外部素材。店、货架、人影、狗都是方块和纯色（灰盒）；雨、移轴、灯管闪烁是程序生成的，声音用 WebAudio 现场合成，带方位。
- 「放大就走进去」由一个过渡进度驱动：外面的轨道相机沿曲线降到 1.6 米视高，雾、移轴和视场跟着一起变；缩小时沿原路升回去。店里多一级「看整间店」，像看娃娃屋。
- 惊吓都由玩法触发：看你站在哪、朝哪看、看不看得见，以及守没守须知。
- 灵感来自 X 上 [@beefnoode](https://x.com/beefnoode/status/2107417931017761271) 的雨夜微缩便利店。原作只能在模型外面转着看，这里想试试放大就能走进去。

规格和逐轮验收记录在 [SPEC.md](SPEC.md) 和 [VERIFICATION.md](VERIFICATION.md)，**里面有全部剧透**。

## 本地运行与测试

```bash
cd diorama-walk
npm ci
node tools/build.mjs            # 打包成 dist/index.html，单文件，可离线打开
node --test tests/*.test.cjs    # 纯逻辑测试
```

浏览器验收用 `tools/browser-check.cjs`（Playwright，需要真实 GPU）。固定机位如 `?view=hero`、`?view=inside`、`?view=door`，见 SPEC「固定机位与钩子」。
