# 一条消息的旅程

管道拼接解谜。格子里是能转的管道，点一格顺时针转 90°；把起点接到终点，点「发车」，一只小橘猫骑着自行车载着消息沿管道跑过去。路上有几个必经的「站」，每个站是一段真实流程里的环节，必须按顺序全部经过：漏一站或走反了，猫跑到半路就停下，被跳过的那一站变红，告诉你缺了什么。

**[在线游玩](https://aliceljy.github.io/playground/message-pipe/)**

五关，每关限时 35–80 秒，从简单到难：

1. **一句话的往返**：手机发一句话，经过消息桥，到 AI，再回到手机。
2. **写一篇公众号**：选题、取材、核实、打磨、成文。
3. **派活与读回**：写说明、派出去、对方干活、交回、验货。绕开「验货」直达终点，猫会带回一个空箱子——对方说做完了，文件根本没生成。
4. **先复现再修**：复现、定位、修改、重跑。
5. **推送之前**：跑测试、拉最新、推送、线上看。

每关通关时用一句话点出这段流程在现实里防的是什么。手机竖屏为主，横屏和电脑也能玩。没有声音，静音也看得懂。

## 操作

- 不用懂任何术语：站上标着 1、2、3，照数字顺序把管道接到终点就行，站名只是装饰。
- 点一格管道，它顺时针转 90°。亮起来的管道是已经接上起点的部分；接到终点时「发车」按钮会跳。
- 卡住了点发车旁边的 ↻，重新打乱再来。
- 接好后点「发车」（电脑也可以按回车）。猫跑错了要等它停下、读完提示，这段时间倒计时照走。
- 离开页面或按 Esc 会暂停，点「继续」恢复。
- 每次重来管道重新打乱，站的顺序不变；打通的关会解锁下一关。

## 怎么做的

- 一页规格在 [SPEC.md](SPEC.md)：关卡表、配色、规则、难度数值、性能预算、固定机位和十二条验收。
- 规则、求解器和三档自动驾驶在 `src/core.js`，不碰画面，可以在 node 里跑。每次打乱后用求解器算出最少转动次数，落在规格范围内才开局。
- 画面是二维画布，管道、站牌和骑车的橘猫都是代码画的，没有图片素材，没有构建步骤。
- 固定机位：`?view=start`、`?view=emptybox`、`?view=ride`、`?view=clear`；试玩钩子 `window.__PLAYTEST__`，验收钩子 `window.__pipe`。

## 本地运行

```bash
cd message-pipe && python3 -m http.server 8942
```

打开 `http://127.0.0.1:8942/`。测试：`node --test tests/*.test.cjs`。浏览器验收（需要本机已有 Playwright 和 Chrome）：`NODE_PATH="$(npm root -g)" node tools/browser-check.cjs <输出目录> [页面地址]`。发布时原样拷贝 `index.html` 和 `src/`。

## 谁会点开、AI 素材

- 谁会点开：想在手机上玩两分钟解谜的人；在用 AI 干活的人会认出这几段流程，尤其是「说做完了，其实没生成」那一关。
- AI 素材：没有 AI 生成的图片、模型、动作或声音；管道、站牌和橘猫都是代码画的。代码通过人与 AI 协作完成。
