# 灯影守夜 · 规格

一页规格。实现、测试、截图都对照这一页；规格改了，验收条目跟着改。

## 1. 一句话体验

散场后的皮影戏幕上，玩家操纵举着小铜锣的皮影小人「铜锣仔」守住幕后的油灯。对手的兵器一透光变亮就按格挡：按得准，铜锣「锵」一响、油灯猛地一跳、时间慢下半拍，对手被弹得踉跄，再上前一锣处决。核心操作是**看预警，按一下格挡**——不是一直按住，也不是连按。一局 3–5 分钟。

## 2. 操作

| 动作 | 键鼠 | 触屏 |
|---|---|---|
| 左右移动 | A / D 或 ← / → | 左下 ◀ ▶ |
| 格挡（按下那一刻记时） | K、空格或鼠标右键 | 右下「锣」 |
| 攻击 / 处决 | J 或鼠标左键 | 右下「槌」 |
| 闪避（带无敌时间） | L 或 Shift | 右下「闪」 |
| 暂停 | Esc 或 P | 右上「歇」 |

按下格挡时，铜锣仔自动转向最快要落下的那一招。

## 3. 手感数值

除标明「真实秒」外都是模拟秒。

| 项 | 值 |
|---|---|
| 完美弹反窗口 | 命中时刻 − 最近一次按下 ≤ 0.16 s，同一步按下也算 |
| 连按惩罚 | 按下前 0.4 s 内每多按一次，这次的窗口除以 (1 + 次数)。取 0.4 s 是为了和弹反姿态 0.42 s 首尾相接：两招相隔不到 0.42 s 时姿态自动兜住，相隔再长时第二下按键已经不在惩罚区间里 |
| 弹反姿态 | 完美后 0.42 s，期间正面来招自动完美 |
| 回击加成 | 完美后 1.0 s 内的**第一槌**：伤害 ×1.5，架势 ×1.8；打出去就用掉 |
| 打开规则 | 只有被打开的对手吃得到槌：回击窗口内、晕住或后仰时、出完最后一招的收招里。别的时候蛾子闪开，剪刀和鼠王用刃面把槌挡开——自己被弹开 0.25 s，不能出手，但能格挡 |
| 预警提前量 | 可格挡 0.40 s（白金光 + 梆子声），不可格挡 0.55 s（红光 + 鼓点）；按模拟秒对齐，不随出招速度变 |
| 预警之后 | 出招者锁定目标位置、不再追踪，侧移能让招落空 |
| 同时出手上限 | 出招中的敌人 ≤ 2；令牌发放间隔 ≥ 0.70 s；任意两次敌方命中相隔 ≥ 0.35 s |
| 闪避 | 0.38 s，无敌 0.04–0.30 s，位移 2.4；处决动作全程无敌 |
| 不叠身 | 步行时与对手中心至少相隔 0.45 + 0.8×对手体宽（鼠王 1.33、剪刀 0.93），对手冲步也停在这个距离外；闪避可以穿过去，晕住的对手可以贴上去处决 |
| 时间 | 顿帧期间时间 ×0.02；慢动作是真实秒的包络；镜头、震屏、灯焰都走真实秒 |

| 反馈 | 完美弹反 | 普通格挡 |
|---|---|---|
| 顿帧（真实秒） | 0.12 | 0.05 |
| 慢动作 | 0.4×，0.45 s（淡入 0.04、淡出 0.16） | 无 |
| 火花 | 28 粒金白 | 7 粒暗橙 |
| 灯焰 | 猛跳 +0.55（闪白） | 不变 |
| 镜头 | 推近 4%，震屏 1.0% | 震屏 0.4% |
| 声音 | 铜锣「锵」 | 木鼓「咚」 |
| 后果 | 对手加架势；蛾子直接晕，剪刀、鼠王攒满即晕可处决 | 自己加架势，满了破防 1.1 s |

## 4. 对手与场次

| | 扑灯蛾 | 剪刀精 | 偷油鼠王（Boss） |
|---|---|---|---|
| 血 / 架势 | 2 / 30 | 6 / 100 | 三盏灯油 / 140 |
| 招式 | 扑（单下俯冲） | 双剪（第二剪晚 0.72 s）、突刺 | 油勺三连、甩油（红，不可挡）、灯台扑 |
| 被完美弹反 | 直接晕 1.5 s | 架势 +35 | 架势 +18（灯台扑 +28） |
| 节奏 | 快、成群 | 第二剪拖半拍，专治乱按 | 只剩最后一盏灯油时进二阶段：出招 ×1.12，叫来两只蛾 |

处决：对手晕住时，在 2.0 距离内按攻击。杂兵一击就下；鼠王的灯油只有处决能灭，一次一盏。处决回灯油 +6。

场次：第一场「扑灯」4 蛾 → 第二场「咔嚓」3 剪刀 → 第三场「灯下乱」2 剪刀 + 5 蛾 → 第四场「鼠王」。场间歇 3.5 s，回灯油 +15。

## 6. 构图

- 正常游玩机位正面平视光幕：16:9 下光幕宽度占视口 86–96%。
- 光从幕后来：灯斑中心在光幕横向正中、离幕底 60% 高处；四角亮度不到幕心的 35%。
- 脚底线（剪影站立线）在视口底边以上 18–30%。
- 主角剪影高 = 视口高的 24–34%（16:9），4:3 下不低于 18%；鼠王 38–52%（16:9）。
- 前景空椅背只在远景机位出现，正常游玩机位里不压住脚底线。
- 可读性：任何预警时刻，出招者的剪影包围盒完整落在视口 4%–96% 的安全区里，16:9、4:3、19.5:9 三种比例都成立。

## 7. 性能预算

- 目标：M 系 Mac 的 Chrome 60 fps；2021 年以后的中端手机 ≥ 45 fps（没测真机前标「未验」）。
- 测量场景：`?view=stress`，视口 1280×720。
- draw call ≤ 110，三角形 ≤ 20k，单文件 HTML ≤ 900 KB。
- 默认像素比 = min(设备像素比, 2)。自适应：连续 1.5 s 平均低于 48 fps 降 0.25，最低 1.0；连续 4 s 高于 58 fps 回升，不超过默认值。

## 8. 固定机位

| URL | 视口 | 场景状态 | 看什么 |
|---|---|---|---|
| `?view=hero` | 1280×720，像素比 1 | 第二场，剪刀精一剪被完美弹反的那一刻，定格在顿帧里 | 火花、闪白、铜锣姿态、镜头推近 |
| `?view=hero&plain=1` | 同上 | 同一场，一直按住格挡，剪刀精一剪被普通格挡 | 与上一行对照：无闪白、火花少 |
| `?view=wide` | 同上 | 第三场，一只蛾子正在预警；远景，戏台框、空椅背都入画 | 构图、前后景、光向 |
| `?view=stress` | 同上 | 鼠王只剩最后一盏灯油，叫来两只蛾，两个攻击令牌都被占着且有一处正在预警 | 性能、同时出手上限 |

机位模式固定种子、冻结模拟，并把自适应分辨率锁在当前像素比上；**不改**像素比、画质或渲染路径。加 `&live=1` 让模拟继续跑。无参数入口是正常游玩。复现：在本目录起 `python3 -m http.server`，打开上表 URL，等 `window.__duel.ready` 为真再截图；也可以直接跑 `tools/browser-check.cjs`，用法见 [VERIFICATION.md](VERIFICATION.md)。

## 9. 验收条目

| # | 条目 | 检查方式 | 通过阈值 |
|---|---|---|---|
| 1 | 完美弹反窗口 | node 测试 | 0.16 s 内完美，0.17 s 以上普通；按住不算；连按 5 次后窗口 < 0.04 s |
| 2 | 预警提前量 | node 测试，出招速度 0.9 / 1.0 / 1.12 各跑一遍 | 可格挡 0.40 s、不可格挡 0.55 s，误差 ≤ 1 个模拟步（1/120 s） |
| 3 | 同时出手上限 | node 测试，固定种子跑完整对局 | 每一步出招中的敌人 ≤ 2；令牌间隔 ≥ 0.70 s；命中间隔 ≥ 0.35 s |
| 4 | 反馈区分 | node 测试读事件与时间缩放，浏览器读图 | 完美弹反时间缩放 ≤ 0.05，之后慢动作 ≤ 0.45×；火花 ≥ 普通格挡 3 倍；声音不同 |
| 5 | 构图（审美断言） | node 测试：实跑对局 + 剪影骨架 + 游戏用的机位函数 | 第 6 节全部范围 |
| 6 | 剪影读数（审美，浏览器） | `window.__duel.probe()`：只留主角本体（不含签子和发光层）对着空幕布各渲染一次，在主角覆盖的像素里比亮度，遮罩内收一像素去掉抗锯齿边；闪白读数是同一帧去掉灯焰闪白再渲染一次比全画面平均亮度 | 四个机位与玩家默认档里，主角剪影 ≤ 同位置幕布的 55%；完美弹反帧（hero、默认档）比无闪白帧亮 ≥ 15%，普通格挡（hero&plain=1）≤ 5% |
| 7 | 时长与难度 | node 测试：两种自动驾驶各跑 8 个种子 | 每招卡准的自动驾驶全赢、零伤，整局 1.6–2.6 分钟；手抖模式（按键时机正态分布，约六成完美）至少 7/8 局赢，整局 1.9–3.5 分钟。真人 3–5 分钟需试玩确认 |
| 8 | 性能 | 浏览器 `?view=stress` | draw call ≤ 110，三角形 ≤ 20k，M 系 Chrome ≥ 55 fps |
| 9 | 默认配置 | 无参数入口，像素比 2、自适应不锁，用真实键盘事件按 K 弹第一招 | 无报错、无外部请求；预警光、火花在兵器和铜锣上，不被遮挡 |
| 10 | 打得完、输得起 | node 测试 + 浏览器 | 自动驾驶能赢；灯油归零判负，能重开 |

手感、听感、好不好玩测不出来，交付时如实写「需要试玩」。

## 10. 借鉴边界

只借长风 Long Wind 的机制思路：按下时间戳判弹反、出招前预警且按模拟秒对齐、攻击令牌限制同时出手、架势与处决、顿帧加慢动作、镜头走真实时间。题材、人物、场景、界面、代码、造型和声音都是这里原创的；没有复制长风源码，也没用它的任何资产。
