## 读图结论

截图对照规格第 5、6 节逐张看过：

- `view-hero`：铜锣位置出现白金星光，火花散在锣边，镜头向交锋点推近；剪刀精刃尖顶在锣上；场次牌是「第二场 咔嚓」。
- `view-hero-plain`：同一位置换成一直按住格挡，没有闪白、没有星光，只有几粒暗火花，架势条涨了一截，提示「挡住了，但不完美」。
- `view-wide`：戏台居中占画面约一半宽，两侧暗红幕布有褶，前景两排空椅背只在戏台下方，光从幕后来，灯斑在光幕中上部。
- `view-stress`：鼠王剩最后一盏灯油，两只蛾子一只在预警发光，油勺发光；铜锣仔与鼠王相隔 1.33，只有锣和勺相碰，身体不叠。
- 默认档的完美弹反帧：闪白与星光落在铜锣上，处决标记在晕住的蛾子上方；没有出现长风那种「默认画质下特效偏到别处」的错位。
- 默认档的预警帧：蛾子前翅眼斑透白发亮，被弹晕的蛾子落在主角身前。
- 触屏横竖屏：◀ ▶ 在左下，「闪」「槌」「锣」在右下；鼠王场的血条在顶部场次牌下，不压按钮。

## 没覆盖到的

- 手感、听感、好不好玩：自动检查测不出来，需要真人试玩。尤其是 0.16 s 的窗口宽不宽、0.40 s 的预警够不够读、顿帧与慢动作的分量、锣声和梆子的音色。
- 声音只验证了不报错：headless 浏览器里没有人听。
- 真手机、Safari 与低端设备：触屏只在 Chrome 的手机模拟里验过；自适应降档的分支在代码里，但这次没有被触发。
- 构图断言用的是皮影骨架的包围盒和游戏自己的机位函数，证明的是「剪影位置与大小」，不证明画面好看。

## 录一段实况视频

这一步可选，不进 CI。`tools/record.cjs` 在页面加载前接管时钟：每拍一帧，游戏正好前进 1/60 秒，CSS 动画跟着同一个时钟走。游戏的 AudioContext 换成离线版本，`currentTime` 也跟着这个时钟，所以每个声音都落在引发它的那一帧上，录出来的帧率和机器快慢无关。截图是全范围 BT.601 的 JPEG，脚本显式转成有限范围 BT.709 并写好标签。需要本机已有 Playwright、Google Chrome 和 ffmpeg，本仓不安装它们。

```bash
cd shadow-gong
python3 -m http.server 8917 --bind 127.0.0.1
# 另开一个终端
NODE_PATH="$(npm root -g)" node tools/record.cjs ./实录.mp4 --seed 19
```

默认 1920×1080、60 帧，自动驾驶用手抖档（按键时机平均比命中提前 0.09 秒、标准差 0.05 秒），从售票页一直录到结算页，再停 5.5 秒。`--seconds N` 只录前 N 秒。`--size` 是 CSS 视口，`--dpr` 是像素比，成片尺寸是两者相乘。竖屏版用 `--size 540x960 --dpr 2` 出 1080×1920：游戏会换成自己的手机竖屏布局，血条和场次牌在上、幕布居中、空座位在下，字也按手机比例放大，比把横屏成片缩进竖屏画面清楚。触屏按钮和「横过来更好玩」只在触屏设备上出现，录出来没有。结束时打印的 JSON 里有时间线文件的路径，记着每次完美、格挡、受伤、处决和换场在视频里的时间。

2026-10-02 实测（Chrome 155 无头，Apple M4 GPU，ffmpeg 9.0.1）：

- 种子 19 录出 160.8 秒、9648 帧，自动驾驶打赢：完美 45、格挡 4、挨打 4、处决 18，和录制前 Node 模拟的预测一致。录一遍约 6.5 分钟。
- 逐帧比对哈希，9648 帧里没有一帧和前一帧完全相同，没有截到旧画面。
- 音画同步：按时间线找 53 次完美、格挡和受伤的起音，声音比画面晚 10 到 21 毫秒，中位数 15 毫秒，不到一帧。其中 4 毫秒是游戏自己的调度余量（`audio.js` 在 `currentTime + 0.004` 起音），其余主要来自起音包络和测量窗口。合轨前后的音频互相关偏移为 0。
- 竖屏版（`--size 540x960 --dpr 2`，1080×1920）：交付规格在录制前写好（同一局应正好 9648 帧），检查通过；事件时间线 81 行和横屏版逐行相同，是同一局。音画同步中位数 16.5 毫秒。唯一一对完全相同的相邻帧在开头的戏票页，那里本来几乎静止，相邻帧常常只差两三个像素。
- 色彩：ffmpeg 9 会把 JPEG 的全范围原样带进 H.264，只写 `-pix_fmt yuv420p` 拦不住，输出标签读回 `yuvj420p` / `pc` / `bt470bg`。脚本改成显式转换并加 `accurate_rnd`：同一帧用无损编码对照，平均偏差 R/G/B 为 −0.23 / −0.51 / −0.08 级；不加 `accurate_rnd` 时红、蓝两个通道系统性偏暗约 2 级。
