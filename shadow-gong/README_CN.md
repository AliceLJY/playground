# 灯影守夜

散场后的皮影戏幕上，举着小铜锣的皮影小人「铜锣仔」守住幕后那盏油灯。扑灯蛾、剪刀精、偷油鼠王轮番上幕：对手的兵器一透光变亮，就按一下格挡。卡准了，铜锣「锵」一响，油灯猛地一跳，时间慢下半拍，对手露出空当；攒满它的架势，再上前处决。

**[在线游玩](https://aliceljy.github.io/playground/shadow-gong/)**

一局四场：扑灯、咔嚓、灯下乱、鼠王，三五分钟打完。场间回一点灯油；输在鼠王那里可以从鼠王重来。

## 操作

- 格挡：K、空格或鼠标右键。算的是按下那一刻：看见白光再按一下。一直按住只算普通格挡，连按会把判定窗口越按越窄。
- 攻击、处决：J 或鼠标左键。对手被打开时才打得进去，也就是弹反后的第一槌、它晕住或后仰时、它出完最后一招的收招里。别的时候蛾子会闪开，剪刀和鼠王会用刃面把槌挡开。
- 闪避：L 或 Shift。红光的招挡不住，只能闪。
- 走位：A、D 或方向键。Esc 暂停。
- 触屏：左下 ◀ ▶，右下「锣」「槌」「闪」，横屏更好玩。

## 怎么做的

- 一页规格在 [SPEC.md](SPEC.md)：配色数值、构图规则、性能预算和十条验收。
- 战斗逻辑在 `src/core.js`，不碰渲染，可以在 node 里跑。测试覆盖弹反窗口、预警提前量、同时出手上限和整局时长；构图测试用真实对局里的皮影骨架和游戏自己的机位函数，量剪影大小和预警时的出招位置。
- 皮影每一节都是铰接的平面，用 canvas 程序化画出镂空纹样；声音全部用 WebAudio 现场合成，没有图片、字体、音频文件。
- 固定机位：`?view=hero`、`?view=wide`、`?view=stress`，加 `&plain=1` 看普通格挡对照；调试钩子是 `window.__duel`。

## 本地运行

```bash
cd shadow-gong && python3 -m http.server 8917
```

打开 `http://127.0.0.1:8917/`。测试：`node --test tests/*.test.cjs`。打成单文件：`python3 build.py`。

## 来源

弹反机制的思路借鉴自 [长风 Long Wind](https://github.com/jbang2004/long-wind)：按下时间戳判弹反，出招前预警并按模拟秒对齐，用攻击令牌限制同时出手，架势与处决，顿帧加慢动作。题材、人物、场景、界面、代码、造型和声音都是这里原创的，没有复制长风的源码，也没有用它的任何资产。
