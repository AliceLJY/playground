# 刀马旦精灵

[English](README.md) · **在线看：https://aliceljy.github.io/playground/daomadan-sprite/**

一张粤剧刀马旦原画，用 AI 变出待机、走、出枪、跳、受击五个游戏动作，最后放到舞台上试玩。放在首页「AI 幕后」那一排：讲的是一张原画怎么变成整套动作，不是一个完整的游戏。

## 规格

- **体验一句话**：访客从上往下看三段——原画怎么定、每个动作怎么来、放进舞台试一下；舞台上方向键走、出枪、跳，一分钟内就能看明白「一张画变出一套动作」。
- **主美学**：表达（看 AI 怎么做出来）为主，感官（戏服与动作好看）为辅。
- **场地**：手机竖屏为主，多半静音，单手点按钮；电脑上用键盘。停留两三分钟。
- **形态**：弧型，看一遍就够，不验通关率。
- **配色**（sRGB）：亮色底 `#f7f1ec`、卡片 `#fffaf6`、强调粉 `#c2416b`（选定标签、步骤序号）；暗色底 `#1b1a20`、强调 `#f07ea3`。舞台天空 `#f8dccb → #eab8a3`，地面 `#7a4a3a → #5a3428`，角色脚底踩在 `y = 380 / 420`。
- **构图**：舞台 960×420，角色约 256 像素高（舞台高的 60%），出生在 `x = 300`，左右各留 90 像素不出画；动作小窗里角色按格子等比缩放、底边留 8 像素。
- **性能预算**：图集五张 WebP 共约 4.9MB、原画三张约 0.14MB；Canvas 2D 每帧画 6 张图（舞台 1 + 小窗 5），目标手机 Chrome 60 帧（未在真机测过）。

### 机位

- `?view=stills`：滚到原画三选一
- `?view=actions`：滚到五个动作
- `?view=stage`：滚到试玩舞台

钩子 `window.__PLAYTEST__`：`ready`、`snapshot()`（状态、帧号、位置、朝向、各动作播放次数）、`reset()`、`step(ms)`、`trigger(动作)`。

## 怎么做的

1. 原画：Codex 生图，绿底 1024×1024。第一版大红配满身金线、绣龙，像男将大靠；按戏服资料（女靠一般只有粉红、大红、淡湖几色，绣花卉和凤凰）改成粉红与淡湖两版，淡湖的淡蓝离绿底太近，选了粉红。
2. 动作：[agent-sprite-forge](https://github.com/0x0funky/agent-sprite-forge)（MIT，用的是 `5324342`）的 `video2dsprite`，每个动作从同一张原画出发，走本机 Grok CLI 图生视频；它自动挑掉转身、换色、首尾接不上的，再抠图、对位、挑循环、把单次动作压到游戏时长、打包图集。一共拍了 16 段。
3. 人工看过每个动作的分帧图：跳的第四段连跳两下，只截第一跳；受击后半段身子转正，只留前半段。
4. 这一页：五张 PNG 图集转成 WebP（质量 90），Canvas 2D 按 `src/clips.js` 的格子逐帧画。

## 已知不足

- **跑没有自己的帧**。六段跑步视频画面都能看，但靠旗、飘带、翎子一直在飘，盖过了腿的节奏，工具找不到能接成循环的一段（最好的一段差 1 个百分点）。舞台上用走路帧 2.2 倍速代替。
- 出枪和跳两段的抠图边缘各有约 1.2% 的绿边残留（工具限值 1%），打包时带了放行记录。
- 没在真手机上试过，只在桌面 Chromium 模拟了两种手机视口。

## 重新生成

`src/clips.js` 由 agent-sprite-forge 打包出的五份 `animation.json` 汇总而来，`assets/*.webp` 由对应的 `*-atlas-00.png` 转换。原始工程在作者机器外接盘上，没有进仓。

## 本地运行

```bash
cd daomadan-sprite && python3 -m http.server 8790
node --test tests/*.test.cjs
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs http://127.0.0.1:8790/ shots
```

角色与画面由 AI 生成。
