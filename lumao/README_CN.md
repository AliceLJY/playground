# 撸猫撸了一手毛

[English version](README.md)

一只橘猫侧身站在你面前。沿着它的背从头往尾巴撸，被撸过的那一道毛贴平、泛起光，撸几下它就闭上眼、抬起下巴打呼噜，尾巴竖得笔直、尖端直抖；撸到尾根，它会把屁股翘起来迎你的手。往回撸是逆毛，那片毛一簇簇炸开，背上的皮一阵阵抽，它转过脸来盯着你。一直撸不停，它会压耳朵、伏低身子、甩尾巴，再不停手就张嘴朝你的手指探过来咬一口，咬完舔舔鼻子。每撸一下都有几根毛粘到手上飘起来，落进左上角那只手里，手越撸越毛，最后变成一只毛手套。点一下手，拍拍手把毛抖掉，它会被拍手声吓得原地一蹦。

几个玩法上的细节：

- **撸过的地方留着**：顺毛撸出来的那道光、逆毛撸出来的那片乱，都留在它背上，过二三十秒才慢慢松回去。
- **手停毛停**：手指按住不动，毛不会接着变。手底下那一小片会被压下去，手走过去以后弹两下。
- **慢慢撸也行**：舒服只在你停手以后才慢慢消退，一下两秒的慢撸照样能撸到它打呼噜。
- **咬之前一定有警告**：压耳朵、伏低、甩尾巴、瞪着你，旁边冒「……」。这时停手三秒，它就不咬了。
- 键盘：空格或右方向键顺毛撸一下，左方向键逆毛撸一下，C 拍手。

手机竖屏、单手横着划、静音也看得懂。呼噜声、撸毛的沙沙声、拍手声都是代码现场合成的，没有录音文件；安卓手机上打呼噜时会轻轻震。

## 怎么做的

猫是一张侧身全身图拆成的几层：身子、尾巴、五个表情的头（眯眼、正脸看你、压耳朵瞪人、张嘴咬、舔鼻子）。一个片元着色器一遍画完：身子会拱背、下陷、翘屁股、伏低、跳起、呼吸，爪子始终踩在地上；尾巴绕尾根转；头绕脖子转、在两个表情之间渐变。各层在自己的范围里「替换」身体而不是叠上去，所以不动的时候画面就是原图，没有接缝。

毛和[手撕日历](../tear-calendar/)同一套手感做法，借自 [Filament 织物实验室](https://play.liyue.io/filament/)：

1. **毛的状态画进一张图，不一根根算毛。** 猫背上铺一张 56×100 的图，记毛朝哪倒、乱不乱、还剩多少浮毛。手指移动时只改手底下一小圈，顺毛把乱度往下压、逆毛往上推，再从浮毛里取走一点放到手上，手上的根数和图上少掉的量严格对得上。没被动过的毛就是原图；哪里被撸得偏离了平时，哪里才长出一根根的毛来。
2. **只让手底下那一小片跟着手动。** 手指身后记着最近几个位置，那附近的毛按阻尼弹簧弯、再弹回来，这部分不写进图里。

整个页面用原生 WebGL 和 Canvas 2D 画，没有第三方库。素材由 `tools/prep_assets.py`（Pillow + numpy）从生成的图里抠出来。

## 本地跑

```bash
cd lumao && python3 -m http.server 8972 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8972/`。测试：`node --test tests/*.test.cjs`。浏览器检查：`NODE_PATH="$(npm root -g)" node tools/browser-check.cjs <输出目录>`。没有构建步骤，发布时原样拷贝 `index.html`、`src/` 和 `assets/`。

固定机位：`?view=hero`（刚打开）、`smooth`（顺毛撸舒服了）、`rump`（翘屁股）、`ruffle`（逆毛炸毛、看你）、`warn`（警告）、`bite`（咬）、`furry`（毛手套）、`clap`（拍掉）。`?q=low` 低画质，`?seed=n` 换一身初始乱毛。规格见 [SPEC.md](SPEC.md)，验证记录见 [VERIFICATION.md](VERIFICATION.md)。

## 谁会点开、AI 素材

- 谁会点开：养过猫、撸过猫、被猫咬过一口还接着撸的人；衣服上永远粘着猫毛的人。
- AI 素材清单：猫的图是 AI 生成的。侧身全身底图由 Codex 照作者家猫的两张照片生成，五个表情由 Grok 在同一张图上只改头生成；照片原图不在仓库和页面里。毛的动态、墙、地板、手和声音都是代码画出、代码合成的。代码由人与 AI 协作完成。
