# 撸猫撸了一手毛

[English version](README.md)

小橘趴在你腿上。顺着毛从头往尾巴撸，被撸过的那一道毛会贴平、发亮，撸几下它就眯起眼、打呼噜、尾巴慢慢摆；往回撸是逆毛，毛一簇簇炸起来，它扭过头来看你。一直撸不停，它会先甩尾巴、压耳朵，再不停手就轻咬一口。每撸一下都有几根毛粘到手上飘起来，落进左上角那只手里，手越撸越毛，最后变成一只毛手套。点一下手，拍拍手把毛抖掉。

几个玩法上的细节：

- **撸过的地方留着**：顺毛撸出来的那道亮、逆毛撸出来的那片乱，都留在它背上，过二三十秒才慢慢松回去。
- **手停毛停**：手指按住不动，毛不会接着变。手底下那一小片会被压平，手走过去以后弹两下。
- **慢慢撸也行**：舒服只在你停手以后才慢慢消退，一下两秒的慢撸照样能撸到它打呼噜。
- **咬之前一定有警告**：尾巴越甩越快、耳朵往后压、盯着你的手，旁边冒「……」。这时停手三秒，它就不咬了。
- 键盘：空格或下方向键顺毛撸一下，上方向键逆毛撸一下，C 拍手。

手机竖屏、单手、静音也看得懂。呼噜声、撸毛的沙沙声、拍手声都是代码现场合成的，没有录音文件；安卓手机上打呼噜时会轻轻震。

## 怎么做的

和[手撕日历](../tear-calendar/)同一套手感做法，借自 [Filament 织物实验室](https://play.liyue.io/filament/)：

1. **毛的状态画进一张图，不一根根算毛。** 猫背上铺一张 56×100 的图，每格记毛朝哪倒、乱不乱、还剩多少浮毛。手指移动时只改手底下一小圈，顺毛把乱度往下压、逆毛往上推，再从浮毛里取走一点放到手上。手上的根数和图上少掉的量严格对得上。
2. **只让手底下那一小片跟着手动。** 手指身后记着最近几个位置，那附近的毛按阻尼弹簧往手走的方向弯、再弹回来，这部分不写进图里。

毛本身是在片元着色器里一遍画出来的壳层：每个像素从毛尖往毛根逐层找自己落在哪根毛上，乱的地方按噪声分成一簇簇、各倒一边。头是单独一块会转的毛球，五官按头的朝向投在球面上。整个页面用原生 WebGL 和 Canvas 2D 画，没有任何第三方库。

## 本地跑

```bash
cd lumao && python3 -m http.server 8972 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8972/`。测试：`node --test tests/*.test.cjs`。浏览器检查：`NODE_PATH="$(npm root -g)" node tools/browser-check.cjs <输出目录>`。没有构建步骤，发布时原样拷贝 `index.html` 和 `src/`。

固定机位：`?view=hero`（刚打开）、`smooth`（顺毛撸舒服了）、`ruffle`（逆毛炸毛、回头）、`warn`（警告）、`bite`（咬）、`furry`（毛手套）、`clap`（拍掉）。`?q=low` 低画质，`?seed=n` 换一身初始乱毛。规格见 [SPEC.md](SPEC.md)，验证记录见 [VERIFICATION.md](VERIFICATION.md)。

## 谁会点开、AI 素材

- 谁会点开：养过猫、撸过猫、被猫咬过一口还接着撸的人；衣服上永远粘着猫毛的人。
- AI 素材清单：没有 AI 生成的图片、模型或声音，猫、毛、毯子和声音全是代码画出、代码合成的；开工前用 AI 生成过一张效果参考图，只用来对照颜色和光感，没有放进页面；代码由人与 AI 协作完成。
