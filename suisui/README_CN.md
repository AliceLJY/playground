# 碎碎平安

[English version](README.md)

一面紫檀博古架做成的展柜，每格顶上一盏射灯，摆着青花梅瓶、青花大盘、汝窑天青盏、琉璃荷叶盏、白玉璧、唐三彩马、紫砂壶、线装古籍、红烛、糖画龙、红鞭炮、宣德炉，还有几张写着烦心事的洒金红纸签。点一下，它按自己的材质碎掉：瓷、玉、琉璃崩成碎片，唐三彩和紫砂塌成沙往下漏，纸签烧成火星，古籍被风吹散，红烛和糖画化掉，鞭炮噼里啪啦炸开，香炉卷成漩涡吸走。碎完的格子过一会儿落下一件新的，可以一直砸。

**[在线玩](https://aliceljy.github.io/playground/suisui/)**

手机竖屏、横屏和电脑都能玩，没有输赢，想砸多久砸多久。

## 怎么玩

- **点一下**：按材质碎，瓷器从你点的位置裂开。
- **按住不放**：格子顶上出现金色蓄力条，东西越来越烫、越抖越厉害，满一秒自己炸开；中途松手就按当时的热度炸。
- **按着划一下**：顺着你的手被甩飞出去。
- **写烦心事**：写十个字以内，写在红纸签上摆上架子，再把它烧掉。
- **全砸了**：整架从左上到右下一波碎完，然后重新补满。
- 右下角可以关声音；右上角记着一共砸了多少件（只存在你自己的浏览器里）。

## 多人房间

打开就进同一个房间：所有人砸的是同一面架子，看得到别人的手指落在哪。同一格有人在砸就排队（「你第 2 位」），轮到你时新东西上亮「轮到你了」，给你 5 秒。便签最多三张，满了进候贴区排队；你候着一张时可以去撕一张别人的，替他烧掉，你的立刻贴上去，他会收到一句「有人替你把『…』烧掉了」。别人的便签你只看得到一张折起来的纸条，字只存在写的人自己的浏览器里，不经过服务器。「全砸了」只砸没人占的格，每人 30 秒冷却。

连不上房间、断线或房间满了（50 人），页面照样能一个人砸，重连上了再回房间。地址后面加 `?solo=1` 就只玩单人版。

## 本地运行

```bash
cd suisui && python3 -m http.server 8971
```

打开 <http://127.0.0.1:8971/>。固定机位：`?view=hero`（开局架子）、`?view=burst`（第一格刚碎开）、`?view=note`（写烦心事的弹窗）。

## 检查

```bash
node --test tests/*.test.cjs                                        # 规则、重复上限、碎法名、粒子预算
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs <输出目录>   # 三种屏幕的真实点、按住、划、写、全砸
```

多人房间：

```bash
node server/room-server.mjs                                         # 本地房间服务，127.0.0.1:8798
NODE_PATH="$(npm root -g)" node tools/room-check.cjs <输出目录>      # 两个浏览器同进一个房间的验收
```

页面加 `?room=ws://127.0.0.1:8798/room/ws` 连本地服务。线上房间是同一个 `server/room.mjs` 跑在 Cloudflare Durable Object 里，地址 `wss://suisui.aliceljy.xyz/room/ws`（发布：`cd worker && npx wrangler@4 deploy`；本地：`npx wrangler@4 dev --port 8799 --var SEED:1`，再带 `ROOM_URL=ws://127.0.0.1:8799/room/ws` 跑 room-check）。规格与验收条目见 [SPEC.md](SPEC.md)。砸起来爽不爽、声音好不好听、震屏会不会晕，要人在手机上试。

## 素材与来源

- 粒子引擎是 [rs-4/dissolve](https://github.com/rs-4/dissolve) 网页版的 Canvas 2D 移植（MIT），原样放在 `vendor/dissolve-atlas.js`，许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
- 架子上的藏品是网页版 ChatGPT 生成的写实棚拍图（不是真实文物的照片），用 `tools/cutout.py` 扣掉黑底切成单件；烦心事纸签是代码画的。
- 声音全部用 Web Audio 当场合成，没有音频文件。
- 「碎碎平安」取的是打碎东西时说的那句吉利话。

## 谁会点开、AI 素材

- 谁会点开：烦的时候想砸点什么、又不想真砸的人；手机上随手点几下就走的人。
- AI 素材清单：架子上 12 件藏品的图片由 ChatGPT 生成；纸签、柜子和界面是代码画的，声音是代码合成的，没有 AI 生成的声音；代码由人与 AI 协作完成。
