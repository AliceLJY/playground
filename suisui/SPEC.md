# 碎碎平安 · 一页规格

## 1. 体验一句话

一面暗色木头博古架，格子里摆着青花盘、梅瓶、玻璃杯、陶罐、蜡烛、气球、乌云和写着烦心事的便签。点一下，它按自己的材质碎掉：瓷器和玻璃崩成碎片，陶罐塌成沙往下漏，便签从边上烧起来变成火星，蜡烛和冰淇淋化掉，气球砰地炸开，乌云卷成漩涡吸走。按住不放会发烫、抖动，蓄满一秒自己炸开；按着往一个方向划，它就顺着你的手被甩飞。碎完的格子过一会儿落下一件新的，可以一直砸。要的感受是**砸东西的痛快**，加一点「碎碎平安」的吉利。

- 主美学：**感官**（每一下的碎法、声音、震动都不一样）为主，**表达**（自己写烦心事贴上去再砸）为辅。
- 场地：手机竖屏单手点为主，电脑鼠标也能玩；多半静音，所以每次碎都有看得见的飘字和震屏，声音只是加分。一次玩一两分钟，没有输赢。
- 循环型，但没有失败和分数压力：验的是「每一下都有反馈、反馈够分量、补货不卡」，不验通关率。

## 2. 东西与碎法（材质决定碎法，不让玩家挑）

| 东西 | 材质 | 点一下 | 飘字 |
|---|---|---|---|
| 青花盘、梅瓶、盖碗 | 瓷 | 从点的位置裂成碎片（shatter） | 碎碎平安 / 岁岁平安 |
| 玻璃杯 | 玻璃 | 碎片更多更细（shatter） | 碎碎平安 |
| 陶罐 | 陶 | 塌成沙往下漏（sand） | 散了 |
| 烦心事便签 | 纸 | 从边上烧成火星（ember） | 烧掉了 |
| 旧报纸团 | 纸 | 被风吹散（dust） | 吹走了 |
| 蜡烛、冰淇淋 | 蜡 / 冰 | 往下融化滴落（melt） | 化了 |
| 气球 | 橡胶 | 从点的位置炸开（snap） | 砰！ |
| 乌云 | 坏心情 | 卷成漩涡吸走（vortex） | 散了 |
| 像素小怪 | 像素 | 方块逐级塌掉（pixel） | 消灭 |

手势对所有东西通用：

- **点**：按下到抬起 < 280 ms、位移 < 18 px，按上表材质碎。
- **按住**：超过 280 ms 不动就进入蓄力（charge），格子顶上出现金色蓄力条、格子里泛起暖光，东西发烫、抖得越来越厉害，满 1 秒自动炸开；没满就松手，就按当时的热度炸开。
- **划**：按下后位移 ≥ 18 px，按抬起前 80 ms 的速度甩飞（fling）。

## 4. 构图

- 架子占可视区宽 92%（电脑上限 980 px），水平居中；顶部留标题与计数一行，底部留操作条一行。
- 列数按宽度：< 560 px 三列，< 900 px 四列，其余五列；行数取能放下的数（三到四行）。
- 东西画在格子里，占格子短边的 74%，底边贴格子底面，带一个接触阴影。
- 光从左上来：东西的高光在左上，阴影向右下。

## 5. 性能预算

- 目标：iPhone Safari、安卓 Chrome、桌面 Chrome；60 fps，单点一下不掉帧。
- 粒子由引擎每次最多 5000 粒；「全砸了」同时在场的粒子总数 ≤ 16000（按每件东西面积 ÷ 粒径² 估算，写成测试）。
- 不加载外部字体与 CDN；页面只请求自己目录下的文件。

## 6. 验收条目

1. 同一个种子，开局架子上的东西完全一样；相邻两格不放同一种东西；同一种东西一架最多两件（便签最多三件），补货 200 次后仍守住。（Node 测试）
2. 每种东西映射到的碎法名都是引擎里真实存在的变体。（Node 测试读引擎源码）
3. 手势分类：点、按住、划三种按第 2 节的阈值判定，边界值两侧都测。（Node 测试）
4. 「全砸了」在三种屏幕的格数下，同场粒子估算 ≤ 16000。（Node 测试）
5. 三种屏幕（iPhone 390×664、安卓 412×700、桌面 1280×720）打开无页面报错、不请求目录外文件，架子上每格都画出了东西（像素非空）。（浏览器检查）
6. 真实点一下：那件东西消失、计数 +1、粒子层有像素、出现飘字；2 秒内格子补上新东西。（浏览器检查）
7. 按住 1.2 秒：进入蓄力并自动炸开，计数 +1。划一下：走甩飞，计数 +1。（浏览器检查）
8. 写一条烦心事：出现在架子上，内容是刚写的字。（浏览器检查）
9. 手机上标题、计数、底部三个按钮都完整在可视区内，彼此不重叠，按钮点击区 ≥ 44 px。（浏览器检查）
10. 与参考并排：拿 dissolve 官网同一种碎法的演示与本页截图并排看，碎片密度和运动不比官网差（人看）。

## 7. 固定机位

- `?view=hero`：开局架子，种子 1。
- `?view=burst`：种子 1，自动点第一格，停在碎开后 260 ms。
- `?view=note`：写烦心事的输入框打开。

试玩钩子：`window.__suisui.probe()` 回报格子、计数、当前在碎的数量；`window.__PLAYTEST__ = { ready, snapshot(), reset(), setSeed(n) }`。

## 8. 没法自动验的

砸起来爽不爽、声音好不好听、震屏会不会晕，要人在手机上试。
