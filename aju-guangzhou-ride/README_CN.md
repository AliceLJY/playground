# 阿橘的广州骑游

通过人与 AI 协作完成的小型浏览器游戏。让小橘猫骑着自行车穿过骑楼、花园和江边，也可以接受三花猫的友好挑战。

[打开试玩](https://aliceljy.github.io/aju-guangzhou-ride/)

## 怎么玩

- 方向键或 WASD 加速、刹车和转向，按住 Shift 或 B 冲刺。手机界面提供对应按钮。
- 自动前行默认开启，自动导航默认关闭。不按方向就保持车头直行。
- 点击小地图，选择西关茶楼、街坊球场或珠江来信，再点击“开启导航去这里”。导航沿相连的道路和园路行驶，到站停车；随时可以关闭。
- 可以进入园路、草地和球场。撞上障碍物会停车，速度较快时会摔倒并自动起来上车；落水会回到岸边。
- 空格按铃，E 在附近停靠，P 或 Escape 暂停，R 回到附近道路。
- 三花挑战可以接受、拒绝或退出；比赛有倒数和五个检查点。
- “拍张照”可以下载 2880 × 2080 的高清明信片。

## 这一版有什么

试玩版 0.1 增加了门楼、戏台、沿街屋顶差异和路口指引。街区地图可以展开、预览路线并选择目的地。地图是艺术化的广州街区，不代表真实道路坐标或实际距离，也没有接入实景地图。

不需要注册、地图密钥或安装软件。刷新会重新开始，下载的明信片可以保留。目前没有多人模式或汽车交通，三花按固定路线行驶，部分建筑细节仍会重复。已验证桌面浏览器和手机尺寸布局，尚未在真实手机或 Safari 上测试。

## 后续更新

建筑和道路可以继续完善。更新提交后会经过自动检查并发布，试玩链接保持不变，刷新页面即可看到新版。技术运行与验证说明见英文自述文件。
