# 首访候场与可选重玩：一杯茶的回礼

本机没有任何有效历史来访时，正常候场直接启用回礼；已有历史则保持原候场。落座、25 秒邀请与递茶规则不改。常驻至少 44px「直接候场」只收起本趟回礼，保留座位、倒计时与来访记录。首次按现有 localStorage 历史判断，读写失败不报错、刷新仍按无历史处理。正常回礼这一趟在离席或幕起时照常写入动作（包括递茶），领位人、纸票不写入历史；若尚未落座或未离席/幕起就刷新，没有历史仍视为首访。

节目单封面仍可点「一杯茶的回礼」进入独立重玩；主目标为无言共在与表达，面向手机静音、单手访问。原入口、五分钟倒计时、声音默认值与难度保持原样。可选趟暂不播放或写入历史来访，已有记录保留；从普通座位切入时先按原离席规则记下当前来访，避免邻座被回放坐满，也不把领位人存成自己的回放。

玩家落座后连续等 **25 秒**，一位灰影来到空邻座，始终标「领位人 · 非真人」，示意要茶；用原「递茶」按钮或键盘 4 递一杯即完成，得到代码绘制的今晚纸票，上盖本次候场的「第几厅／几排几座」小章。约 **30–45 秒**可领到回礼，之后可继续等原五分钟幕起，结尾合影带票，也可随时从节目单返回普通候场。25 秒与 30–45 秒体验目标均**待试玩校准**。

提前递茶无奖励、不扣物品；中途离席撤销本趟回礼、重新计时，可重新落座；不递茶不会自动完成，错过幕起也无惩罚，可在开演层点「再试回礼」或返回普通候场。只需完成一次，不设反应窗和失败惩罚。纸票不持久化，返回或下一趟后清除。纸色沿用 sRGB `#efe6d2`、章色 `#9b2d20`；回礼与合影由 Canvas 绘制，不新增图片素材。触控与键盘共用动作函数，按钮至少 44×44 CSS px。

验收（Node 纯函数 + 浏览器真实输入，截图逐张读图）：

1. 默认首访落座满 25 秒出现非真人领位人并可递茶，完成或跳过的正常来访保存后再访问不自动启用；固定机位及 `?intro=skip` 仍为三灰影、无领位人；普通结尾返回、声音与入口尺寸旧检查全过。
2. 可选趟在落座前及落座不足 25 秒时不能领票；跨种子、全部可选空座至少实际出现一次邻座邀请，25 秒后领位人和玩家座位不同且相邻、不重叠、不计入人数，静音也有常驻邀请。
3. 真实触控与键盘序列「菜单进入→落座→等邀请→递茶」均只发一张票；不操作不会完成；提前操作不发票，离席后计时重置并能重试成功。
4. 合影实际绘出纸票与本次座位章；独立重玩的退出、离席重试、幕起后「等下一场」均清除玩法状态，原历史内容不变，可正常落座与进行原动作。首访正常候场按原规则保存来访，跳过仅取消邀请、不清除本趟。
5. 发布文件在 390×664、320×568、844×340（DPR2）与 1365×900（DPR1）零页面错误；邀请、回礼、合影和返回按钮可读可达，所有新按钮 ≥44×44 CSS px；默认抗锯齿与渲染比例不变。

复现：清空本机历史→无参数入口→落座→等 25 秒→递茶→合影；「i」封面可重试或回普通候场。使用页面时钟推进真实 RAF 走等待，不直接注入回礼状态；结尾检查可用原 `jumpTo()` 加速。自动检查不代替真人手感、真手机和声音试听。

# 画面质感：剧场座椅与点灯亮台（2026-11-11）

从观众席后排看台口：描金台柱与金楣、带金流苏的垂花檐幕、褶子有明暗的丝绒大幕、木纹台板与台唇；台下三排红丝绒剧场椅从背后画，有圆顶椅背、软包分缝、扶手、铜号牌（尺寸够时写几排几座，小屏省略座号），前后排 0.92 / 1 / 1.08 近大远小。空座露出放平的坐垫、不写「空」字；有人坐露出头发、耳朵、脖子与肩背，灰影「身影 · 非真人」只画灰色头肩剪影；自己的座位椅背描金、地上一圈金光、头肩一圈金环。名签贴在椅背下半，最后画，不被后排举手或气泡遮住。

点灯只改呈现，计数、同步与不设上限照旧（舞台最多画十二盏，再点只加计数）：每盏灯是立在台口前沿的红纸灯笼，朝幕布打一道暖光锥，幕上一片光斑、台板一点反光、锥里几粒浮尘。整台亮度 `lit` 以 `min(灯数, 5) / 5` 为目标指数逼近（约 1 秒），0 盏只剩金框轮廓，5 盏满台暖光；幕起时目标为 1。静态幕布、台口和台板烘焙进离屏画布，尺寸变了才重画；Canvas 2D 原路线，不加依赖。

验收：`tools/stage-light-check.cjs` 在 1440×810、1440×1080（DPR1）与 390×664（DPR2），固定 `?view=first&t=6&seed=11&mute=1`、默认 Canvas 2D 路径读真实像素。`__foyer.geometry` 回报真实舞台、幕布、木台板、左右台柱与第一盏灯的光锥/光斑几何，坐标为逻辑 Canvas 像素；检查器按实际画布横纵像素比分别换算、向内取整，空框或出界直接失败，不再推算舞台尺寸。

- 整台分区：幕布左/中/右三等分各内缩取 x 12–88%、y 为幕高 32–68%；木台板取自身 x 15–85%、y 12–48%；左右台柱各取柱宽 20–80%、幕高 35–72%。正常落座、点灯并推进真实模拟，稳定的 0/1/3/5 盏每一区各档 ≥+3、5 比 0 ≥+25，单位为 sRGB 加权亮度 `0.2126R+0.7152G+0.0722B`（0–255）。
- 暖光锥独立验：第一盏完全淡入后冻结时间和总光，暂藏灯笼数组得到参考渲染，再恢复同一盏得到实测渲染；不改总光或时间，左右台柱像素变化须 ≤0.05。取幕高 18–20% 的上段光锥，根据真实光锥边界与光斑半径选两者之间的框，四角都在锥内、都在圆形光斑外；左右锥外各在同高度取同大小框。先对每框扣除参考渲染以消除幕褶和总光，再要求锥内比左右锥外各自亮 ≥4、偏暖 `R−B` 多 ≥3（0–255）。这样删除锥形填充、保留幕上光斑也应失败。
- 总光时间独立验：点第一盏后在 0/120/600/1000/2000/3000 ms 采左右台柱（光锥裁剪区外、远离灯笼光晕）。每柱首末差 ≥3，按各自首末亮度归一化，120 ms 为 10–40%、600 ms 为 60–85%、1000 ms 为 80–96%、2000 ms 为 96–104%；前三段严格上升，其后不下降。对应约一秒完成大半、两秒基本到位；瞬间跳亮、过慢或灯笼自身 0.6 秒淡入均不能替代总光检查。

每档保存原截图、取样框叠图、原始 RGB/亮度/色差、像素框、Canvas 尺寸与横纵比例、时间读数和逐条断言 JSON，派活方逐张读图核对；本轮浏览器阈值尚未实测，不沿用旧均值检查的通过结论。Node 检查只验实际绘制几何与真实总光模拟，不称为像素通过。另与靶子图、改前截图并排对照四项（材质、几何、主角、光）；真人观感、真手机仍未验。
