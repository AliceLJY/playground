# 搭台 · 茶楼早市

广州茶楼早市，位子紧，伙计会把你安排到一张还有空位的桌，和陌生人搭台。各要各的一盅两件，各看各的报纸，不必搭话。能做的只有八件事：落座、斟茶、叩指、揭盖、翻报纸、夹一件、唔该（喊伙计）、离席。桌满了，下一位自动开新桌。

坐下伙计先问「饮乜茶」：普洱、菊普、铁观音、寿眉、香片，茶汤颜色跟着变，壶和大碗一起上桌，头一泡不入口，筷子碗碟在大碗里涮一遍。喊一声「唔该」拿到点心纸：十四样分小点、中点、大点、特点、顶点五档，一次勾三样落单，厨房二三十秒一样样出品端上桌。点心车另算，推到桌边要一笼阿姨就搁下盖印。离席是埋单：茶位加点心按档算钱。

早市会过去：进门是 7 点，五分钟真时间到 11 点收市，窗外的光从斜长的暖黄变成竖直的白。每隔半分钟多点心车推到桌边，三样各剩一两件，桌上别人也伸筷子，你夹不夹、夹哪样是这件玩意里唯一要抢的事。离席给你一张茶单：搭了几位、坐了多久、斟了几巡、夹了哪几件、谢了几次被谢几次，长按能存图。

这是 playground 里第一件「有别人在」的玩意，没有账号、没有聊天框。桌上的别人分三种：**你自己前几次来的回放**（本机记着你最近 12 次坐了多久、什么时候斟过茶叩过指，下次进门它们就坐在桌上，标着「你 · 昨天」「你 · 3 天前」）；**最近来过的别人的回放**（离席时这一市的动作时间线匿名留给后来的人，进门取最近 12 条，标着「有人 · 2 天前」，见下面「跨用户痕迹」）；和**灰色身影**（桌上别人不足两个时补上，标着「常客 · 不是真人」，不计人数）。门口排着等位的几个人也是画出来的，不是真人，伙计每隔一阵领走一位、再来一位。

**[在线玩](https://aliceljy.github.io/playground/datai-teahouse/)**

## 操作

- 进门先站着，顶栏告诉你哪张桌有位；按「落座」或点画面坐下。坐下伙计问饮乜茶，顶栏下出五种茶，拣一种，三秒后壶到。
- 唔该：喊伙计。没拣茶就再问一遍茶；拣了茶就递点心纸——十四样带图和档位价钱，勾满三样「落单」，第一样 18–30 秒出品，之后每样隔 12–25 秒；空笼放六秒伙计来收。
- 斟茶：头一泡洗杯，不算一巡；之后每按一次给全桌斟一巡，壶里的水少一截。桌上的人会回你叩指。
- 叩指：只在有人给你斟了茶的 8 秒内能按（按钮会亮），两根手指在桌上敲两下，是广州茶楼的谢茶礼。
- 揭盖：把壶盖搁在壶口，茶楼叫加水的暗号，几秒后伙计来加满。
- 翻报纸、夹一件：各看各的报纸；夹一件从自己桌上的笼里夹，碟上的点心画得认得出是哪样。桌上没笼就夹不到。
- 点心车：到桌边时顶栏下出现三样和各剩几笼，点一样阿姨就把整笼放到你桌上、点心纸盖印；桌上别人也会要，笼数是真的会少，车停九秒就走。车上只有最常见的八样，另外六样（糯米鸡、萝卜糕、流沙包、牛肉球、春卷、咸水角）得喊伙计下单。
- 早市 7:00 到 11:00（五分钟真时间）。最后一刻钟光变白、鸟笼取下、伙计开始收碟；收市时还坐着就被请离席，茶单上写「坐到收市」。
- 离席：先出埋单（长按存图）——搭了几位、坐了多久、茶位哪种茶、点了哪几笼各什么档、几笼几件、礼数、合计多少钱；点「再开一市」回到门口，大堂按新的历史重排，你会看到「你 · 刚才」坐进去。
- 键盘 1–8 对应八个按钮（7 是唔该、8 是离席），M 静音。手机竖屏为主，电脑也能用。

## 规格

- 体验一句话：进茶楼和陌生人搭一张桌，不说话也不尴尬，用几个茶楼里本来就有的动作把「我在、你也在」做出来。
- 主美学：社交（无言共在）加感官（茶楼早市的光与声）；辅：表达（礼数）。
- 场地：手机竖屏、多半静音、单手，一次三五分钟。所以每个动作都有画面变化，静音也看得懂；所有按钮在 390×664 不滚动可见。
- 循环型，但每一市有头有尾：一市五分钟，收市是终点，茶单是记录；每次来桌上的人都不同（上次的自己在）。验「第二次来有没有看到上次的自己」「桌满会不会开新桌」「点心车上有没有东西可抢」，不套通关率。
- 每 20–40 秒一个小决定：点心车每 30–42 秒一趟、停 9 秒，车上三样各 1–3 笼，桌上别人约六成会在 1.5–6 秒内伸手；一个早市车上一共 24–60 笼。点心纸一次最多三样。壶四巡见底，揭盖 3.5 秒加满。
- 真茶楼里有的、这里也有的：茶位与拣茶、头泡洗杯、点心纸五档盖印、点心车、叩指谢茶、揭盖加水、搭台不搭话、埋单。价钱取 2020 年代中档茶楼的大概数（小点 12 中点 16 大点 20 特点 24 顶点 28，茶位 6），不是哪一家的真价目。
- 分桌四条：每桌四位；新人进最满的未满桌；平手取最小桌号；都满就开最小未用号的新桌；最后一位离席就撤桌。历史幽灵和你走同一套规则，幽灵按它们当年进门的先后落座，再轮到你。
- 配色（sRGB）：木色 `#6b4a2b`、桌布 `#efe6d2`、满洲窗玻璃 `#3f8f7a` `#c7532f` `#d9a441` `#4a6fa5`、蒸笼 `#c9a063`、茶汤 `#b8762a`、你 `#c7532f`、灰影 `#9a948c` 60% 不透明。
- 构图：后墙只占画布上 22%（满洲窗是背景不是戏台，Alice 10-31 试玩后定「桌子大一些」），近桌中心在地板 56% 处、桌面宽到画布 94%、两侧坐的人和标签留 50 px；桌上的壶、杯、笼、点心随桌径等比放大，人物放大一半的幅度；你永远坐前左，其余按桌上顺序排；横屏画布太矮时桌子缩小、前排人物不出画。
- 性能：Canvas 2D，无图片、无字体文件，每帧图元约一百多个。
- 声音：全部 Web Audio 合成，首次触碰后才建；同一音效音高随机 ±6%。斟茶是带通噪声 420→1300 Hz 扫 1.3 秒加一条上升正弦，叩指是两记 1.75 kHz 三角波 70 ms，揭盖是 2.65 kHz 瓷音，翻报是两段高通噪声，环境是粉噪声低通 320 Hz 很轻。

## 跨用户痕迹

每个人的屏幕上永远只有自己那张桌，大堂里的其他桌只看到台号和人头。别人不必此刻在线：离席时把这一市「第几秒做了哪个动作」留下，后来的人进门时按同一套分桌规则把这些痕迹排进大堂，坐到你桌上的就照当时的节奏斟茶、叩指、伸筷子。

- 服务：一个 Cloudflare Worker 加一个 KV（`worker/`）。`POST /trace` 收 `{v:1, dur, acts:[[秒, 动作码], …]}`，上限 2 KB、`dur` ≤ 1800 秒、`acts` ≤ 200 个且时间不倒退、动作码只收玩家能按的八个；服务端按白名单重建对象，多余字段（名字、文字、伪造的时刻）一律丢掉，自己记进门时刻，七天过期。`GET /traces?n=12` 回最近 n 条（最多 12），最新的在前，缓存 30 秒。同一地址每小时最多留 6 次。只放行 `https://aliceljy.github.io`。不提供删单条的接口：没有身份就没法认归属，七天自然过期。
- 页面：`src/game.js` 的 `TRACE_ENDPOINT` 为 `null` 时一切照旧，不发任何请求。填上地址后，进门向服务要最近 12 条，最多等 1.2 秒，等的时候伙计说「人多 · 稍等，帮你揾张位」、落座键灰着，过时就先按本机记录开桌；离席坐满 5 秒以上才上传。自己上传过的那几条服务回了 key，记在本机，拉回来时认出是自己，标「你」不标「有人」。
- 不做的：在线人数、实时位置、任何文字。
- 现状：2026-11-03 已部署在 `https://datai-traces.aliceljy.workers.dev`。**国内直连连不上**（Globalping 三网 8 个探针：7 个 DNS 被污染、1 个连接被拒；海外 4 个探针 200），国内访客进门等满 1.2 秒后只回放本机记录，开着代理或在海外的访客才看得到别人。
- 部署：`bash worker/deploy.sh`（第一次会在浏览器里授权 Cloudflare、建 KV、部署，把地址写进 `worker/.deployed-url`，这个文件不进仓库）；然后把地址填进 `TRACE_ENDPOINT`。

## 固定机位

| URL | 状态 |
|---|---|
| `?view=first` | 没有历史：你一个人开第 1 桌，两个灰影陪坐 |
| `?view=busy` | 注入 6 次合成来访：第 1 桌满，你进第 2 桌（3/4） |
| `?view=full` | 注入 3 次：第 1 桌 4/4，没有灰影 |
| `?view=crowd` | 注入 10 条合成的「别人」：三桌 4/4/3，门口等位三位 |
| `&t=<秒>` | 把时间线推到 t 定格（`t=14` 点心车在桌边；`t=301` 收市出茶单） |
| `&door=1` | 保持站在门口 |
| `&mute=1`、`&seed=<n>` | 静音；灰影日程的种子 |
| `&ask=1`、`&tea=<key>` | 固定机位默认替你拣普洱；`ask=1` 保留「饮乜茶」的问话，`tea=tgy` 换铁观音（puer / jupu / tgy / shoumei / jasmine） |

带 `view` 参数时不读不写 localStorage。钩子：`window.__datai`（`act(code)`、`snapshot()`、`pause()`、`step(ms)`、`chooseTea(key)`、`order([kinds])`）和统一的 `window.__PLAYTEST__`。

## 本地运行

```bash
cd datai-teahouse && python3 -m http.server 8793 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8793/`。测试 `node --test tests/*.test.cjs`；浏览器检查 `NODE_PATH="$(npm root -g)" node tools/browser-check.cjs http://127.0.0.1:8793/ check-out`；开局流程 `node tools/walkthrough.cjs <url> <out>`。没有构建步骤。

## 怎么做的、借了什么

- 分桌规则（满开新桌、进最满的未满桌、平手取最小号、空桌撤）和「没人时放标注过的身影」这两条，是从一座韩国线上寺庙站的做法里抽出来的——夜店宁可塞满一个卡座也不开两个半空的。只取了规则，名字、文案、动词、画面都是茶楼自己的；它要一台常驻服务器，这里一台都不要。
- 「多人感」和「实时同步」是两件事：别人不必此刻在线，你上次留下的痕迹就是别人。先在本机走通，再把痕迹放到一个 Worker 上让后来的人看见（见「跨用户痕迹」）。没选实时：访客少的时候实时多半是空屋，回放总有人坐着。
- 门口等位是画的：真茶楼早市门口总有人拿着筹等位，这里照样有，但不让玩家真的排队，进门最多等远端 1.2 秒。
- 茶楼的礼数都是真的：叩指谢茶、揭盖加水、搭台不搭话、点心车要抢。
- 第二轮试玩反馈：「看不清什么菜」「有没有得喊服务员下单」「越像茶楼的真实情况就越好玩」。于是十四样点心各画各的样子、同一份画法用在车上笼里碟上纸上；加了第八个动作「唔该」喊伙计，坐下先拣茶、头泡洗杯、点心纸五档下单、厨房出品、空笼收碟、埋单算钱。都是真茶楼里本来就有的事，不是另造的玩法。
- 第一版试玩反馈「单调」：七个按钮两分钟按完就没新东西。按 AGENTS.md 的八问对照，缺的是决定、终点和场地的参与，所以补了点心车（反复出现的小决定）、早市的弧（五分钟一市、收市清场）和茶单（这一趟的记录），词汇表没有加按钮。

## 文件

- `index.html`：页面与按钮。
- `src/core.js`：分桌、来访记录与回放、灰影补位、带种子随机；浏览器与 Node 共用。
- `src/game.js`：画面、动作状态机、合成音效、本机存储、固定机位、钩子。
- `tests/core.test.cjs`、`tests/publish.test.cjs`、`tests/traces.test.cjs`：规则、发布扫描、痕迹服务，`node --test tests/*.test.cjs`。
- `worker/`：痕迹服务（`index.js`、`wrangler.toml`、`deploy.sh`）。不随页面发布。
- `tools/traces-check.cjs`：痕迹的浏览器检查，部署前后都能跑。
- `tools/browser-check.cjs`、`tools/walkthrough.cjs`：四视口浏览器检查（含点心车与收市茶单两档）、开局真实输入流程。
