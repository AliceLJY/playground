# 药性配对

药材一味一味从药柜上冒出来往下落：薄荷、生姜、黄连、附子……在它落地前把它分进寒、凉、温、热四个药篓。点篓子，或者按住药材拖进去；连对分数翻倍。分错了，药签会翻过来告诉你它到底是什么性、为什么。一局 75 秒，结尾停在一句大字：四气是药物作用于人体后的反应，不是药材本身的温度。

**[在线游玩](https://aliceljy.github.io/playground/herb-match/)**

手机竖屏、横屏和电脑都能玩。小游戏只为认识四气，不是医疗建议；用药请遵医嘱。

## 操作

- 手机：点下面的药篓，最靠下的那味药就放进去；也可以按住药材拖进篓里。
- 电脑：点篓子或拖药材；键盘 1–4、A S D F 或方向键 ← ↓ ↑ → 对应寒、凉、温、热。空格或回车开始、再来一局。
- 开始页和结算页右上角可以关声音。

## 药材和出处

十六味，每个篓四味；微寒、大寒算寒，微温算温，大热算热。每一味的性味和出处列在 [SPEC.md](SPEC.md) 第 4 节，取自香港理工大学中药数据库，并与《中华人民共和国药典》2020 年版的「性味与归经」对过。薏苡仁和西洋参在不同资料里分别写「凉」和「微寒」，暂时没有放进来。

## 怎么做的

- 一页规格在 [SPEC.md](SPEC.md)：配色、构图范围、规则数值、性能预算和十条验收。
- 规则在 `src/core.js`，不碰画面，可以在 node 里跑；测试用真实对局量同屏数量、药材互不重叠、药签不盖药材、四档打法（不操作、精准、真人、手抖）的时长和正确率。
- 画面是二维画布，药材在 `src/herbs.js` 里用代码画：薄荷、生姜、菊花移植自短片《中药定义接龙》的 SVG，其余十三味照同一套扁平画法补画。声音用 WebAudio 现场合成。
- 固定机位：`?view=hero`、`?view=flip`、`?view=stress`、`?view=result`，药材一览 `?view=sheet`；调试钩子是 `window.__herb`。

## 本地运行

```bash
cd herb-match && python3 -m http.server 8941
```

打开 `http://127.0.0.1:8941/`。测试：`node --test tests/*.test.cjs`。没有构建步骤，发布时原样拷贝 `index.html` 和 `src/`。
