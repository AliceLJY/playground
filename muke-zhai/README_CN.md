# 穆柯寨 · 不打不相识

[English](README.md)

京剧《穆柯寨》里的一段：穆桂英先打退孟良，再和杨宗保对枪，打着打着不打了。做成一个两三分钟的横版小游戏，调子是甜的，没有人倒地。

## 规格

- **体验一句话**：玩家扮穆桂英，看对方出招前的预警，架开、闪开、抓收招的空当刺回去；第一场打掉孟良三格金盔，第二场把杨宗保的「心动」攒到满，两人并肩亮相。核心操作是「看预警，选架、闪还是等」。
- **主美学**：叙事（一段戏从开场走到结尾）为主，感官（夜戏台的光、动作和锣板的节奏）为辅。
- **场地**：手机竖屏为主（单手拇指，多半静音），电脑用键盘；一局两到三分钟。
- **形态**：弧型。只走一遍，验陌生人第一次能不能走完、能不能复述发生了什么；另用自动驾驶验时长与难度两侧。
- **配色**（sRGB）：三族。暗部靛蓝到蓝紫（夜空 `#1b1a3a` 一带）；压暗的朱红与旧木褐（后幕、地板）；灯笼暖琥珀（`#ffaa50` 一带）是唯一的亮色。界面金色 `#c9a45c`、字幕纸色 `#e4d3ae`、心动条渐变 `#6e1f28 → #d79078`；不用纯黑、纯白、纯红。
- **构图**：画布 960×540 逻辑像素，整体缩放适配；角色脚底踩在 y = 448（占高 83%），穆桂英盔顶到靴底约 250 px（占画面高 46%）；底图 `assets/stage.webp`（1920×1080）铺满，台口、两侧门帘、五盏灯笼在底图上；手机竖屏取一个约 4:5 的取景窗（逻辑 400×540，高度铺满横梁到台口），水平跟着两人中点平滑移动、到底图边缘钳住，主角在屏幕上约 270 CSS 像素高；横屏和桌面保持整幅。光从上方灯笼来。
- **画面方向**：见 `ART.md`。精灵每帧压夜色（只用正片叠底 `rgb(196,182,224)`，灯间再按离灯远近叠暗）、降饱和 0.9 并略加对比、上缘一圈窄暖色边光；对手预警时轮廓快闪两下、兵器上一点高光（不动透明度）、三层接触影加地板倒影，结果缓存到离屏画布；前景有暗角、颗粒、浮尘和很暗的台口虚影。
- **性能预算**：目标手机 Chrome / Safari，60 帧；每帧一次底图、两个角色、至多几个特效，离屏缓存按帧懒生成，内存随看到的帧增长（实测未在真机量）。
- **背景可替换**：`src/backdrop.js` 独立，换底图只改这一个文件和 `assets/stage.webp`。

### 操作

键盘：← → 或 A D 走；J 出枪；K 架枪（按住是挡，对方命中前 0.2 秒内按下算「架开」）；L 或空格翻身闪避（中间一段无敌，能打断自己的出招）。触屏：左下两个方向键，右下闪、架、刺三个键。右上角一个静音键，第一次点按后才出声。

### 机位

- `?view=meng`：第一场，孟良预警（身体闪一下、地面一道提示）。
- `?view=duel`：第二场，两人相距约 200 px 对峙。
- `?view=end`：结尾并肩亮相、飘心形、出字幕。
- `?stage=2`：直接进第二场。`?seed=N` 换种子。

定格状态都由真实模拟推进得到（自动驾驶或按键推进），不手摆。钩子 `window.__PLAYTEST__ = { ready, snapshot(), reset(), setSeed(n), step(ms), press(键名) }`，另有 `play()`、`coverage()`、`luma()`。

## 怎么做的

- 逻辑全在 `src/core.js`：固定步长 60 Hz、带种子的随机数、不碰 DOM，可在 Node 里无头跑整局；自动驾驶（精准、手抖、莽撞）也在里面，定格机位和测试共用。
- 手感：出手吸附（转向最近的对手、小滑步到够得着）、命中双方各自顿帧（轻 70 毫秒、重 110 毫秒，其余照常）、顿帧期间输入缓冲、火花出在接触点并顺着枪的方向飞、震屏按创伤值平方。
- 玩法：第一场孟良有三格金盔，出斧前约 0.6 秒预警，他收招硬直或被架开后打中掉一格；第二场没有血条，「心动」0–100：架开 +12、挡下 +6、他收招时打中 +8、对枪 +15、他架枪时打中 +3（每次架枪只算一次）。气 5 格，掉光出「再来」，重打当前这一场。
- 声音：WebAudio 合成板、小锣、脆响、大锣，音高随机偏 ±6%（带种子），第一次点按后才出声。

## 已知不足

- 手感、听感没有人试过，数值（预警、反应窗、冷却）按自动驾驶调到合理区间，真人未必合适。
- 素材瑕疵：孟良的走路步子很大；穆桂英胜利动作第 4、5 帧之间有跳接；抠像边缘可能有残留。
- 没在真手机上测过，只在桌面 Chromium 里模拟了 390×664；声音没验。
- 一次只有一个对手；背景是静态底图加后期，灯笼只有明暗呼吸。
