# 穆柯寨 · 不打不相识

[English](README.md)

京剧《穆柯寨》里的一段：穆桂英先打退孟良，再和杨宗保对枪，打着打着不打了。做成一个两三分钟的横版小游戏，调子是甜的，没有人倒地。

## 规格

- **体验一句话**：玩家扮穆桂英，看对方出招前的预警，架开、闪开、抓收招的空当刺回去；第一场打掉孟良三格金盔，第二场把杨宗保的「心动」攒到满，两人并肩亮相。核心操作是「看预警，选架、闪还是等」。
- **主美学**：叙事（一段戏从开场走到结尾）为主，感官（夜戏台的光、动作和锣板的节奏）为辅。
- **场地**：手机竖屏为主（单手拇指，多半静音），电脑用键盘；一局两到三分钟。
- **形态**：弧型。只走一遍，验陌生人第一次能不能走完、能不能复述发生了什么；另用自动驾驶验时长与难度两侧。
- **配色**（sRGB）：三族。暗部靛蓝到蓝紫（夜空 `#1b1a3a` 一带）；压暗的朱红与旧木褐（后幕、地板）；灯笼暖琥珀（`#ffaa50` 一带）是唯一的亮色。界面金色 `#c9a45c`、字幕纸色 `#e4d3ae`、心动条渐变 `#6e1f28 → #d79078`；不用纯黑、纯白、纯红。
- **构图**：画布 960×540 逻辑像素，整体缩放适配；角色脚底踩在 y = 448（占高 83%），穆桂英盔顶到靴底约 250 px（占画面高 46%）；底图 `assets/stage.webp`（1920×1080）铺满，台口、两侧门帘、五盏灯笼在底图上；手机竖屏取一个约 4:5 的取景窗（逻辑 400×540，高度铺满横梁到台口），水平跟着两人中点平滑移动、到底图边缘钳住，主角在屏幕上约 270 CSS 像素高；横屏和桌面保持整幅。光从上方灯笼来。
- **画面方向**：见 `ART.md`。精灵每帧压夜色（只用正片叠底 `rgb(196,182,224)`，灯间再按离灯远近叠暗）、降饱和 0.9 并略加对比、上缘一圈窄暖色边光；对手预警时轮廓快闪两下、兵器上一点高光（不动透明度）、三层接触影加地板倒影，结果缓存到离屏画布；前景有暗角、颗粒、浮尘和很暗的台口虚影。
- **性能预算**：目标手机 Chrome / Safari，60 帧；每帧一次底图、两个角色、至多几个特效，离屏缓存按帧懒生成，内存随看到的帧增长（实测未在真机量）。
- **背景可替换**：`src/backdrop.js` 独立，换底图只改这一个文件和 `assets/stage.webp`。

### 操作与招式


键盘：← → 或 A D 走；J 出枪；K 架枪（按住是挡，对方命中前 0.2 秒内按下算「架开」）；L 或空格翻身闪避（中间一段无敌，能打断自己的出招）。触屏：左下两个方向键，右下闪、架、刺三个键。右上角一个静音键，第一次点按后才出声。屏幕底部常驻六个键（◀ ▶ 闪 架 刺 绝），桌面上每个键下面画着对应的键帽（← → / L·空格 / K / J / K+J），可以直接用鼠标点，按键盘时对应的键会亮一下；手机上键帽隐藏。

| 招式 | 按键 | 数值（实测于 `tests/combo.test.cjs`） |
|---|---|---|
| 刺 | J | 出枪动画 1.1 倍速；命中顿帧 70 ms、击退 0.3；打在收招硬直或架开之后直接掉一整顶金盔，其余命中松一格（松满三格掉一顶，两次松动至少隔 2.2 秒）；第二场普通命中 +3 心动（至少隔 2.4 秒），硬直里 +8 |
| 三连刺 | J J J | 后两下在上一枪的后半段按（有输入缓冲）。第 2 枪 1.25 倍速、顿帧 60 ms；第 3 枪 0.85 倍速蓄势，顿帧 130 ms、击退 0.62（约普通的 2 倍）、震屏 0.6。第 3 枪松动 1 格、第二场 +6 |
| 冲刺突刺 | 按住 ← 或 → 跑起来超过 0.35 秒再按 J；或 0.25 秒内同方向连点两下再 J；刚起步、贴身（相距不到 120）是普通刺 | 滑步最多 230 px（普通 110），不出舞台；顿帧 100 ms、击退 0.55，收招多锁 0.22 秒；第二场 +5 |
| 翻身刺 | L 的后半段按 J | 落地时（闪的 85% 处）接一枪，此时无敌已过；顿帧 90 ms、击退 0.4；第二场 +5 |
| 大招 | 势满后 K 与 J 在 0.08 秒内一起按；或点第六个键「绝」 | 全场放慢到 0.35 倍约 0.4 秒，镜头推近 10%，连刺五枪（间隔 150 ms，带三层残影），最后一枪顿帧 250 ms、大锣、对方大退（击退 0.85）；她全程无敌，不可格挡。对孟良：掉一整顶并长硬直；对杨宗保：+25 心动 |

**势**：左上角「气」下面的细条。普通命中 +5～6，重招 +8～10，硬直里 +12，架开 +15，对枪 +20，挡下 +4，被打中不掉。放出大招清零。第一次满时出一句「势满了。同时按『架』和『刺』」（桌面写 K 和 J），「架」「刺」两个键一起亮，两键之间出一条连线；放出一次后不再出。

**杨宗保的三连刺**：偶尔（约 14%）用同样的三连刺回敬，预警比平常长（560 ms），每一枪的反应窗都不少于 450 ms，三枪可以逐一架开，全架开额外 +20 心动。孟良被重招打中后有 0.7 秒霸体，然后立刻还手；被打中后每 1.4 秒最多晃一次，所以乱按不会把他一直打晕。

### 蓄力条、杨宗保、两位主角

- **蓄力条**：对手出招的预警期，头顶（孟良在金盔下面、杨宗保在头上）出一条细条，从预警开始匀速走满，走满的那一刻招式落下；最后 0.2 秒（架开判定窗）是更亮的暖色，条头走进这一段时条身轻轻一亮。三连回敬时每一枪各走一条，条下三个小点标第几枪。按住「架」时她身上有一道很淡的暖色护光加脚下一圈细环，松手就没有；在亮段里按下时，条头处有个小的确认闪光，再接原来的架开反馈。亮段按下 = 架开，早于亮段按下 = 挡下。
- **杨宗保从第一场就在场**：开场穆桂英在左、孟良居中、杨宗保站在右侧门边（画得略小 6%、略暗，离台口远一点），用 idle。他不参战、不被打到、不参与碰撞结算；她架开或放大招时他微微后仰（hurt 前三帧）或握枪一架（guard），孟良每掉一顶盔他往前迈半步，打到右半场时他让进门帘里一点。第一场「心动」条就在：每次架开 +4、三连第三枪 +3、大招 +5，第一场最多 20，他有反应时一个小暖光点飘向条；第二场从这个数接着涨。
- **转场不黑场**：孟良丢盔后走进右门，杨宗保走上前站到对面，再说他的台词；结尾并肩亮相时孟良从右门帘后探半个身子（暗一些）。
- **身体有体积**：两人身体圆半径约 42（间距不小于 84），互相推开；大招起手前先把间距修到不小于 130，冲刺和大招停在「刚好够得着」的距离（间距不小于 105）。
- **受击不整身变白**：被打中只在受击那一侧闪一道窄亮边（约 60 毫秒）加身体抖动，任何状态下角色都不变半透明或整体发白（浏览器检查对比有无闪光的渲染，变化像素 < 6%）。
- **手机竖屏取景**：取景窗 400 宽，跟着两人中点走；第一场两人打到右半场时往右偏最多 120，把杨宗保带进画面，但不会把穆桂英或孟良挤出画面（两人都要留在窗里），所以两人在左半场时杨宗保不在画面里。

### 教学、示范、招式页

- 第一次进游戏默认走教学（`localStorage` 记住，`?tutorial=0` 关、`?tutorial=1` 强制开；机位默认不出）：走 → 刺 → 架（孟良放慢到 0.35 倍举斧；字幕随状态走：「他举斧了，看他头上的条」→ 条走到一半「条走到亮的那一段时，按住 K（『架』）」→ 亮段里按住后「架住了」→ 架开后换下一句；按得太早算挡下，字幕「挡住了。等条走到亮段再按，能把他弹开」然后再练一次；这一步必须真的架开一次才过，不按就挨这一下、不掉气，三次后在亮段里自动替她架一次）→ 趁他愣住刺（硬直加长到 1.2 秒，掉第一顶金盔）→ 闪 → 连按三下刺，然后「就是这样。把剩下两顶金盔打下来。」。每步只教一件事，做对了才进下一步；右上角有「跳过」。教学里亮的是该按的那个键（暖色缓慢呼吸的亮边）。
- 教学过后右上角有「教学」「招式」「看示范」。「看示范」由独立的一局（精准档自动驾驶）演约 15 秒：连招、冲刺、架开、闪开接翻身刺、大招，下方的键随它的操作亮起，每次出一个短词（架、刺、闪、绝）；点任意位置或按任意键回到自己的局，不改她的进度。大招前把势直接填满，因为那是演示。「招式」页列出每一招的按键和一句话效果。
- 第二场开头补一句提示：「两枪同时出手会撞在一起，那也算数。」停 3 秒。

### 机位

- `?view=meng`：第一场，孟良预警（身体闪一下、地面一道提示）。
- `?view=duel`：第二场，两人相距约 200 px 对峙。
- `?view=end`：结尾并肩亮相、飘心形、出字幕。
- `?view=open`：开场第一帧，三个人都在台上。`?view=act1`：第一场中段，孟良在出斧、杨宗保在门边。
- `?view=teach3`：教学第三步，孟良慢慢举斧、蓄力条走到一半、「架」在亮。
- `?view=demo`：示范进行中（定格在她按下「架」之后）。
- `?view=ult`：大招第三枪。`?view=chain3`：三连刺第三枪命中。
- `?stage=2`：直接进第二场。`?seed=N` 换种子。

定格状态都由真实模拟推进得到（自动驾驶或按键推进），不手摆。钩子 `window.__PLAYTEST__ = { ready, snapshot(), reset(), setSeed(n), step(ms), press(键名) }`，另有 `play()`、`coverage()`、`luma()`。

## 怎么做的

- 逻辑全在 `src/core.js`：固定步长 60 Hz、带种子的随机数、不碰 DOM，可在 Node 里无头跑整局；自动驾驶（精准、手抖、莽撞）也在里面，定格机位和测试共用。
- 手感：出手吸附（转向最近的对手、小滑步到够得着）、命中双方各自顿帧（轻 70 毫秒、重 110 毫秒，其余照常）、顿帧期间输入缓冲、火花出在接触点并顺着枪的方向飞、震屏按创伤值平方。
- 玩法：第一场孟良有三格金盔，出斧前约 0.6 秒预警，他收招硬直或被架开后打中掉一格；第二场没有血条，「心动」0–100：架开 +12、挡下 +6、他收招时打中 +8、对枪 +15、他架枪时打中 +3（每次架枪只算一次）。气 5 格，掉光出「再来」，重打当前这一场。
- 声音：WebAudio 合成板、小锣、脆响、大锣，音高随机偏 ±6%（带种子），第一次点按后才出声。

## 已知不足

- 手感、听感没有人试过，数值（预警、反应窗、冷却）按自动驾驶调到合理区间，真人未必合适。
- 素材瑕疵：孟良的走路步子很大；穆桂英胜利动作第 4、5 帧之间有跳接；抠像边缘可能有残留。
- 没在真手机上测过，只在桌面 Chromium 里模拟了 390×664；声音没验。
- 一次只有一个对手；背景是静态底图加后期，灯笼只有明暗呼吸。
