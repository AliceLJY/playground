# 浮空之城

一座停在云海上方的小城：象牙色石墙、金线青铜穹顶、四座卫星岛、凌空的桥，以及末端化成水雾的瀑布。转动它、拨动昼夜，或者搭上巡航的铜色飞艇。

所有东西由 JavaScript 生成。城市有 463,099 个实体体素，飞艇另有 15,371 个，旗帜另有 84 个。先剔除相邻体素内部面，再合并为少量带顶点色的网格；局部邻接遮蔽在生成时烘入顶点颜色。页面不下载模型、纹理、字体或声音。

## 本地运行与检查

```sh
npm install
node tools/build.mjs
node --test tests/*.test.cjs
node tools/browser-check.cjs
```

直接打开 `dist/index.html` 即可游览，Three.js 和程序都在单个文件里。浏览器检查使用本机 Playwright 和 Chrome；若普通模块路径找不到 Playwright，会查 `/opt/homebrew/lib/node_modules`。截图、性能读数、交互结果和开场操作录像保存在 `shots/`。

检查未打包的源码入口：

```sh
node tools/serve.cjs . 8947
# 另一个终端：
node tools/browser-check.cjs http://127.0.0.1:8947/dev.html shots/source
```

检查器可接收 `[基准地址] [输出目录]`，支持网站子目录。成品页面没有外部请求。本任务没有接入仓库首页或 CI，也没有发布。

## 怎么玩

- 拖动旋转，滚轮或双指捏合缩放，右键拖动或双指移动平移。镜头距离和平移目标均有限制。
- 一碰场景就交还控制；正常入口停止操作十二秒后，恢复缓慢环绕。
- 点击飞艇进入跟拍；再点飞艇或「返回自由视角」离开。
- 点击场景地标或下方同名按钮，飞近并读一句说明。
- 时间滑块可连续过渡，也能直接选黎明、正午、黄昏、深夜。暂停会停下水流、云、旗帜和飞艇，镜头仍可操作。

`?view=hero`、`?view=wide`、`?view=night` 使用固定种子 731，在动画 12 秒时定格，沿用正常渲染路径与自适应画质。点击「继续流动」可恢复动画。夜景是建筑近景，允许部分远岛与根须在画面外；全岛完整轮廓见 hero 和 wide。

`?palette=c` 为默认「碧空琥珀」，`?palette=a` 切暖金黄昏，`?palette=b` 切清透晴空。每套均包含四时段连续过渡，参数不进入玩家界面。运行 `node tools/palette-shots.cjs` 重出六宫格与四时段图；像素回归需先执行上面的构建，使用真实城市遮罩与背景渲染，定义见 SPEC A11。

## 性能安排

可见页面主动限到 30 帧，桌面像素比最多 1.5，手机最多 1.25，横屏触屏设备同样封顶。连续超时才降低分辨率，带冷却时间与慢速恢复。页面进入后台或画布离开视口就取消渲染循环；暂停时以 10 帧维持镜头阻尼。2048² 日光阴影首次计算后缓存，改变时间时最多每秒更新两次。窗灯共用发光材质，只有两盏不投影的局部真光。

黄昏常规帧实测 13 次绘制、299,370 个三角形，更新阴影时 14 次；深夜增加星空后常规 14 次、更新阴影时 15 次。三角形峰值 575,354。烟、水花和水雾合计 348 粒子，另有 86 个解析云精灵与 500 个静态星点；云与水雾合并提交，抵消天空渐变的一次绘制。没有全屏后期，也没有每帧重建几何。没有测量机身温度，不能据此承诺任何设备都不发热。

统一钩子 `window.__PLAYTEST__` 提供就绪、快照、重置、重生成种子与推进时间。快照含真实 draw calls、三角形、GPU 字符串、像素比、画质和 JS 更新与提交耗时；额外诊断仅在 `?debug=1` 开启。规格与证据见 [SPEC.md](SPEC.md)、[VERIFICATION.md](VERIFICATION.md)。Three.js 固定为 0.186.1，其 MIT 许可保留在生成页面内。
