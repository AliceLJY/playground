# 方块侏罗纪 / Dino Craft

在无边的史前群岛采集、搭窝，用预热的加特林逼退霸王龙，带着头灯守过第一夜。主美学：探索、挑战。循环型沙盒；电脑双手、手机双拇指，静音可辨全部威胁，一次 3–6 分钟。目标是首夜存活，之后可以继续远行建造。

## 画面与场地

- 参考：`shots/reference.jpg` 左中案例4；只参考视觉和评测，不取代码。提高植物轮廓、恐龙关节/牙齿/尾巴和手持枪的层次，避免参考中的边界断层。
- 唯一默认为晴朗正午的侏罗纪岛。所有基色均为 sRGB HEX，Three.js 在线性空间计算光照，ACES 曝光 1.1，输出 sRGB。完整基色和纹理变化幅度见下文。
- 第一人称机位高 1.65 格，垂直 FOV 68°；枪在右下，可见包围框桌面宽 20–35%、手机宽 25–45%，高 20–32%（固定 hero 帧，手臂允许裁到屏幕外）；准星居中、血量在左上。近地层、树冠、山脊/天空分三层，地平线约 35–55%。16×16 像素草土、石层、树皮及年轮图集，无导入贴图/模型。
- 区块 16×16×48；横向无预设边界。大陆、沙滩、水、岩、铁矿和琥珀由种子定义，修改独立保存于本次会话。无磁盘存档是明确的 MVP 边界。
- 左键持续开火，右键持续采集，Q/中键放置，1–6 选物品，E 合成，F 吃肉，H 头灯，Shift 冲刺，空格跳跃；Esc 释放鼠标。触屏摇杆、看向区、四个动作和合成/头灯/食物。放置必须有库存且不能包住玩家。
- 霸王龙咬击前 0.85 秒红色张嘴预警，冲入 2.8 格内才命中；翼龙俯冲前 1.1 秒预警。夜里加快追击；屋顶加两面墙判为庇护，降低被发现距离并恢复生命。拾肉后 F 补饥饿，饥饿耗尽持续失血。昼夜一轮 180 秒。

## 性能预算

默认桌面 1440×900，DPR≤1.5；手机 390×664，DPR≤1.25。桌面目标 60fps/16.7ms，手机目标 30fps/33.3ms，主线程 JS p95≤12ms。桌面可见区块半径3（49块）、手机2（25块），超半径立即卸载；每块最多12,000合并四边面，正常目标<4,000。Worker 串行做带边缘采样的面剔除和贪心合并；每帧最多接入两块，编辑只重建本块及触到的边界及 AO 角邻块，最多 4 块。碰撞查询直接取确定性体素，不依赖网格到达。生物上限18，弹壳/碎屑上限96，掉落物上限24；重复生物部件及粒子 InstancedMesh。默认 draw calls≤110，三角形≤300,000。无全屏重型着色器、无实时阴影贴图。

自适应分辨率比例1/.85/.70/.55，连续45个超预算帧降档，连续240个低负载帧升档，3秒冷却；背景或窗口离屏暂停 RAF 和模拟。固定机位无动作时30fps，普通游玩上限60fps；不每帧创建几何或对象。

## 第二轮返修的画面断言

- 正常入口在原出生区选择干燥落脚点，半径 5 格内没有原木或叶簇，前向相机射线 6 格不碰体素。朝向远处第一只霸王龙，轻微抬头 0.1 rad。10 个指定种子为 46、55、64、71、91、135、731、732、9、1001。1440×900 默认 DPR 档的真实 GPU 分类帧中，天空与地面各占至少 15%。分类帧保持原几何、机位、叶片镂空和深度，天空、地面、植物分别编码，辅助物隐藏，另保存正常截图。
- 一个 Canvas 生成的 256×16 图集，每格 16×16。草顶、草侧、泥、石、沙、木端年轮、树皮、木板、叶、琥珀、矿点及灯具各自取图格。草侧上沿 3–5 像素草边。NearestFilter、无 mipmap，逐体素重复。叶片 alphaTest .35，琥珀 alpha 168/255，所有地形区块共享一个材质。相邻两侧和角体素计算四顶点 AO，遮蔽角亮度低于开放角至少 .05，非均匀 AO 不跨格贪心合并。雾仅占可见距离的后 40%，桌面 37.8–63 格、手机 26.4–44 格。
- hero 为固定侧面观察机位，位置 (-12.5,29,-12)，YXZ 旋转 (-.262,-1.72,0)，种子 731 真实推进 2 秒，DPR/材质沿用玩家默认档。霸王龙投影包围框像素宽高比 >1.2，头与尾位于身体投影两端，头到身体的 NDC 距离 >.06。大头、铰接颚、上下牙、短前肢、粗腿、水平长尾均可辨。头、尾与腿的实际动画矩阵跨两帧应变化，腿反相摆动，移动朝向与位移点积 >.99。地形深度测试后霸王龙可见像素/无地形轮廓像素 >95%，前方深度 <10 格的树干与树冠像素占全帧 <1.5%，近场树冠不得遮住主体。桌面 hero 中草食龙与翼龙各至少一只完整在画内，像素宽高比 >1.2、屏宽占比 >4%。

- 前后图固定相机、种子、CSS 1440×900、设备 DPR 2、实际 DPR 1.5、渲染比例 1。hero 对照双方都用上述新侧机位，另保留旧正面机位失败读数。night 对照双方沿用第一轮相机。各截图记录回报机位和实际性能。所有预算沿用原表，地形材质数与 draw call 量级保持。

## 第四轮：配色

唯一默认方向为晴朗正午的侏罗纪岛，按本轮指定 sRGB 基色执行。实现改色前先在当前默认 C 上增加同一套真实渲染检查，保存为 shots/r4-before.html 和 r4-before-report.json。

- hero 完整 WebGL 帧上方 15% 的 HSV 饱和度采样均值 ≥0.35，包含云和飞行物，保持明朗蓝天。
- hero / wide 真实叶材质 ID 遮罩各 ≥100 个采样点，sRGB Rec.709 加权亮度均值 ≥0.28，S<0.15 且 V>0.8 的叶像素 <1%。遮罩匹配 atlas alpha、深度并内缩 1 个 framebuffer 像素，孔洞中的天空不计入叶片。
- hero / wide 各至少 10 个真实草土地形块同时取到受光顶面与背光侧面，两面各 ≥3 个采样点。按世界坐标配对，每块先算顶面/背面 sRGB 加权亮度比，再求均值，需 ≥1.5。背光以法线与实际太阳方向点积 ≤0 判定。此指标包含草顶/泥土的材质差异。
- 保留整帧黄绿 70–110° 占比 hero ≤40%、wide ≤32%、night ≤28% 和高饱和 S>0.65 占比 ≤28%，黄绿统计需 S≥0.15 且 V≥0.10，高饱和统计需 V>0.20。hero 的 40% 上限容纳给定草色 #5E9A35 / #7FB043（HSV 色相约 87°–96°）覆盖近半帧地面的正常构图；wide / night 沿用旧值。高饱和上限仍为 28%，配合新增饱和度/亮度下限，约束荧光与灰闷。原绿色版 hero 47.24% / 39.70% 仍会同时失败。
- 保留恐龙对周围地面/天空 CIE76 ΔE 白天 ≥18、夜间霸王龙 ≥12，以及 4–32 CSS 像素外环、双方各 ≥30 采样点。色差将双方平均 sRGB 转为 D65 / 2° Lab。每帧采样数 >50,000，天空与地面各 >100 点，两者平均 sRGB 的 HSV 圆周色相差 ≥35°，天空通道均值白天 ≥80/255、夜间 ≥8/255。
- 纯数学、生成纹理与配置推导放 tests/*.test.cjs。真实浏览器检查只放 tests/*.browser.cjs，CI 测试不调用浏览器、不读取 shots。配色检查用 NODE_PATH="$(npm root -g)" node --test tests/palette.browser.cjs 本地运行。

每隔 3 个 framebuffer 像素采一点，1440×900 / DPR 1.5 每帧为 324,000 点。采样沿用种子 731、同一模拟状态和三个机位，CSS 1440×900、设备 DPR 2、默认实际 DPR 1.5、scale 1。正常完整帧直方图、排除辅助物的色差帧、ID 帧共享机位及默认渲染路径。前后并排均为左旧 C、右新默认。复用既有 Canvas、体素、噪声、Playwright 和颜色数学，不增加依赖。
