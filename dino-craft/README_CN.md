# 方块侏罗纪

在程序生成的史前群岛里挖方块、搭庇护所，用无限子弹的加特林逼退恐龙，活过第一夜。横向地形没有预设边界，走到哪生成到哪。

页面需要 WebGL 2。全部素材由代码生成，发布产物只有一个 HTML，不请求外部素材。

```sh
npm install
node tools/build.mjs
node tools/serve.cjs . 8954
# 正常游戏：http://127.0.0.1:8954/dist/index.html
# 源码入口：http://127.0.0.1:8954/dev.html
node --test tests/*.test.cjs
node tools/browser-check.cjs
```

浏览器检查复用本机已装的 Playwright，自启临时服务器，截图和读数放在 `shots/`。可把页面 URL 作为第一个参数。macOS 默认选择 ANGLE Metal；其他系统使用 Chromium 默认后端。帧率要结合报告里的渲染器判断。

开局有少量原木和 16 块木板。可以挖树、岩石和矿点，在工作台合成六种配方。屋顶加至少两个方向的墙会降低恐龙发现距离，并慢慢回血。琥珀加石头可做头灯电池；火把与灯笼能照亮营地（最多四个同时发光）。击倒恐龙后走近拾肉，直接吃或加工成熟肉。饥饿耗尽会掉血。

约第 83 秒入夜，一轮昼夜 180 秒。霸王龙咬击前张嘴预警 0.85 秒，后退离开范围就能躲开；翼龙预告 1.1 秒后俯冲，扑空会脱离，不能一直黏着你。夜间捕食者更快，并会从不同方向接近。守过首夜后可以继续建造探索；死亡后按钮重开。

## 实现与验收

Three.js **0.186.1**、esbuild **0.28.2**，无额外游戏依赖。16×16×48 的带种子区块在 Blob Worker 里做面剔除、邻接体素顶点 AO 与贪心合并，挖放只重建本块及触及的边界邻块。Canvas 生成的 16 像素图集按方块和面分纹理，叶片镂空、琥珀半透明，地形共用一个材质。桌面最多保留 49 块，手机 25 块，远处几何会释放。恐龙部件、粒子、掉落物用实例绘制。设备像素比封顶、自适应分辨率带滞回、手机封顶 30fps，后台与离屏暂停；没有阴影贴图和全屏后期。

出生点检查半径 5 格植被净空和前方 6 格视线。霸王龙有张合颚、长尾和交替步态，枪有六根圆柱枪管与两道圆箍。`?seed=731` 换种子；`?view=hero`、`?view=night`、`?view=wide` 是固定验收机位，hero 从侧面观察恐龙。机位从真实模拟推进后冻结，夜景用生存测试里的驾驶器再往林边走。无 view 参数就是正常游戏。统一钩子 `window.__PLAYTEST__` 回报状态与性能，支持重开、种子与步进；额外的朝向、画质调试方法只在 `?test=1` 下出现。

性能阈值见 [SPEC.md](SPEC.md)，实测和边界见 [VERIFICATION.md](VERIFICATION.md)。本目录不接入首页、不改 CI、不提交和发布，由 owner 统一处理。

MVP 边界：方块与库存仅在当前会话保存；高度 48 层；没有洞穴、联机、流体传播、磁盘存档。水面是视觉表面，浅水移动减速。恐龙使用简单贴地 AI，庇护所只检查附近屋顶与墙面，没有通用建筑封闭求解。没有声音。真手机手感与长时间热表现仍需人试玩。

默认配色为晴朗正午的侏罗纪岛，蓝天、暖金阳光、冷色补光与饱满绿叶，搭配红褐霸王龙、深纹蓝灰草食龙与铜色翼龙。雾从可见距离的 60% 处开始。天空、地形纹理和草地区域色由代码生成。

CI 使用 `node --test tests/*.test.cjs` 运行纯 Node 检查。本地真实渲染单独运行 `NODE_PATH="$(npm root -g)" node --test tests/palette.browser.cjs`。`node tools/palette-check.cjs --default` 量 hero、wide 和头灯夜景，存在本地旧 C 基线时还会生成同机位前后对照。`tests/fixtures/` 保留实际旧帧读数，用于校准回归检查。
