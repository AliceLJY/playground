# Dino Craft

A small first-person voxel survival sandbox in a procedural prehistoric archipelago. Explore beyond the horizon, gather blocks, build shelter, and survive the first night with an infinite-ammo rotary gun. There is no map edge in the horizontal terrain generator.

Play the self-contained `dist/index.html` from a static server. Everything is generated in code; the page makes no asset requests. The game needs WebGL 2.

```sh
npm install
node tools/build.mjs
node tools/serve.cjs . 8954
# http://127.0.0.1:8954/dist/index.html
# http://127.0.0.1:8954/dev.html (unbundled source)
node --test tests/*.test.cjs
node tools/browser-check.cjs
```

The browser checker reuses an installed Playwright, starts a temporary local server, and writes screenshots plus `shots/browser-report.json`. It accepts a page URL as its first argument. On macOS it selects ANGLE Metal; on other systems it uses Chromium's default backend. Check the reported renderer before interpreting FPS.

## Play

| Action | Desktop | Touch |
|---|---|---|
| Move / sprint | WASD / Shift | Left stick / push to edge |
| Look | Mouse, click to lock; Esc to release | Drag the right side |
| Jump | Space | Jump |
| Fire | Hold left mouse | Hold Fire |
| Mine / collect | Hold right mouse | Hold Mine |
| Place selected block | Q or middle mouse | Place |
| Select block | 1–6 / click hotbar | Tap hotbar |
| Craft / pause | E | Craft |
| Headlamp | H | Lamp |
| Eat | F | Eat |

Start with a few logs and 16 planks. Mine trees, rock and exposed amber; craft six recipes at the field workshop. A roof and walls on at least two sides hide your scent and slowly heal you. Headlamp charge drains while switched on; amber plus stone refills it. Torches and lanterns light a camp (up to four active light sources). Walk close to a defeated dinosaur's meat to collect it, then eat or cook it. Hunger eventually costs health.

The first night arrives after about 83 seconds; a full cycle lasts 180 seconds. T. rex telegraphs its bite by opening its jaw; retreat during the 0.85-second warning. Pterosaurs warn for 1.1 seconds and commit to a dive that can be dodged. Night brings faster, flanking predators. After surviving the first cycle, exploration continues. Death offers a full restart.

## Implementation and review

Three.js **0.186.1**, esbuild **0.28.2**, no other game dependencies. Seeded 16×16×48 chunks use a Blob Worker for face culling, corner vertex AO and greedy meshing. A Canvas-generated 16-pixel atlas supplies face-specific textures, cutout leaves and translucent amber through one terrain material. Only edited chunks and touched border neighbours rebuild; remote meshes are disposed. Desktop keeps 49 chunks, touch devices 25. Animal parts, particles and meat use instancing. Pixel ratio caps, a hysteretic resolution governor, a mobile 30fps cap, and background/offscreen suspension bound rendering work. No shadow maps or full-screen postprocessing.

`?seed=731` chooses the world. The spawn selection checks a five-block vegetation clearing and six-block sightline. T. rex has articulated jaws, a long counterbalancing tail and alternating legs. The gun uses six cylindrical barrels and two circular collars. Fixed captures: `?view=hero`, `?view=night`, `?view=wide`. The hero camera observes the dinosaur from the side. These advance the real simulation and then freeze it; reload without `view` to play. The night capture uses the same driver as the survival tests, then walks toward the forest. `window.__PLAYTEST__` exposes readiness, snapshots, reset, seed and step; orientation/governor diagnostics additionally require `?test=1`.

See [SPEC.md](SPEC.md) for budgets and [VERIFICATION.md](VERIFICATION.md) for actual evidence. The owner will connect the directory to the homepage and CI. This work does not edit those shared files or publish anything.

MVP limits: session-only edits and inventory, 48-block vertical span, no caves, multiplayer, dynamic fluid or disk saves. Water is a visual surface with slower movement in the shallows. Dinosaurs use simple terrain-following AI, and a shelter is a local roof/wall check rather than a general enclosure solver. No sound is included. Physical-phone feel and long-session thermal behavior require human testing.
