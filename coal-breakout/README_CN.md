# 煤球突围

小黑煤球带着环绕的人工智能小助手，闯过三种日常灾难。单指拖动走位，小助手自动开火；捡经验、选工作流卡，撑过倒计时，再打掉首领，解锁下一关。每关约两分钟出头，所有危险静音也看得懂。

**[在线玩](https://aliceljy.github.io/playground/coal-breakout/)** · [英文说明](README.md)

## 怎么玩

- 手机：在场地内按住拖动，像浮动摇杆一样控制方向；松手停下。
- 电脑：鼠标拖动，或方向键及键盘左侧四个方向字母键；退出键或暂停键可以暂停。
- 默认静音，点声音按钮开启代码合成的芯片音乐与音效。
- 每隔一级自动替你挑一张卡并在顶栏提示，其余升级时战场暂停，三选一，也能跳过；每升三级回一格生命。
- 标题页可选本局「清场」（优先穿透、并行）或「续航」（优先拾取、存档）自动升级倾向；默认不偏向，没匹配卡照旧选第一张，结算后重来或下一关恢复默认。
- 第一关「幻觉怪」：经验宝石里混有粉芯闪烁的假货，靠近后先张口，再追咬。首领只有白色描边的真身会掉血。
- 第二关「上下文溢出」：文字墙向内挤压，击败黄色压缩器能推回一截。首领会把你和宝石吸向中心。
- 第三关「额度重置」：每四十秒重置一次，提前三秒红条预警，然后停火四秒，恢复后爆发五秒。首领的黄色限流框变红前要离开。

八张卡分别增加小助手、穿透光束、弹数、攻速、拾取半径、一次免死、移速和暴击。每张最多三级，每一种效果都进入真实模拟。阵亡可立即重来本关；浏览器只保存已解锁关卡，禁用存储也能在当前会话继续闯关。

结算图包含本局数据、选过的卡、角色与入口二维码。「保存图片」优先调用系统文件分享，不支持时下载图片。

## 本地运行与检查

```sh
cd coal-breakout
python3 -m http.server 8936 --bind 127.0.0.1
node --test tests/*.test.cjs
node tools/lint-hot.cjs
```

打开本机八九三六端口。无需安装或构建，发布只复制入口页面与源码目录。

模拟采用每秒六十步、整数帧号、种子随机数和预分配池；每帧模拟全部在热路径文件内，绘制、声音与检查分开。热路径检查禁止构造、闭包和对象、数组字面量，并先拿故意违规的样例校准。测试录制完整一局输入，重放时逐帧比较全状态摘要。每个发布文件分别压缩后相加不得超过一百五十千字节。

关卡、敌人与卡片说明集中在数据表，新增机制只需补相应的模拟与绘制。运行时不加载外部图片、音频、字体或服务。碰撞使用有容量上限的池扫描，规模扩大后才需要空间索引。

## 浏览器验收入口

```sh
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs http://127.0.0.1:8936/
NODE_PATH="$(npm root -g)" node tools/workflow-check.cjs http://127.0.0.1:8936/ <仓外输出目录>
NODE_PATH="$(npm root -g)" node tools/record.cjs http://127.0.0.1:8936/
```

工具使用本机已安装的浏览器自动化工具；录制还需要本机已有的视频编码工具，不向仓库添加依赖。截图、逐帧记录、录像和本地组装产物都被版本控制忽略。

五个固定机位依次是战斗中段、升级选卡、第三关首领与重置预警、结算、压力场景，对应地址参数：

```text
?view=hero
?view=levelup
?view=boss
?view=result
?view=stress
```

固定机位通过带种子的真实自动驾驶推进再暂停。压力场景明确提高生成倍率，没有无敌。统一试玩钩子提供就绪状态、快照、重开、设种子与推进；额外诊断只在测试参数或固定机位下开放。

具体阈值见[规格页](SPEC.md)，实际结果与截图结论见[验收记录](VERIFICATION.md)。自动驾驶不能代替真人手感和中端手机性能验证。合并、发布及线上复验由验收者完成。
