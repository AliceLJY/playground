# 煤球突围 · 核心版规格

手机竖屏，单指拖动小黑煤球走位，让环绕的 AI 小助手自动开火；认出陷阱、抢回空间、熬过停火，再击败首领。主美学是**挑战 + 幻想**，循环型；陌生访客、单手、多半静音，每关约 2–4 分钟。桌面支持拖动及方向键 / WASD。

## 画面与场地

- 全部颜色为 sRGB：背景 `#101827`；地面是石板地（每关一组石色，第一关 `#1F2C3E`–`#2F3849`，石缝 `#070B12`），不再画网格线和 COAL 水印；薄荷绿 `#72F1C4` 用于经验与友方弹道；粉色 `#FF5DA2` 用于天线、幻觉与重点；危险红 `#FF665E`，预警黄 `#FFD166`；正文 `#F4F1DE`。
- 主角近黑圆身 `#111111`（左上一块煤面高光 `#24272F`/`#3A3E4A`、右下暗边），两只白点眼、短白横嘴，细黑天线末端粉球，只有两条细黑腿、没有手臂，白色贴纸描边。走路时眼睛看向移动方向、天线反向歪、两腿交替迈步并上下颠 2 单位。启动生成像素图集，不请求图片、字体、音频。
- 地面与道具（2026-11-11）：地面、道具和主角都按「1 像素 = 2 单位」画。石板按 12 像素格拼单块、长条和 2×2 大块，每块自带色差、斑块、左上亮边、右下暗边、缺角、裂缝和煤灰；石缝里走暗绿电路线和过孔（过孔周期闪一下），少量通风格栅，边缘一圈煤块碎石逐渐压暗。每关一组点缀：第一关紫色幻觉斑点，第二关散落的纸片，第三关焦痕。
- 道具（障碍）：每关 4 件，来自固定的 8 个候选位，用本局种子随机数挑位和微调（±6），四种各一件：服务器机柜（LED 闪烁）、token 木箱（`{ }` 标签）、煤堆（余烬暗闪）、旧终端（绿屏）。每件有深色描边、左上亮、侧面暗、右下落地影。碰撞盒半宽×半高分别为 21×28、24×21、26×18、20×17 单位。道具挡主角（按脚底）和普通怪；怪看不见主角时沿 12 单位格的距离场绕行。子弹从道具上方飞过（小助手在空中开火）。首领和分身是半径 ≥20 的大幻影，直接飘过道具。第二关文字墙离道具不足 34 单位时把它吞掉（之后可穿过，只留淡影），中间区域不放道具。
- 光与后期：场地整体压暗 42%，主角周围一圈抖动边缘的暖光（半径随剩余生命从 100% 缩到 78%，停火时闪烁），四周暗角；LED、余烬、终端屏和电路过孔在暗处保持亮色。普通受击时红色屏边闪 18 帧、主角提亮。预警框、敌人、宝石、子弹画在压暗层之上，读数不变。
- 固定俯视场地 360×520 单位，整体等比例放进 HUD 与底部操作提示之间；桌面仍保留竖屏战场。主角完整轮廓约 44×76 单位（场宽 11–14%，2026-11-11 由 25×42 放大约 1.75 倍），敌人 18–30，首领 52–64。伤害判定半径仍为 10（以身体中心算，约为新身体半径 20 的一半，沿用旧难度、保持幸存者类的宽容判定）；碰道具和墙用脚底圆（身体中心下方 20、半径 14）；活动范围 x 22–338、y 46–489；移速 1.95→2.1 单位/帧，小助手环绕半径 25→34。HUD 不覆盖活动区；主角轮廓不能出活动区。像素块平涂，左上亮边、脚下暗影，无动态光照。
- 三关分别 100 / 130 / 130 秒出现首领（2026-11-03 Alice 试玩嫌 3 分钟长后缩短）；进度只记录已解锁关卡。问号团与假宝石；向内推进的文字墙与压缩器；40 秒周期重置与限流区。偶数级升级自动选卡并在顶栏提示，奇数级暂停三选一或跳过（选卡打断减半，同日 Alice 定），最多每张 3 级；存档卡提供一次免死。
- 幻觉宝石以粉色芯和间歇闪烁露破绽，靠近后 0.7 秒张口预警才追咬；敌人入场有 0.6 秒淡圈预警。重置提前 3 秒红条倒计时，停火 4 秒，之后 5 秒爆发。限流区落地前 1.2 秒黄框预警，危险持续 1.3 秒。所有信息静音可读。
- 标题页使用完全不透明的 `#101827`，HUD 与底部操作提示不能透出；升级、暂停遮罩保留半透明战场。
- 前两关从第30秒起用短波次与恢复段交替：第一关每8秒有2.5秒密集段，第二关每10秒有3秒密集段，密集/恢复段的生成间隔分别为原节奏的0.5/1.5倍。第一关假宝石追咬速度125单位/秒，分身每5秒重组、速度80；所有显形/入场预警时长不变。第二关文字墙每秒收缩2.4单位、上限84（2026-11-11 由 100 调低，抵消主角变大后变窄的活动区）；压缩器在15秒首次出现、之后每35秒出现，击败仍推墙18单位，文字团基础速度55单位/秒、黑洞牵引66单位/秒。敌人和首领血量不变；第三关参数保持原样。

## 固定机位

所有机位同正常入口的画质、图集与渲染路径，固定种子自动驾驶推进真实模拟后暂停；只有压力机位使用显式压力生成倍率（不改变伤害规则）。钩子回报请求机位、实际状态、种子与帧号；正常入口无自动驾驶。

| 参数 | 目标状态与复现 |
|---|---|
| `?view=hero` | 第一关第 84 秒，已升级、多个敌人与经验 |
| `?view=levelup` | 第一关第一次升级停在三选一 |
| `?view=boss` | 第三关种子 2，模拟第 9500 帧（9500 / 60 ≈ 158.33 秒），首领在场、重置红条预警中；钩子必须回报 `actualView=boss`（2026-11-11 加道具后种子 1 在 146 秒就打掉首领，改用种子 2） |
| `?view=result` | 第一关真实通关后的结算海报 |
| `?view=stress` | 显式压力生成模式下≥300 活敌，暂停可复现；工具可恢复实测 |

截图三个视口共 15 张，另拍开场与默认游玩；录制正常入口开局 30 秒。发布直接复制 `index.html` 与 `src/`，本地另按 CI 同样结构组装后复测；线上复验留给 owner 发布之后。

## 可选玩法：本局自动升级倾向（2026-11-03）

标题页可选「不偏向 / 清场 / 续航」再出发；默认不偏向。清场只优先现有穿透光束、并行调用，续航只优先现有拾取、存档卡。偶数级仍从原来的三张候选中选卡，取第一个符合倾向的候选；没有匹配时仍取第一张。奇数级手选与跳过不变，不增加弹窗，不改关卡、敌人、卡片效果或难度数值。主目标为挑战中的构筑选择，手机单手静音、电脑键盘均可。

沿用每关 100 / 130 / 130 秒出首领、击败首领完成的流程；倾向不保证通关，走位失误仍受伤、免死用尽仍阵亡。结算后重来、下一关或回标题都恢复不偏向；想再用倾向，从标题重新选择。暂停继续保留本局倾向，暂停重开视为新局。没有额外时长或强度阈值；两组偏好的实际手感与收益待试玩校准。

| 编号 | 验收（最多五条） |
|---|---|
| W1 | 纯选择函数不改候选、不消耗随机数：有匹配选最前匹配，没有匹配或未选择取索引 0；全满、无效输入也安全。未选择的真实模拟逐帧摘要与修改前基线一致。 |
| W2 | 第一关种子 1–6、同一 precise 驾驶规则，分别真跑两种倾向到胜负；每局至少 2 次自动选卡，每种倾向至少 4/6 局实际匹配本组（候选可能整局没有本组卡，不强求每局匹配），跨种子实际获得本组自动卡更多，两组至少一半样本的已获卡与战斗结果（耗时、击败、受击、发射数）均不同；至少各有一局击败首领，持续输入却无位移、无击败进展的卡死窗口 <180 帧。浏览器另以真实触控/键盘输入走完，不用直接改状态。 |
| W3 | 两种倾向 reckless 均实际受伤并阵亡；新建默认局清空卡片、免死、自动提示、倾向并可移动击杀。浏览器覆盖结算重来、下一关、回标题与暂停继续/重开，默认结果无残留。 |
| W4 | 发布组装产物在 390×664、320×568、844×340、1365×900 下，两种倾向均完成一局；菜单、升级、结算操作区按钮至少 44×44 CSS px，完整可见且中心可点；说明文字不超出自身框或压到后续内容（容差 0.5 CSS px）；零页面错误，逐张读截图。原有浏览器与 Node 检查仍通过。 |

实现复用现有候选、卡表、模拟、输入与结算，增加一个无分配选择函数，不另建模式框架或升级面板。

## 小规模取舍

复用本仓静态目录 / CI 方式，用平台 Canvas、WebAudio 与 Node 内置测试，不加引擎、构建器、运行库。碰撞是有容量上限的池扫描（敌人512、弹丸256、宝石768，道具8），怪的绕行用 30×44 格广度优先距离场、每 6 帧重算一次，如将来超过这个规模再改空间网格。无服务器、账号、排行榜或每日挑战；保留种子输入。角色设定遵循任务信封全部锚点；受任务末尾硬围栏约束，未跨仓读取角色文档。
