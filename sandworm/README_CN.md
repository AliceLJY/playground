# 机械沙虫 · 沙行者 MK-X

一份虚构的工程设计档案：一条在沙漠地下掘进的机械沙虫。可以转着看、切机位，开 X 光看埋在沙里的部分，把装甲往外拆开。头部横截面、全长纵剖面、单环结构和蠕动周期四张小图跟主视图用同一个时钟，一起动、一起停。

**[在线看](https://aliceljy.github.io/playground/sandworm/)**

## 操作

- 六个预设机位：正面、侧面、俯瞰、追逐、前哨、环绕，点按钮或按数字键 1–6。
- 鼠标拖动旋转、滚轮缩放；手机上单指转、双指缩放。
- X 光（X）看地下部分，拆解（E）把装甲展开，暂停（空格），参考姿态（R）。

## 怎么做的

- 照着 [AYi 的七轮制作提示词和参考图](https://x.com/AYi_AInotes/status/2104826052979597409)独立实现：程序化几何加 Three.js r160，没有用原作者的代码、模型文件或截图。
- 这个文件夹只放打包好的单文件 `sandworm.html`，Three.js 运行库和它的许可证都在文件里，打开后不再请求别的文件。拆开的源码、模型检查和打包脚本在作者的提示词素材库里：改动在那边做完、重新打包，再整份覆盖这里的文件，别直接改这份。
- 题材取自《沙丘》。机构、尺寸、地形和运动都是概念示意，不代表电影设定，也不是能照着造的工程图。
