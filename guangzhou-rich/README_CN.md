# 花城收租佬

一圈广州街区的收租桌游：上下九、北京路、沙面、东山口、珠江新城、广州塔、白云山、长隆……每回合挑掷两颗还是掷一颗，走到空地决定买不买，走到别人的地交租，走回自己的地加盖一层。十五轮后比身家，交不起租就出局。手机竖屏优先，电脑上也能玩，一局十来分钟。

**在线：https://aliceljy.github.io/playground/guangzhou-rich/**

## 对手

- **规则机器人**：默认，三个座位都是，不用任何 key。
- **DeepSeek / 通义千问**：在选座页把座位换过去，填你自己的 key。同一个服务商可以坐好几个座位，每个座位可以改接口地址（比如换成你的中转站）和模型名。
- 模型只在代码给出的合法选项里挑一个（掷几颗、买不买、盖不盖、花钱出塞车还是等一轮），顺带说一句嘴炮；掷骰、扣钱、产权、破产全部由代码判定。模型回了乱七八糟的东西、超过 8 秒没回、报错或被浏览器拦了，这一回合就由规则机器人代打，游戏不会卡住。

## key 安全

- key 只在你的浏览器里，直连 DeepSeek / 千问，本站没有服务器，不经手。
- 默认只放在页面内存里，关掉页面就没了。勾选「在这台设备上记住」才会存进浏览器的 localStorage；注意整个 `aliceljy.github.io` 是同一个源，这个网站的其他页面也读得到，用完可以点「清掉记住的 key」。
- 页面不加载任何第三方脚本、字体或图片，并用内容安全策略锁住；为了支持自填的中转站地址，联网放行了所有 https 地址（不放行 http）。
- 中转站地址要允许网页直接调用（CORS），不允许的话座位旁会提示「这个地址不允许网页直接调用」，并由规则机器人代打。

## 本地运行

```bash
cd guangzhou-rich && python3 -m http.server 8811
node --test tests/*.test.cjs
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs http://127.0.0.1:8811/ shots
```

固定机位：`?view=setup`、`?view=play&seed=7`、`?view=over&seed=7`；`?fast=1` 去掉动画间隔。规格与验收条目见 [SPEC.md](SPEC.md)，实测记录见 [VERIFICATION.md](VERIFICATION.md)。
