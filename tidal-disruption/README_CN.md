# 潮汐之下

一颗恒星在 108 秒内经历接近、潮汐拉长、撕裂、回落碰撞、成盘与余波。拖动环绕，滚轮或双指缩放；时间轴可跳到任意时刻，支持暂停和倍速。空格切换播放，物理说明面板解释每一段的变化与近似。

## 本地运行

```sh
npm install
node tools/build.mjs
node tools/serve.cjs . 8941
```

访问 `http://127.0.0.1:8941/dist/index.html`，源码入口为 `/dev.html`。构建产物是带 Three.js 的单个 HTML，所有画面由代码生成，页面没有外部资源请求。

固定机位暂停在同一套模拟的可复现时刻。

- `?view=wide` 在 8 秒远看恒星接近。
- `?view=hero` 在 82 秒斜看成盘与透镜光环。
- `?view=edge` 在 82 秒侧看盘背面被弯到上下方。

界面的机位按钮保留当前时间，无参数入口从头播放。到 108 秒停止，可重播。

## 光与物质怎样计算

降分辨率片元着色器逐段积分史瓦西零测地线的空间轨道方程，以史瓦西半径为单位使用 `x'' = -1.5 L² x / r⁵`。光线每次穿过盘面才采样气体，沿弯折线段采样恒星体积，逃逸方向决定看到哪片星空。重复的盘面交叉自然产生高阶盘像和光子环。观察者发射方向与有限积分步长采用近似。

GPU 片元计算把粒子坐标写入浮点纹理，解析时间函数保证倒拖时间轴也能准确复现。碎屑具有不同轨道能量与开普勒周期，另加指定的近心点进动，再平滑环化。一次双附件密度绘制同时记录辐射和速度矩，交叉流的速度方差用于估算加热。透镜光线取样这两张密度图，使物质流与吸积盘一起弯折。盘面包含差分旋转、引力红移和多普勒增亮近似。

恒星大小为观看而放大，真实天文时间被压缩。碎屑垂直厚度压成薄层，环化、冷却与激波加热使用现象近似，颜色是温度启发的可见光假色。未求解流体、磁场、辐射输运与旋转黑洞，没有喷流和声音。

## 功耗控制与验收

渲染上限为 30 帧。桌面像素比封顶 1.5，手机 1.25。节能、平衡、精细三档的光线目标比例分别为 0.30、0.75、1.00，密度图分别为 384²、1024²、1024²，最大步数分别为 96、144、192，GPU 粒子分别为 4096、9216、16384。默认平衡档以 M4 桌面 GPU 中位≤20ms 为目标。每帧四次绘制。持续超时会降档，恢复更慢，切档后冷却八秒。后台、画面不可见以及暂停静止时停止渲染。

```sh
node --test tests/*.test.cjs
node tools/browser-check.cjs
node tools/browser-check.cjs --record
node tools/clarity-check.cjs
node tools/r3-compare.cjs
node tools/performance-check.cjs
```

检查器查找本机 Playwright，启动独立 Chrome 和临时本地服务器，截图与报告保存在 `shots/`。可附页面地址复验带子路径的产物，`--record` 加录正常入口的 30 秒操作。GPU 检查顺序执行。额外测量控制仅在 `?test` 下开放，统一 `window.__PLAYTEST__` 回报实际渲染指标并提供重置、种子和步进方法。

清晰度检查在 82 秒的 hero、edge 两机位读取真实最终画布，逐帧与光线比例 1.0、密度图 1024² 的同帧参考比较；光子环与盘内缘的梯度能量须分别保留至少 65%。Node 测试也实际运行这项 GPU 检查。`r3-compare.cjs` 需要 `shots/` 中保留的前后截图，输出左右对照与 3 倍局部图。性能脚本应等其他 GPU 检查结束后单独运行，并记录 Chrome 进程负载与实际 GPU timer 样本。

具体实测和覆盖范围见 [VERIFICATION.md](VERIFICATION.md)。渲染占空比经过限制，设备温度与长时间热稳定性仍需硬件测量。
