## 性能实测

默认自适应保持开启。每次测量先预热，再连续观察五秒。JS p95 使用最近 180 次提交耗时并排除最初四帧编译预热，GPU 计时通过 EXT_disjoint_timer_query_webgl2 取得。

| 场景 | 平均 FPS | JS p95 | GPU 读数 | 绘制 | 几何 |
|---|---|---|---|---|---|
| 正常入口，约 2–7 秒 | 29.96 | 0.40 ms | 十个定时样本，中位 7.44 ms，范围 3.39–31.03 ms | 4 calls | 3 三角形、9216 GPU 点 |
| hero 播放，约 83–88 秒 | 29.90 | 0.40 ms | 最后一次 8.34 ms | 4 calls | 3 三角形、9216 GPU 点 |

两段均为平衡档，光线目标 864×540、144 步、512² 密度图。实测帧时间约 33.4 ms。GPU 样本有瞬时波动，最高 31.03 ms 仍保留在原始报告中。设备温度、整机瓦数和长时间热稳定性尚未测量。

三档实际回报分别为 4096/9216/16384 粒子、96/144/192 步、648×405 / 864×540 / 1080×675 光线目标。每档均四次绘制、三个全屏三角形。切档仅重分配目标和点索引，常规帧复用对象。

### 单独性能复测

最后一次计时在 `2026-11-11T11:30:43Z` 开始，在本任务的所有其他 GPU 检查和并排图生成结束后，单独运行 `node tools/performance-check.cjs`，退出 0。Chrome 157.0.8103.39，WebGL 2，`ANGLE (Apple, ANGLE Metal Renderer: Apple M4, Unspecified Version)`，真实硬件 GPU。视口 1440×900、实际 DPR 1.5、drawing buffer 2160×1350；三个场景均为正常默认自适应模式、实际平衡档 0.75 / 144 步 / 1024²，未强锁质量。

| 场景 | 实测 FPS | GPU 中位 | GPU p95 | GPU 范围 | JS p95 |

| 正常入口，约 2–7 秒 | 29.969 | 9.942 ms | 12.060 ms | 6.776–13.499 ms | 0.20 ms |
| hero 播放，约 83.5–88.5 秒 | 29.968 | 7.074 ms | 8.879 ms | 6.950–9.456 ms | 0.20 ms |
