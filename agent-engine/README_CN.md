# agent 引擎是什么

一页六个镜头的动画讲解，讲一件事：模型 API 只会说话；让它动手、记事、转第二圈的那一层叫引擎，多数人天天在调的规则文件、skill、记忆库，是引擎上面的 harness。六个镜头依次是：三层关系；只有 API 时卡在哪；加上循环后每一圈发生什么；循环外那 99% 的工程（八张可以翻面的失败卡）；拿到引擎的三条路；以及陪伴型 bot 的「有自己的日子」是什么——在引擎外多一层模型改不动的世界状态。

**[在线观看](https://aliceljy.github.io/playground/agent-engine/)**

打开停在第一个镜头，播完它的入场动画就等你：翻页自己点。想被带着走，就按「自动播放」。手机竖屏、横屏和电脑都行，浅色深色跟随系统，没有声音。

## 怎么看

- 不按「自动播放」（右上角）就不会自己动。按下之后每个镜头停「动画时长 + 扫读文字的时间」（12 到 40 秒），播完镜头 6 就停，不循环。字最多的镜头按扫读速度要约 77 秒才读完，所以它只是导览速度、不保证读完；点按、按键、滚轮、触摸滑动，任何一下都会接管，按钮可以再开始。
- 顶上的步骤按钮、舞台下面的上一步和下一步，或者键盘左右方向键。从长镜头的底部点下一步，会自动滚回顶部。
- 镜头 4：点一张失败卡（或聚焦后按回车）翻面，从问题翻到引擎怎么接住，背面有一行当场算出来的结果。
- 系统开了「减少动态效果」时，每个镜头直接显示终态，不自动播放。

## 哪些是真跑的

页面上会动的东西，回放的都是 `src/core.js` 算出来的结果：

- 镜头 3 的循环是一个真循环：一个只会返回文字或工具请求的脚本化假模型，三个工具，一道权限门，在一个消息数组上转。环和右边的 `messages[]` 回放它的 15 个事件；把假目录换掉，回答里的数字也跟着换。
- 镜头 2 是同一个模型只调一次、不带循环：它的请求停在那里，没人执行。
- 八张卡是八个小函数：修补请求与结果配对、转参数类型、在预算内压缩上下文、给错误分类并带抖动退避、拒绝危险命令、先读后写、只给核心工具完整定义、给不支持工具调用的模型解析 XML 请求。每张卡背面「现场算」那一行就是它们的输出。
- 镜头 6 把一串请求（出行、午饭、买东西）交给规则闸，逐条驳回、改正或通过，再更新世界状态，转述时只讲通过了的。

这些是教学用的小实现，不是 Claude Code 或页面提到的任何产品的代码，页面上也这么写了。关于其他产品的说法都是原作者的自述，页面上标明了。

## 固定机位和钩子

`?view=1` 到 `?view=6` 定格在某个镜头，动画跑到终态，不自动播放。`?view=4&flip=all` 把八张卡全翻面，`&flip=1,6` 翻指定的几张。不带参数就是正常入口：停在镜头 1、播入场动画、手动翻页。钩子是 `window.__agentEngine`：`ready`、`state()`、`go(n)`、`settle()` 和 `core`（`src/core.js` 的全部导出）。

## 出处

讲解参考了 Anthropic Agent SDK 文档里讲 agent loop 的一篇、Nader Dabit 写的「自己搭一个迷你 Claude Code」、一份 MIT 许可的 agent 产品工程方法论，以及一篇对比六家引擎循环的小红书笔记。链接和各自取了什么写在 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 和页脚里。

## 怎么做的

- 一页规格在 [SPEC.md](SPEC.md)：配色、构图、性能预算、固定机位和十条验收。
- `src/core.js` 不碰 DOM，可以在 node 里跑；`src/view.js` 只回放核心算出来的东西；`src/style.css` 有两套主题的配色。
- 测试（`tests/*.test.cjs`）对好坏输入各跑一遍循环、权限门、八种修补和世界状态闸，扫描发布文件里有没有站外请求和指向人或机器的内容，按真实文字量查自动播放节奏，并从样式表算文字与底色的对比度。
- 没有构建步骤，没有依赖，不发任何站外请求。发布时原样拷贝 `index.html` 和 `src/`。

## 本地运行

```bash
cd agent-engine && python3 -m http.server 8971
```

打开 `http://127.0.0.1:8971/`，或者直接双击 `index.html`。测试：`node --test tests/*.test.cjs`。浏览器检查（需要本机已有 Playwright 和 Google Chrome）：`NODE_PATH="$(npm root -g)" node tools/browser-check.cjs <输出目录>`。

## 谁会点开、AI 素材

- 谁会点开：天天用 Claude Code 之类的工具、想知道规则和 skill 底下那个「引擎」到底是什么、以及引擎要扛住哪些裸模型 API 碰不到的事的人。
- AI 素材清单：没有 AI 生成的图片、模型或声音，页面里根本没有图片；讲解底稿、页面和迷你引擎由人与 AI 协作完成；页面里的假模型是脚本写死的，打开页面不会调用任何模型。
