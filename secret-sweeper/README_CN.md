# 凭证扫雷

经典扫雷，换一层皮。格子是日志行、配置片段和交接文件，雷是藏在里面的钥匙，数字是周围八格里有几把钥匙。插旗就是「打码」，旗子下面压着一条 `<REDACTED>` 黑条。

- 点一下翻开，按住插旗（也可以打开「点：插旗」模式），电脑上右键插旗。
- 第一下不会踩雷，之后每一步都能靠数字推出来，不用猜。
- 三档：轻松 7×9、标准 8×11、困难 9×13，一局一到五分钟。
- 踩到钥匙时，会弹出一张小卡片，讲一种真实发生过的泄露情形（去掉了具体工具和服务名）。全部打完码，结算页写「先看线索再动手」。
- 像素小人会在插旗、踩雷、通关时做出反应，画法沿用像素办公室。
- 有经典扫雷音效（翻开、连片展开、插旗、爆炸、通关），浏览器现合成；底栏 🔊 可以静音。

画面里所有「钥匙」都是假的，而且故意写成残缺的样子（比如 `sk-…4f2a`），扫描器不会把它们当成真密钥。

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8941 --bind 127.0.0.1
# 打开 http://127.0.0.1:8941/secret-sweeper/
```

## 检查

```bash
cd secret-sweeper && node --test tests/*.test.cjs
NODE_PATH="$(npm root -g)" node secret-sweeper/tools/browser-check.cjs /tmp/sweeper-check   # 浏览器验收，在仓库根目录跑
```
