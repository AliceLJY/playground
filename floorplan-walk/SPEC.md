# 走进户型图 · 规格

按仓库根目录 [制作与验收约定](../AGENTS.md) 写的一页规格。实测结果在 [README_CN.md](README_CN.md) 的「验证」一节。

## 体验一句话

一张户型图变成一套摆满家具的房子：先转着看全貌，再按一下从入户门走进去，走近门会自己开；拖时间看阳光，换一套木色。核心操作是「转」和「走」。

## 配色（sRGB，HEX）

| 用途 | 颜色 |
|---|---|
| 页面纸底（白天背景） | `#F3EFE8` |
| 文字与墙顶剖面 | `#2B2824` / `#2E2C2A` |
| 强调色（走进去按钮、滑块） | `#B5653A` |
| 墙面 | 橡木套 `#F3F0EA`，胡桃木套 `#EEE6DB` |
| 木地板基色 | 橡木 `#C4A076`，胡桃木 `#684630` |
| 夜景背景 | `#10151F`，室内灯色 `#FFC98A` |

家具配色两套，逐项写在 `src/core.js` 的 `STYLES` 里；换木色时地板、门、踢脚线、窗框和全部家具一起换。

## 构图规则

- 鸟瞰（`hero`）：俯角约 48°（与竖直方向夹角 0.84 rad），35° 视场。房子整体落在标题与工具栏之间，外包框宽度占画面 45%–90%，四边留白不少于 2%。
- 竖屏（宽高比小于 0.8）：房子转 90° 让长边顺着屏幕竖直方向，再按上面的规则退到刚好放下。
- 走进去：视高 1.6 m，62° 视场。带我走的终点在客餐厅，面向沙发与壁炉。
- 光：默认示意光来自西南上方高处；拖日照滑块后换成北京冬至当天的真实太阳，此时俯视下天花板只投影不入画，光只从窗洞进屋。

## 性能预算

目标是近几年的手机与电脑浏览器。测量机位 `?view=hero`，1280×720：

- 一帧绘制调用不超过 700（含阴影那一遍；阴影只在有东西动时重画，静止时约一半）。
- 走进去全程不低于 30 帧每秒（默认像素比，电脑上像素比 2）。
- 像素比封顶 2；触屏设备阴影贴图 2048，其余 4096。

## 固定机位

| 入口 | 状态 |
|---|---|
| `?view=hero` / `top` / `living` / `kitchen` / `family` / `entry` | 六个预设机位，直接定格，不播开场 |
| `?view=cut` | 鸟瞰 + 墙剖到 1.2 m |
| `?view=walk` | 用真实的行走与开门代码按固定步长走完「带我走」路线后定格 |
| 附加参数 | `&style=walnut`、`&night=1`、`&minute=600`（真实日照，单位是当天第几分钟）、`&labels=0`、`&debug=1` |

无参数入口是正常体验：先播一遍从图纸长出来，再停在鸟瞰。钩子在 `window.__house`：`ready`、`probe()`、`screenBox()`、`luma()`、`setView()`、`walkTo()` 等。

## 验收条目

| # | 条目 | 检查方式 | 通过阈值 |
|---|---|---|---|
| 1 | 数据没走样 | `tests/core.test.cjs` | 8 个房间合计 263.1 ㎡（±0.05），37 件家具、16 级踏步 |
| 2 | 每件家具都有对应做法，橱柜靠墙且吊柜不挡窗 | 同上 | 37 件全部映射到存在的做法，尺寸在 0.25–5 m 内；四段台面的靠墙方向与吊柜开关逐个核对 |
| 3 | 带我走能走到，门在人到之前打开 | 同上 + 浏览器实走 | 三条路线全部走完，离墙不小于 0.22 m，停顿不超过 0.5 s，穿门时开度不小于 75%；开门速度与帧率无关 |
| 4 | 走不穿墙、窗和关着的门；键盘鼠标能接管 | 同上 + 浏览器 | 从每个房间朝 8 个方向快走 10 s 仍在屋内且不在墙里；S 键 0.9 s 后退 0.6–1.8 m；拖动转头超过 0.3 rad；Esc 退出 |
| 5 | 机位构图 | 浏览器读 `screenBox()` | 鸟瞰与平面：宽 45%–90%、四边留白 ≥ 2%；竖屏宽 ≥ 55% |
| 6 | 换木色是整屋一起换 | Node 数色 + 浏览器读地板亮度 | 至少 30 件家具换色且位置尺寸不变；胡桃木地板亮度低于橡木的 70% |
| 7 | 日照读的是算出来的太阳轨迹，夜景亮灯 | Node + 浏览器读亮度 | 滑块每一步与数据逐点一致，正午太阳在正南；夜里室内亮度高于室外两倍以上 |
| 8 | 干净启动 | 浏览器 | 开场 8 s 内播完；零报错；运行时零外部请求 |
| 9 | 性能 | 浏览器读 `renderer.info` 与帧率 | 见上面的性能预算 |
| 10 | 手机竖屏能用 | 浏览器 390×844 触屏 | 页面不横向溢出，「走进去」按钮在屏内，摇杆出现且能推动 |

手感、好不好看、真机上顺不顺，仍要人试。
