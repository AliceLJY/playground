# 走进户型图

一张网上找来的户型图，读出墙、门窗和房间，变成一张可以自己摆家具的彩色平面图；切到 3D，房子从图上长出来，可以转着看，也可以从入户门走进去。

**[在线看](https://aliceljy.github.io/playground/floorplan-walk/)**

和旁边那张 [户型图 · 三维小样](../floorplan/) 是同一套房子、同一份数据。那一页是成片里的手机页，家具是简化体块，重点在 CAD 图和光追效果图；这一页能摆家具、能走进去。

## 怎么玩

**2D 平面（打开就是这一页）**

| 操作 | 电脑 | 手机 |
|---|---|---|
| 加家具 | 从左侧家具库拖到图上，或点一下放到画面中央 | 点底部家具库里的卡片，或按住拖上去 |
| 挪动、旋转、改尺寸 | 拖动家具；拖上方圆点旋转，R 转 90°；拖右下角方块改尺寸；方向键微调 | 点选后拖动；底部浮动条上有旋转、复制、删除 |
| 复制、删除、撤销 | ⌘/Ctrl D、Delete、⌘/Ctrl Z（加 Shift 重做） | 浮动条与顶栏按钮 |
| 看图 | 滚轮缩放，拖空白处平移，F 适应窗口 | 双指缩放，单指平移 |
| 其他 | 「贴墙吸附」「尺寸」「房间」「家具」开关，「恢复原样」「清空布置」，C 换木色 | 同左 |

布置存在浏览器本地，刷新还在。图上的尺寸单位是毫米。

**3D 场景（点「3D 场景」或按 T）**

| 操作 | 电脑 | 手机 |
|---|---|---|
| 转着看、缩放 | 拖动、滚轮 | 单指转、双指缩放 |
| 六个机位：鸟瞰、平面、客餐厅、厨房、家庭室、门厅 | 数字键 1–6 | 点按钮 |
| 走进去 | F，然后 W A S D 走、拖动转头、Shift 快走、Esc 退出 | 点「走进去」，左下摇杆走、拖动转头 |
| 带我走（自动走一段） | 走进去后按 T | 点按钮 |
| 墙剖到 1.2 米 | X | 点按钮 |
| 真实日照、夜景 | R、N，或直接拖时间滑块 | 同左 |
| 房间标注、环绕、重播生长 | L、O、G | 点按钮 |

切到 3D 时房子会从刚才那张平面图上长出来，用的就是你摆好的布置。点「走进去」后会自己从门外走到客餐厅，走近的门会自己开；中途按方向键或拖动就由你接管。

## 怎么做的

- **房子**：墙、门窗、房间和默认的家具位置都来自同一份数据（`data/house.js`），是之前做户型图成片时从那张图里读出来的。墙体按多边形画和挤出，所以厨房那两面 45° 的斜墙和斜窗都在。门扇挂在合页上，走近 1.9 米开、离开 2.6 米关。
- **平面图**：墙、窗、门的开启弧线、房间名与面积、四周的尺寸链都是按这份数据现画的。尺寸链取外轮廓上的转折位置，数值按比例尺换算、取整到 10 毫米；比例尺是从图上楼梯踏步的标注推出来的。
- **家具**：60 种家具的 2D 图例、家具库清单和 45 种三维做法移植自 [wy51ai/floorplan-3d](https://github.com/wy51ai/floorplan-3d)（MIT）。每件按宽、深、颜色生成，所以在图上改了尺寸，三维里跟着变；换木色时整屋一起换，单独指定过颜色的那件保持不变。椭圆餐桌、圆茶几、吊灯、壁炉和楼梯那边没有，是这里补的（`src/extras.js`）。厨房台面会看自己背后是不是墙：靠墙才装吊柜，背后有窗就不装，挪到屋子中间吊柜就没了。
- **编辑**：拖放、吸附、撤销的做法参考了同一个项目，但按这里的多边形墙重写了（它的墙只支持横平竖直的矩形）。它的测量、拆墙、估价没有做：这张图读不出哪面是承重墙，估价的单价也不是行情。
- **日照**：滑块读的是按公式算出来的太阳位置，假设地点北京、冬至这一天。原图只画了指北针，没写地点，所以这是个假设。默认的「示意光」不是真实太阳，只是为了看清模型。
- **行走**：墙的轮廓、窗、落地玻璃门、楼梯、壁炉和大件家具都会挡路；椅子和绿植不挡，免得卡在餐桌边。把柜子摆到路中间，「带我走」会绕，绕不过去就停下。

## 文件

| 路径 | 是什么 |
|---|---|
| `src/core.js` | 坐标、家具布置清单、贴墙吸附、碰撞、开门、路线、太阳位置，不依赖三维库，可以单独测 |
| `src/plan2d.js` | 2D 平面图与全部编辑操作 |
| `src/symbols.js`、`src/kit.js` | 移植来的 2D 图例与家具库清单、三维家具套件 |
| `src/extras.js`、`src/house.js`、`src/textures.js` | 补的几件家具、房屋结构、地板贴图 |
| `src/main.js`、`index.template.html` | 页面本身 |
| `data/house.js`、`assets/floorplan.jpg` | 户型数据与原图 |
| `tools/build.mjs` | 打包成单个离线网页 `dist/index.html` |
| `tools/browser-check.cjs`、`tools/shot.cjs` | 浏览器验收与截图，手动跑 |
| `tools/make-data.py` | 从原出片工程汇总数据，只在作者机器上用 |
| [SPEC.md](SPEC.md) | 规格与验收条目 |

## 本地构建

```bash
npm ci
node tools/build.mjs          # 生成 dist/index.html，双击即可打开
node --test tests/*.test.cjs
```

发布时 CI 跑同样三步，把 `dist/index.html` 放到站点的 `floorplan-walk/`。`dist/` 和 `node_modules/` 不进仓库。

## 验证

2026-10-03，Mac mini（Apple M4），Google Chrome 155.0.8059.27 无头模式经 Playwright 驱动，WebGL 走真实 GPU（`ANGLE Metal Renderer: Apple M4`）。没有在真手机、Safari、Firefox 或低端设备上测过。

**自动测试**：`node --test tests/*.test.cjs` 13 条全过。测试写完后各把门碰撞、墙碰撞、贴墙吸附、家具挡路弄坏过一次，对应那条都报了红。

- 构图：鸟瞰时房子宽占画面 47.6%，平面 54.3%，四边都有留白；手机竖屏宽占 89.7%。
- 平面图（默认档，真实鼠标键盘）：打开是 2D，41 件家具、家具库 63 张卡片（60 种加这里补的 3 种），房子占中间一栏宽度的 81%。从库里拖一张床到家庭室，落点离鼠标松开处 4 毫米；拖动 1.5 米、R 转 90°、方向键微调都生效；拖右下角方块把 1800×2000 改成 3110×1060，拖圆点转到 180°；复制 43 件、删除 42 件、撤销 43 件、再撤销 42 件；C 换木色后地板图案和家具颜色都变；刷新后 42 件还在。
- 切到 3D：4.8 秒长完，平面图上 42 件、三维里建出 43 件（多的一件是壁炉）。
- 3D 实走：点「走进去」后 13.3 秒走到客餐厅，离终点 0.11 米，穿过入户门时门已全开；S 键后退、拖动转头、Esc 退出、数字键切机位、拖滑块切真实日照（时钟读 15:00）、X 剖切、C 换色、O 环绕（1.5 秒内镜头转了 0.1 弧度）、G 重播（播完回到鸟瞰）、T 回到平面图都按真实输入验过。
- 读数：同一块客餐厅地板，橡木亮度 161、胡桃木 92；夜景下屋内亮度 75、屋外 21。
- 手机竖屏：平面图完整显示，家具库是底部一条，点一张卡片加了一件；切到 3D 后页面不横向溢出，「走进去」在屏内，摇杆出现并能推着走 1.14 米。
- 11 个固定机位、默认档和手机档都没有报错，运行时没有任何外部请求。
- 载入后屏幕尺寸变化（Alice 在手机上发现「载入完变得特别大」后补的，见下）：折叠屏展开→合上、合上→展开、竖屏→横屏三种，平面图都重新适应（占图纸区 81% / 81% / 73%，整栋在内）；3D 鸟瞰重新取景（占屏 88%×33% / 83%×54% / 39%×61%，四边有留白）；自己放大过的平面图换屏后中心没动（偏移 0.0 mm）。修之前同样三种情况：平面图撑到图纸区的 178%、37%、102%，3D 撑到屏宽的 172%、42%、19%。
- 线上复验：这一版发布后补

**读图**：2D 平面（橡木、胡桃木、拖动中、编辑后、手机竖屏）、鸟瞰、平面机位、四个房间、剖切、走进去、夜景、真实日照、胡桃木、生长两帧、门正在打开的一帧、手机 3D 两张，逐张看过。看图改掉的问题：白墙发灰（补光强度按物理单位给低了，色调映射也压白）、墙顶和窗边有细漏光缝、竖屏下房子太小和标注互相压、工具栏把提示文字盖住。

**没在真机上复现的一件事**：Alice 用手机打开后说「一开始载入还正常，等全部载入就变得特别大」。无头浏览器按七种手机与折叠屏尺寸打开都没有复现；能稳定复现的同类问题是「载入后屏幕尺寸一变就不再适应」，已修并写进验收第 12 条。她手机上的现象是不是这一条造成的，要等她再打开一次才知道。

**没验的**：真机触屏手感（尤其手机上从底部家具库往上拖，自动验收里手机只测了点卡片添加）；双指缩放没测；环绕和重播只验了会动、会结束，没有逐帧看；夜景只有每间一盏顶灯，客餐厅偏暗是现状。
