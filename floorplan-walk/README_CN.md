# 走进户型图

一张网上找来的户型图，读出墙、门窗和房间，摆满家具，做成一套可以转着看、也可以从入户门走进去的房子。

**[在线看](https://aliceljy.github.io/playground/floorplan-walk/)**

和旁边那张 [户型图 · 三维小样](../floorplan/) 是同一套房子、同一份数据。那一页是成片里的手机页，家具是简化体块，重点在 CAD 图和光追效果图；这一页把家具做全了，能走进去。

## 怎么玩

| 操作 | 电脑 | 手机 |
|---|---|---|
| 转着看、缩放 | 拖动、滚轮 | 单指转、双指缩放 |
| 六个机位：鸟瞰、平面、客餐厅、厨房、家庭室、门厅 | 数字键 1–6 | 点按钮 |
| 走进去 | F，然后 W A S D 走、拖动转头、Shift 快走、Esc 退出 | 点「走进去」，左下摇杆走、拖动转头 |
| 带我走（自动走一段） | T | 点按钮 |
| 墙剖到 1.2 米 | X | 点按钮 |
| 真实日照、夜景 | R、N，或直接拖时间滑块 | 同左 |
| 换木色（橡木 / 胡桃木） | C | 点按钮 |
| 房间标注、环绕、重播开场 | L、O、G | 点按钮 |

第一次打开会先播一遍房子从图纸上长出来。点「走进去」后会自己从门外走到客餐厅，走近的门会自己开；中途按任意方向键或拖动就由你接管。

## 怎么做的

- **房子**：墙、门窗、房间、家具位置都来自同一份数据（`data/house.js`），是之前做户型图成片时从那张图里读出来的。墙体按多边形挤出，所以厨房那两面 45° 的斜墙和斜窗都在。门扇挂在合页上，走近 1.9 米开、离开 2.6 米关。
- **家具**：45 种参数化家具的做法移植自 [wy51ai/floorplan-3d](https://github.com/wy51ai/floorplan-3d)（MIT），每件按宽、深、颜色生成，所以能按图上的位置严丝合缝摆进去，换木色时整屋一起换。椭圆餐桌、圆茶几、吊灯、壁炉和楼梯那边没有，是这里补的（`src/extras.js`）。厨房台面会自己判断靠哪面墙；背后有窗的那一段不装吊柜。
- **日照**：滑块读的是按公式算出来的太阳位置，假设地点北京、冬至这一天。原图只画了指北针，没写地点，所以这是个假设。默认的「示意光」不是真实太阳，只是为了看清模型。
- **行走**：墙的轮廓、窗、落地玻璃门、楼梯和大件家具都会挡路；椅子和绿植不挡，免得卡在餐桌边。

## 文件

| 路径 | 是什么 |
|---|---|
| `src/core.js` | 坐标、家具布置、碰撞、开门、路线、太阳位置，不依赖三维库，可以单独测 |
| `src/kit.js` | 移植来的家具套件 |
| `src/extras.js`、`src/house.js`、`src/textures.js` | 补的几件家具、房屋结构、地板贴图 |
| `src/main.js`、`index.template.html` | 页面本身 |
| `data/house.js`、`assets/floorplan.jpg` | 户型数据与原图 |
| `tools/build.mjs` | 打包成单个离线网页 `dist/index.html` |
| `tools/browser-check.cjs`、`tools/shot.cjs` | 浏览器验收与截图，手动跑 |
| `tools/make-data.py` | 从原出片工程汇总数据，只在作者机器上用 |
| [SPEC.md](SPEC.md) | 规格与验收条目 |

## 本地构建

```bash
npm ci
node tools/build.mjs          # 生成 dist/index.html，双击即可打开
node --test tests/*.test.cjs
```

发布时 CI 跑同样三步，把 `dist/index.html` 放到站点的 `floorplan-walk/`。`dist/` 和 `node_modules/` 不进仓库。

## 验证

2026-10-03，Mac mini（Apple M4），Google Chrome 155.0.8059.27 无头模式经 Playwright 驱动，WebGL 走真实 GPU（`ANGLE Metal Renderer: Apple M4`）。没有在真手机、Safari、Firefox 或低端设备上测过。

**自动测试**：`node --test tests/*.test.cjs` 9 条全过。测试写完后各把门碰撞、墙碰撞弄坏过一次，对应那条都报了红。

**浏览器**：`tools/browser-check.cjs` 打开打包后的 `dist/index.html`，22 项检查全过。

绘制调用含阴影那一遍。

- 构图：鸟瞰时房子宽占画面 47.6%，平面 54.3%，四边都有留白；手机竖屏宽占 89.7%。
- 默认档实走：开场 4.8 秒播完；点「走进去」后 13.3 秒走到客餐厅，离终点 0.11 米，穿过入户门时门已全开；S 键后退、拖动转头、Esc 退出、数字键切机位、拖滑块切真实日照（时钟读 15:00）、X 剖切、C 换色、O 环绕（1.5 秒内镜头转了 0.1 弧度）、G 重播（播完回到鸟瞰）都按真实输入验过。
- 读数：同一块客餐厅地板，橡木亮度 161、胡桃木 92；夜景下屋内亮度 75、屋外 21。
- 手机竖屏：页面不横向溢出，「走进去」在第一屏，摇杆出现并能推着走 1.14 米。
- 11 个固定机位、默认档和手机档都没有报错，运行时没有任何外部请求。

**读图**：鸟瞰、平面、四个房间、剖切、走进去、夜景、真实日照、胡桃木、开场两帧、门正在打开的一帧、手机两张，逐张看过。看图改掉的问题：白墙发灰（补光强度按物理单位给低了，色调映射也压白）、墙顶和窗边有细漏光缝、竖屏下房子太小和标注互相压、工具栏把提示文字盖住。

**没验的**：真机触屏手感；环绕和重播只验了会动、会结束，没有逐帧看；夜景只有每间一盏顶灯，客餐厅偏暗是现状。
