# 史前岛屿

一座火山小岛，连同周围的海水和海底一起被切成一块展台。水面上：山顶一个火山口，坑里一小池熔岩在冒烟，山坡上是针叶林、苏铁状的树和蕨丛，岸边一圈沙滩；几只长颈植食恐龙沿东岸来回走，翼龙绕着山顶盘旋。水面下切开看：一圈浅浅的礁盘，长着枝状和团块珊瑚、海扇、海百合，菊石在礁盘外缘漂；再往外陡坎落到深海平原，一侧切出一条海沟，一只蛇颈龙类沿着沟巡游。两群鱼在礁盘边上来回。

六个机位逐个看，或一键连播 48 秒：岛屿全景、水下剖面、礁盘、海沟、海滩、火山口。拖动画面可以自由环绕。手机竖屏可看。

所有造型和颜色都由代码生成，没有外部模型、贴图或生成的图片。造型是示意，不是真实复原，画在一起的这些动物也不一定生活在同一时期。

## 运行和检查

```sh
npm ci
node tools/build.mjs            # 打成单文件 dist/index.html
node --test tests/*.test.cjs    # Node 测试：地形、动物、构图、镜头连续、材质、预算、页面措辞
node tools/browser-check.cjs    # 真实 Chrome：12 张固定机位截图、布局、像素读数、鼠标拖动、页面报错
node tools/preview.cjs          # 没有 WebGL 的机器上看构图的 CPU 预览（不是渲染截图）
```
