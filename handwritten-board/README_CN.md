# 手写板书

两页手写板书一笔一笔写出来，讲的就是这页板书自己是怎么做出来的：手写字体逐字揭示，一只手跟着笔尖走，红笔把重点圈出来。点一下画面暂停或继续；可以倍速、重放、在「翻页」和「长卷」之间切换、换字体。看一遍约 36 秒。

**[在线观看](https://aliceljy.github.io/playground/handwritten-board/)**

手机竖屏、横屏和电脑都能看。手机竖着拿时板书会换成更方正的形状，字才够大；转屏或改变窗口大小会自动重新选，进度不丢。没有声音。

## 操作

- 点画面、按空格（电脑）或点第一个按钮：暂停和继续。播完以后同一个操作会重新播一遍。
- 画面下面的控件条里有重放、倍速（1× 到 2×）、翻页模式开关和字体菜单。翻页模式是一页一页翻；关掉就是一张长卷往下写，镜头跟着笔走。
- 字体菜单里有随页面带的龙藏行书，另有四款苹果系统自带的手写字体；设备上没有的字体会灰掉。

## 怎么做的

- 纯静态文件，没有构建步骤，也不发任何网络请求。板书是网页文字，每个字一个 `<span>`，用 `clip-path` 从左到右揭示；红圈、波浪线、箭头是 SVG 路径，用描边偏移一笔画出来；手是内嵌的 SVG，和揭示放在同一条 GSAP 时间线上，所以笔和字天然对齐。
- `src/pages.js` 放板书的字，`src/core.js` 放计时数值、两种板书形状和红笔路径的几何（不碰页面，Node 能直接测），`src/board.js` 是页面逻辑。
- 字体是龙藏行书裁出来的子集：只留板书用到的字，加上英文数字和常用中文标点，约 40 KB（原字体 5 MB）。板书的字改了就重新裁：`node tools/subset-font.cjs <LongCang-Regular.ttf>`。
- 一页规格在 [SPEC.md](SPEC.md)：配色、构图数值、性能预算和十条验收。
- 固定机位：`?view=page1`、`?view=page2` 定格在每一页写完的样子，`?view=mid` 定格在第一页第三行写到一半；后面加 `&mode=flow` 可以用长卷模式看。不带参数就是从头播放。调试钩子是 `window.__handBoard`。
- 第三方文件和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)：GSAP 3.13.0（用的是它的 Standard "No Charge" 许可，不是 MIT）和龙藏行书字体（SIL 开放字体许可 1.1）。

## 本地运行

```bash
cd handwritten-board && python3 -m http.server 8973
```

打开 `http://127.0.0.1:8973/`。测试：`node --test tests/*.test.cjs`。发布时原样拷贝 `index.html`、`src/` 和 `vendor/`。

## 谁会点开、AI 素材

- 谁会点开：想看清「手写板书」这类讲解动画一步步是怎么搭出来的人，也包括只想安安静静看两页笔记被写出来的人。
- AI 素材清单：没有 AI 生成的图片、模型或声音，页面完全没有音频。手和笔是代码里画的矢量图形，红色记号是程序生成的路径。板书上的文字和代码由人与 AI 协作完成。龙藏行书字体（SIL OFL）和 GSAP 库是第三方的，不是 AI 生成。
