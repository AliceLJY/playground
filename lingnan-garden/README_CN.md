# 岭南园林一角

照一张图搭出来的可走场景。[在线打开](https://aliceljy.github.io/playground/lingnan-garden/)

先查了岭南园林和别处园林不一样的地方（[facts.md](facts.md)，逐条写了来源），再照查到的写提示词让 AI 画了一张图，最后把图里看得见的东西一样样列出来，用 Three.js 纯代码搭成三维场景，可以第一人称走进去。那张图只用来对照，没有贴进场景；页面里点「对照原图」能并排看。

这不是哪座真实的园子，是取余荫山房、清晖园、可园几处典型做法拼成的示意一角；图是 AI 画的。

第一版照的是另一张图，那张图的提示词里写了白墙、曲岸荷塘、石拱桥、曲廊和浅色假山，是江南园林的路数，所以整套重做了。

## 怎么玩

- 明信片视角：和起始图同一个机位。
- 走进去：电脑 WASD 走动、拖动转头、Shift 快走；手机左下摇杆走动，其余地方拖动转头。
- 带我逛一圈：自动从庭院出北墙的门，走窄巷绕到屋后，上廊子、进敞厅、过廊桥、进八角亭再回来，随时可以接手。
- 俯瞰：从空中看整座院子。

## 做出来的东西

青砖墙围起来的一个小院。北面是临长方荷池的敞厅：灰瓦两坡、博古脊和山墙上的灰塑、八樘满洲窗、窗上的蚝壳横披，檐廊西头爬着炮仗花。檐廊东头接出一段廊子，折向南是一座廊桥，石拱下面的水道通到八角池，池中立着八角亭。东墙下是贴墙的英石壁山，有一线跌水。院子里有砖砌的花基和三盆榔榆盆景、石桌石鼓、大陶缸、两块黄蜡石、一棵挂果的荔枝；墙外探进来一树木棉，远处是一座青砖高楼。

敞厅能走进去，屋里抬头是露明的梁架和瓦底。水面有倒影，荷叶、芭蕉会动，锦鲤在游，木棉在落花。声音是浏览器现场合成的。

图里被挡住或在画框外的部分（屋里、窄巷、屋后、进八角亭的石板桥、南面园门）是按查过的做法补的。逐项的还原情况和「岭南特征检查表」在 [SPEC.md](SPEC.md)：哪些特征场景里有、哪些有意没放、哪些只是示意，都写在那里。

## 本地运行

```
npm ci
node tools/build.mjs          # 生成 dist/index.html，自包含单文件
node tools/serve.cjs . 8973   # 打开 http://127.0.0.1:8973/dist/index.html
node --test tests/*.test.cjs
```

截图与真实输入检查需要全局装的 Playwright：

```
NODE_PATH="$(npm root -g)" node tools/shots.cjs http://127.0.0.1:8973/dist/index.html shots
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs http://127.0.0.1:8973/dist/index.html shots/check
```
