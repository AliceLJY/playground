# 小橘逛花城

骑着小橘猫的自行车逛一座卡通广州街区。骑楼、茶楼、戏台、花园与江边共有 14 个发光入口，分别通向本仓已有的小游戏、小玩意和三维展页。标题页的骑楼、陈家祠、镇海楼会跟着节拍跳舞。

## 怎么玩

- 方向键或 WASD 骑车，Shift / B 冲刺，E 停靠，M 打开地图；手机有对应的触控按钮。
- 自动前行默认开启，自动导航默认关闭。以正常速度骑过光圈只会看到轻提示；在光圈里停稳 0.6 秒，或按 E / 点「停下来看看」，会打开入口卡片。
- 点「进去玩 / 进去看看」前会保存停车位置、朝向、手账与驾驶设置，再打开 `../<作品 id>/`。六小时内回来，标题页可选择「回到刚才的地方」或「从头逛」。存储不可用时也能正常从头开始。
- 地图按骑楼段、支路与戏台、花园、江边分组，选中入口后可自动导航，到站停车即打开卡片。
- 顶栏「手账」显示作品街进度 N / 14，进过一个入口就加 1；三个小憩点的章在手账内单独保留，不计入这个分母。三花挑战、明信片、自动前行与扶正功能都保留。

## 本地运行与检查

Three.js r160 和全部素材均在本地，不需要安装依赖、密钥或 CDN。在仓库根目录启动服务，让入口的相对链接能解析到真实目录：

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765/xiaoju-city/`。固定验收机位为 `?view=title`、`?view=hotspot`、`?view=map`，分别展示标题、真实导航到「骑楼雨夜」后弹出的卡片、选中「十三行江岸」的路线图。

```sh
cd xiaoju-city
node --check src/core.js
node --check src/game.js
node --test tests/*.test.cjs
python3 build.py
```

`build.py` 生成单文件 `小橘逛花城.html`，把 CSS、JavaScript、three.js 以及 `assets/*.webp` 全部内联；三张 WebP 转为 data URI，因此发布时不需要额外拷贝 assets 目录。`shots/` 是本地验收截图，不进入发布白名单。

## 谁会点开、AI 素材

- 谁会点开：在首页不知道先玩哪个的人，骑着车逛一圈，看到哪个门口顺眼就进哪个。
- AI 素材：三栋楼立面是网页版 GPT 生成的图（同「小黑煤球盖广州」）；街区与角色是原创程序化模型；代码由人与 AI 协作完成。
