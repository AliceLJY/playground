# 辋川卧游 · 鹿柴

[English](README.md) · [打开](https://aliceljy.github.io/playground/wangchuan/)

王维《鹿柴》做成一段可以走进去的手卷。打开就是一幅盛唐青绿画风的深林，一束返照落在苔上；停着不动，画会轻轻呼吸，光慢慢移，远处有人喊话，卷子自己向左展开，卷尾的素纸上，诗一行一行显出来。

留 2 秒有 2 秒的收获，不用看完。

## 规格

- 体验一句话：像古人「卧游」那样看一段山水，先见画，后见诗。主美学是感官与沉浸；只走一遍的弧型，不是反复玩的循环型。
- 场地：陌生访客用手机竖屏打开，多半静音，停留从两秒到一分多钟不等。所以第一眼必须成立，声音是加分不是前提。
- 年代一致：王维是盛唐人，画取盛唐青绿，字取盛唐小楷。画面上不题诗，诗在卷尾素纸上。
- 页面不放解说。屏幕上的字只有卷尾一行署名说明、一个声音提示和一个声音开关。
- 配色不另定：画心的颜色就是那张画；隔水 sRGB `#3C3428` 上下，卷尾素纸 sRGB `#E2CB9F` 上下，题诗墨色 `#261E16`。
- 性能预算：手机浏览器 60 帧；一个全屏着色器、一次绘制，两张贴图（画 3966×1586，深度 992×397）；设备像素比封顶 2。

## 停留几秒得到什么

| 停留 | 看到、听到的 |
|---|---|
| 2 秒 | 一幅成立的画：深林，返照落在苔上 |
| 10 秒左右 | 画在轻轻呼吸，光有明灭，远处云气在流；碰过屏幕的话，听见风声和远处一喊一应 |
| 7 秒以后 | 卷子自己慢慢向左展开，手一拖就听你的，松手 5 秒后再接着走 |
| 一分钟上下 | 卷到隔水和素纸，诗从右往左一行行显出来 |
| 一分半以后 | 返照移走，林子略略暗下来 |

## 怎么做的

- 画：AI 生图（Codex），带两幅传世的早期青绿当参考（传唐人《明皇幸蜀图》、传展子虔《游春图》，取自维基共享资源），只学设色质感和用笔，不抄构图。画的是新作，不是古画。
- 字：AI 生图，带盛唐小楷墨迹《灵飞经》（传钟绍京，大都会博物馆藏，取自维基共享资源）当参考；二十四个字逐字核对过，再抠成只有墨迹的透明图。
- 动：画不拆层、不补画。用 Depth-Anything-V2 给画算一张深度图，着色器按深度让近处比远处多动一点点；云气、返照的明灭与移动也在着色器里叠上去。
- 声：风声是 Web Audio 实时合成的；远处的喊话是系统语音合成后加混响和滤波。
- 没有构建步骤，没有运行时依赖。

## 验收

`node --test tests/*.test.cjs` 跑七条：开场第一眼看得见返照（六种屏幕比例）、开场不露出画心之外、卷尾题诗居中且整首在屏内、最窄的手机装得下整首诗、题诗不压画心、题诗图尺寸与布局一致、页面没有多余的字。第一条拿改坏的版本（开场停在画的最右端）试过，会变红。

另在 390×844 视口实跑：开场 2 秒截图、等它自己展卷、拖到卷尾等诗显全，控制台零报错，60 帧。

这些只证明它按规格跑。好不好看、有没有唤起那首诗，要人看。
