# 最靓的仔

一只放大 85 倍的广州小强（美洲大蠊），在红阶砖上原地奔跑，能拆开看。

**[打开看](https://aliceljy.github.io/playground/gz-roach/)**

拖速度条，从慢走拖到每秒 1.5 米：六条腿先是两组三角形轮流着地；过了 1 米每秒前足抬起来，四条腿跑；再快中足也抬起，只用两条后腿跑。这是真的，美洲大蠊最快时就是这样跑的（Full & Tu, 1991）。右边的步态图、每只脚的垂直力、左边的读数，都跟着同一个速度算出来。

最后按「最靓的仔」。

## 能做什么

- **速度**：0 到 1.5 米每秒。读数里有「按人的身高换算」，最快时约 260 公里每小时。
- **单看**：头与触角、前胸背板、前足、中足、后足、翅、腹与尾须，其余部分变透明，带一行说明。
- **X 光、拆开、张翅**。
- **最靓的仔**：立起来，腹尾点地，中足举起来秀肌肉，触角往后甩成两条马尾，墨镜从天而降。
- **导览**：不操作时，一个光标自己去点这些按钮，走完一遍 36 秒。点任何地方就交给你，25 秒不动再交回去。

## 操作

| 动作 | 电脑 | 手机 |
|---|---|---|
| 转着看 | 按住拖动 | 单指拖动 |
| 远近 | 滚轮 | 双指捏合 |
| 速度 | 拖速度条，或方向键上下 | 拖速度条 |
| 换机位 | 底栏「机位」 | 底栏横滑 |
| 快捷键 | X 光 X、拆开 E、张翅 W、最靓的仔 S、藏面板 H | 无 |

## 怎么做的

先写模型，再画虫。`src/model.js` 只有纯函数：给一个速度，算出六条腿每个关节在哪、每只脚踩地有多重、身体抬多高。三维的虫、面板、测试都读它，没有一帧是手调的动画。整只虫是代码搭的（椭球、圆柱、顶点着色），没有模型文件和图片。

做法借自 Elvar 的 teardown（一个把机器做成可拆模拟器的 Claude Code 技能，MIT）：一个输入驱动整台机器、按导览节拍截图逐张挑错、导览自己走并在有人碰时交出控制。这一页的代码是另写的，没有搬它的代码。它的九步话术独立改写进了作者的提示词素材库：`tinkering-lab/prompts/interactive-3d-exhibit/variant-teardown-one-input-simulator.md`。

## 本地运行与检查

```bash
npm ci
node tools/build.mjs            # 打成一个文件：dist/index.html
node --test tests/*.test.cjs    # 骨长、脚不打滑、体重守恒、不插地、步态、导览
NODE_PATH="$(npm root -g)" node tools/browser-check.cjs /tmp/roach-check   # 浏览器验收，需要本机已有 Playwright 和 Chrome
```

## 录一段演示视频

可选，不进 CI。`tools/record.cjs` 逐帧调用页面的 `render(t)` 再截图，录出来的帧率和机器快慢无关；录的就是那 36 秒导览，光标会把手机上横滑的按钮行先滑到目标处再按。同时写一份事件表（每只脚着地、光标按下、墨镜落下的时刻），`tools/score.py` 按它合成配乐：底下四个和弦循环，每只脚着地一声很轻的「嗒」，按钮一声「咔」，墨镜落下一记低音加一串铃。全是算出来的，没有采样和现成音乐。

```bash
node tools/build.mjs
NODE_PATH="$(npm root -g)" node tools/record.cjs ./横屏.mp4                           # 1920×1080
NODE_PATH="$(npm root -g)" node tools/record.cjs ./竖屏.mp4 --size 540x960 --dpr 2    # 1080×1920，用手机排版
uv run --with numpy python -I tools/score.py ./横屏.events.json ./配乐.wav           # 需要 numpy
ffmpeg -i 横屏.mp4 -i 配乐.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart 成片.mp4
```

录片时面板不带毛玻璃（无头浏览器截图偶尔会丢掉毛玻璃面板里的内容）。2026-11-01 实测：成片响度 -14.6 LUFS，真峰值 -1.2 dBFS。

## 已知的边界

- 速度、步频、换步态的区间是实测；换档的两个具体点、骨长、关节姿态是估值。
- 「最靓的仔」姿态和墨镜是虚构的。
- 没在真手机上试过；帧率只在一台 Mac mini 上量过。页面没有声音；录片的配乐还没人听过。
