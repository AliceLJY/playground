# 小黑煤球盖广州

[English version](README.md) · [在线玩](https://aliceljy.github.io/playground/coal-build/)

一群小黑煤球顶着青砖，一块块把广州的老房子从地基砌到屋脊。放置建造小游戏，三栋：骑楼 → 陈家祠 → 镇海楼。

- 每栋楼一开始只是一道淡淡的轮廓，砖从下往上填进去；顶上写着「还剩 N 块」，快完时变「最后 N 块！」。
- 轮廓上有一条红色目标线，按楼的真实分层切段（骑楼是柱廊、二楼三楼、四楼、女儿墙与山花）。砌满一段，那一段就从砖块拼图变成整幅画。
- 点楼帮煤球砌一块；攒下的工钱在底部四张卡里花：招煤球、扩工棚、练力气、涨工钱。后两栋砖更重（陈家祠 ×4、镇海楼 ×12），更要靠力气。
- 左边圆钮「齐心一砌」冷却 90 秒，一下砌一大片；地上偶尔推过糖水担，点到了煤球跑得快。
- 盖完一栋亮出整幅画和一句小知识，收进图鉴，开下一栋。进度存在本机，关掉回来接着盖。

不看说明也知道点什么：开局楼上写「点这里」，点几下之后，提示和箭头跟着你买得起的那张卡走，大招好了、糖水担来了也会指过去。

## 本地跑

```bash
cd coal-build && python3 -m http.server 8971
```

打开 `http://127.0.0.1:8971/`。固定机位：`?view=hero`（第 70 秒）、`?view=stage`（柱廊刚砌满）、`?view=done`（骑楼盖完）、`?view=album`（图鉴），`?seed=n` 换种子。

## 怎么做的

- 思路借自一款微信小游戏（蚂蚁一块块搬空一座山）：进度是看得见的物理变化、目标写在画面里、四格升级、随机事件加冷却大招。题材、名字、美术都是这里自己的，也没有广告点，原作里看广告翻倍的地方改成了游戏内的糖水担。
- 三栋楼的外形先查资料再画：骑楼的柱廊和女儿墙山花，陈家祠头门的门神、一对石鼓、两侧大砖雕和满脊陶塑，镇海楼下两层红石、上三层青砖、五重绿琉璃檐。小知识出自中英文维基百科和广州市政府网。
- 三张正立面画由网页版 ChatGPT 生成，离线脚本 `tools/bake.py` 抠掉纯色底，再按砖格取平均色，所以砖拼出来的就是那张画的马赛克，轮廓和成画严格一致。
- 煤球干活是一条接力：地上的煤球顶着砖走到楼下，蹲一下把砖抛上去；竹棚上的泥瓦匠跳到落点踩实，砖闪一下白。力气越大，头上顶的砖越多。
- 小黑煤球照 IP 设定用代码画：纯黑圆身、白描边、白点眼、短横嘴、天线粉球、两条细腿、没有手臂，砖顶在头上。

## 验收

- `src/core.js` 是规则（经济、升级、事件、提示、布局），不碰画面，Node 里能跑。`tests/core.test.cjs` 按 `SPEC.md` 第 8 节逐条检查：同种子同结果、普通玩家第一栋中位 2.5–7 分钟、不点楼也能 15 分钟内盖完、三栋逐栋变长、四张卡都有人买、目标和提示一直在画面上、样本里真用过大招和糖水担、六种手机尺寸下按钮不重叠不出屏。在本目录运行 `node --test tests/*.test.cjs`。
- `tools/work-check.cjs` 检查看不看得出煤球在干活：砖要从煤球头顶抛上去、泥瓦匠要当场踩实、头上顶的砖随力气变多，另存 12 帧连拍。
- `tools/browser-check.cjs` 在真实浏览器里跑三种屏幕、五个机位，用触屏点击走一遍开局，自动玩家盖完骑楼并截图，刷新后检查存档。用法写在文件开头。
- 数值和节奏只经过自动玩家校准，好不好玩要真人试玩。第一版没有声音，真手机还没试过。

## 谁会点开、AI 素材

- 谁会点开：想在手机上挂着玩几分钟的人；在广州生活过、认得骑楼和陈家祠的人。
- AI 素材清单：三张建筑画是网页版 ChatGPT 生成的；小黑煤球、砖块、糖水担、界面都是代码画的；没有声音；代码由人与 AI 协作完成。
