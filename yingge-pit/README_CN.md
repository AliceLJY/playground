# 打回乐池

英歌小戏台上，三个英歌纸偶——左普宁、中甲子、右潮阳凤岗——守着戏台。白衣木偶（舞剧《英歌》里的邪祟）从台板下的乐池往上爬，甩白袖子、抽铁枝。哪一道的袖子鼓起来就盯住哪一道，铁枝一亮就点它，那个纸偶出槌，把木偶打得上弹、后翻、落回乐池一截。漏了，纸偶被拍倒，三秒后自己爬起来，木偶往上爬一格；爬到台口就占了戏台。连着打中攒满锣鼓槽，点台口大锣，三人齐槌「大英歌」。三波过后把它整个打回乐池、台板盖上，三个纸偶画脸，接棒。

**[在线游玩](https://aliceljy.github.io/playground/yingge-pit/)**

一局一分钟左右。竖屏为主，横屏和电脑也能玩。可以两个人同一台手机一起打：阿爸管左半边，心远管右半边，中间那道谁先点算谁的。

## 操作

- 手机：点下面的按键，或者直接点戏台上那一道。横屏时按键在两边，左手管左、中，右手管中、右。锣鼓槽满了点台口那面大锣。
- 电脑（单人）：← ↓ → 或 A S D 对应左中右，↑、W 或空格敲大锣。
- 电脑（双人）：阿爸用 A（左）、S（中）、W（锣）；心远用 ↓（中）、→（右）、↑（锣）。
- 开始页选单人或双人；开始页和结算页右上角可以关声音。

## 三波

- 第一波 · 探头：一次抽一道。
- 第二波 · 虚晃：它先在另一道鼓袖子，再换道抽。虚晃的那只袖子不会亮，等铁枝亮了再点就不会上当。
- 第三波 · 两道齐抽：两道一起亮，两只手（或两个人）一起点。
- 每波之间牛肉丸红球弹过台面，点中有分，打回去的球偶尔砸在木偶头上，下一波它少爬一格。

## 怎么做的

- 一页规格在 [SPEC.md](SPEC.md)：配色、构图、预兆提前量与判定窗口、升降格数、三波节奏、锣鼓槽长度、性能预算和十条验收。
- 规则在 `src/core.js`，不碰画面，可以在 node 里跑；测试用真实模拟的对局量预兆和判定窗口、四档打法（精准、手抖、不操作、乱点）的胜率和时长、双人分别计分、大锣只在槽满时可点、亮起的铁枝露出多少。
- 画面是二维画布。戏台和三个纸偶取自短片《英歌小戏台》的素材：戏台用分层图重新拼过、加深了乐池、补了暖光，纸偶照短片的骨架坐标转手臂出槌；白衣木偶、铁枝、光柱、火花和结尾的脸谱是代码画的。锣、梆子、甲子的「咚咚咚，隆咚咚」鼓点都用 WebAudio 现场合成。
- 固定机位：`?view=hero`、`?view=feint`、`?view=stress`、`?view=duo`、`?view=ball`、`?view=win`、`?view=result`、`?view=lose`；调试钩子是 `window.__yingge`。

## 本地运行

```bash
cd yingge-pit && python3 -m http.server 8951
```

打开 `http://127.0.0.1:8951/`。测试：`node --test tests/*.test.cjs`。没有构建步骤，发布时原样拷贝 `index.html`、`src/` 和 `assets/`。`tools/` 里是手动跑的浏览器验收、录屏和素材烘焙脚本。

## 素材与来源

- 粉丝向小游戏，画面全部自制，没有用舞剧的剧照、片段和录音。结算卡里那句「舞剧《英歌》的演员跟普宁、甲子、潮阳凤岗三支英歌队学过」出自羊城晚报 2024 年 11 月 11 日的报道。
- `assets/` 由 `tools/make-art.cjs` 从短片工程的素材烘焙而来（只读源文件，缩到游戏用的尺寸）。

## 谁会点开、AI 素材

- 谁会点开：看过舞剧《英歌》、想在手机上和家里人一起敲两下的人；潮汕人看到普宁、甲子、凤岗三支队会会心一笑。
- AI 素材清单：三个英歌纸偶的部件图由 AI 画图工具生成；戏台分层、大锣和红球是短片工程里用代码画的；白衣木偶、特效和声音是代码；代码由人与 AI 协作完成。
