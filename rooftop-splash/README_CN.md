# 天台水枪大战

暖黄色城市天台上的第一人称水枪对战。蓝橙两队绕着水箱、花坛和补给小屋走位，三把水枪加上水球，打湿对手后得分。

**[在线游玩](https://aliceljy.github.io/playground/rooftop-splash/)**

这是单人游玩的电脑团队对战，其他队员均由电脑控制。支持三对三、四对四、六对六，三档难度及十五、三十、五十分目标。每局最多三分钟，先到目标分数获胜；时间结束时比分高的一队获胜，同分则平局。打湿后等待三秒自动归队，并获得短暂出生保护，开火会提前解除。

## 操作

- 键盘移动，鼠标瞄准和开火；右键瞄准，高压水炮可以放大视野。
- 数字键一、二、三选择水枪，Q 或滚轮轮换；R 补水，G 扔水球。
- 空格跳跃，Shift 快跑，C 蹲下，Tab 看战报，Esc 暂停。
- 触屏用左侧摇杆移动、右侧拖动转头，按钮负责开火、补水和跳跃，建议横屏。
- 浏览器不允许锁定鼠标时，可以按住画面拖动瞄准。切走页面时比赛自动暂停。
