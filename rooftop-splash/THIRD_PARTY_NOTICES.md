# Third-party notices

`vendor/three.min.js` is the existing Three.js build reused from this repository's Xiaoju Racing project. Its MIT license and copyright notice are preserved in `vendor/THREE-LICENSE.txt` and the generated standalone HTML.

Scenery, character geometry, interface, game simulation and synthesized sound were created for this project. There are no external image, font, audio or model dependencies.

Gameplay reference: [Transport Ship](https://claude-opus-5-5-cf-transport-ship.pages.dev/), linked to [riba2534/claude-opus-5-5-demo](https://github.com/riba2534/claude-opus-5-5-demo). The reference was inspected as a running website. Its implementation and assets are not distributed here.
