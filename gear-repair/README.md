# Gear Repair

DeepSeek Harness (dsh) is an agent shell the author runs on a Mac mini. In one pass it wrote a Three.js gear page: two gear pairs, A (12 teeth) driving B (30), B and C (12) on one shaft, C driving D (30), a 6.25 : 1 reduction overall. The ratios and the starting phases were right. One sign in the tooth-shape formula was not: the involute ran the wrong way, so each tooth came out wider at the tip than at the root, and the meshing gears passed through each other in every frame.

The author did not fix it. The task sheet named the symptom (teeth get wider outwards), two ways to check (a 2D outline intersection test and a close-up screenshot of the mesh) and "the problem is in the tooth-shape code". Finding the cause and fixing it was left to dsh, which came back with a corrected page and its own evidence: over one tooth period, 60 of 60 frames overlapped before, 0 of 60 after.

This page puts the two versions side by side. One button switches between the original and the repaired version; red dots mark every place where two outlines cross or one gear's vertex sits inside the other.

**[View online](https://aliceljy.github.io/playground/gear-repair/)**

## Controls

- Top right: the original / repaired switch (the buttons are labelled in Chinese on the page). The badge in the middle shows the result of a 60-frame check over one tooth period for the version on screen: 60 of 60 frames overlap for the original, 0 of 60 for the repaired one.
- Bottom: the live count of overlap points for A–B and C–D, three camera buttons (whole train, A–B close-up, C–D close-up), pause, slow motion (0.2x), a switch for the red markers, and a short explanation sheet (also in Chinese).
- Drag to orbit, scroll or pinch to zoom, right-drag or two fingers to pan. Space pauses.

## What is different between the two versions

| | Original | Repaired |
|---|---|---|
| Tooth shape | involute direction reversed: tip 24.3 degrees wide, root 13.4 degrees (12-tooth gear, measured on the generated outline) | root 16.0 degrees, tip 5.1 degrees |
| Root and clearance | none | root pulled inward, 4% backlash |
| Overlap over one tooth period (60 frames) | 60 of 60, up to 12 crossing edge pairs and 121 vertices inside the other gear in one frame | 0 of 60 |
| Shafts | cylinders left lying along Y, not along the gear axis | turned to the gear axis |

The three tooth-shape changes are dsh's: the sign of the involute direction (one line plus the three lines that depend on it), an inward root transition, and 4% backlash. A sign-only fix is not enough: in the same 60-frame check it still leaves 9 frames with slight overlap, so the other two changes were not optional.

## What was changed for this page

The two `makeGearShape` functions are dsh's own, word for word (a test compares them with the original text). Everything else is for showing them:

1. Both versions live on one page and switch with a button; the tooth shape and the shaft orientation follow the version.
2. Three.js r160, OrbitControls and RoomEnvironment are read from `vendor/` instead of a CDN, so the page makes no outside requests.
3. The assembly is centred for both versions, rotated 90 degrees on portrait screens, and the camera is fitted to the area between the top and bottom bars. In dsh's original page the driving gear A fell out of the frame on a phone held upright.
4. dsh's overlap test (60 frames, 2D outline intersection) was rewritten as a shared script, run every frame for the red markers and used by the tests.
5. Fixed views, slow motion and a `window.__gearRepair` hook were added.

## Fixed views

| URL | State |
|---|---|
| `?version=original` or `?version=repaired` | which version, original by default |
| `?view=hero` / `?view=mesh` / `?view=mesh-cd` | whole train / A–B close-up / C–D close-up |
| `&t=<seconds>` | pause at that simulation time, so both versions can be compared at the same instant |
| `&hl=0`, `&slow=1` | no red markers, slow motion |

Without parameters it opens on the original, whole train, playing.

## Running locally

```bash
cd gear-repair && python3 -m http.server 8972 --bind 127.0.0.1
```

Open `http://127.0.0.1:8972/`. It has to go through http; double-clicking `index.html` will not load the ES modules. Tests: `node --test tests/*.test.cjs`. There is no build step. To publish, copy `index.html`, `src/` and `vendor/` as they are.

## Who it's for, AI assets

- Who it's for: People curious what a one-sign bug looks like when it is made visible, and what an AI agent does when it is only given a symptom and left to find the cause itself.
- AI assets: The gear page code was generated by dsh and repaired by dsh itself; the two tooth-shape functions are kept as written. The showcase page around them (switching, overlap markers, camera views, tests) was built through human and AI collaboration. There are no AI-generated images, models or sounds.
