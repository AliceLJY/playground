# 上下文蛇

贪吃蛇，蛇头是小黑煤球，蛇身就是上下文。吃文件、网页、日志会变长，越长拐弯越慢：按了方向，要先走几格才拐。撞到自己叫「上下文污染」，这局结束。

**[在线玩](https://aliceljy.github.io/playground/context-snake/)**

一局最多两分钟（一次「会话」），手机竖屏优先，横屏和电脑也能玩，静音也看得懂。

## 怎么玩

- 手机：在棋盘上滑动转弯，或者按下方的方向键（按下就生效，不等松手）。一次长滑可以连拐两下。
- 电脑：方向键或 WASD 转弯，Q 压缩，E 派子 agent，Esc 或 P 暂停。
- 棋盘四边相通，从一边出去会从对边进来；只有撞到自己会输。
- 对话本身也会长上下文：每 7 秒自己多一段。光躲不吃也会越来越长。
- 新吃的挨着头，最老的在尾巴。

两个技能：

- **压缩**：身子至少 5 段才能用。砍掉尾巴最老的一截，尾巴剩一段「摘」字摘要；分数不扣；冷却 10 秒。
- **派子 agent**：身子至少 7 段才能用。从尾巴甩出 4 段，变成一个青色天线的小煤球，自己去场上吃 9 秒，然后回来交一份 205–588 字的汇报：加分，但不加长度。它在外面越吃越大，旁边标着它的「token」（只是示意）。
- 同时在外的子 agent 已经 3 个，再派一个，4 个全撞上 **429** 一起消失，汇报全丢，派子 agent 锁 8 秒。

拐弯有多慢：15 段以内按了就拐；16–23 段慢 1 格，24–31 段慢 2 格，32 段以上慢 3 格。棋盘上粉色虚线圈标出「现在按方向会在哪一格拐」，已排队的拐弯画成粉色箭头，顶栏写着「转弯慢 N 格」。

结算页会按你这局发生的事，挑一件对应的真事讲一句，比如子 agent 在外面读了十几万 token、交回来只有几百字，或者一口气派了 8 个全撞 429。

## 怎么做的

- 一页规格在 [SPEC.md](SPEC.md)：规则数值、配色、构图、性能预算和十二条验收。
- 规则在 `src/core.js`，不碰画面，能在 node 里跑；页面、输入、声音在 `src/game.js`。二维画布，没有构建步骤，不用 three，不用图片：煤球、图标、特效全是代码画的，声音用 WebAudio 现场合成。
- 测试：`tests/core.test.cjs` 用真实对局量转弯延迟、压缩、汇报、429、刷新位置和四档自动驾驶的时长与存活率；`tests/input.test.cjs` 在页面脚本上发真实的键盘、按钮和滑动事件。
- 浏览器检查：`tools/browser-check.cjs`，五种视口。
- 固定机位：`?view=hero`、`?view=long`、`?view=burst`、`?view=end`；钩子 `window.__snake` 和 `window.__PLAYTEST__`。

## 本地运行

```bash
cd context-snake && python3 -m http.server 8977
```

打开 `http://127.0.0.1:8977/`。测试：`node --test tests/*.test.cjs`。发布时原样拷贝 `index.html` 和 `src/`。

## 验证

见 [VERIFICATION.md](VERIFICATION.md)。拐弯延迟的手感、各项数值好不好玩，还要真人试玩。

## 谁会点开、AI 素材

- 谁会点开：用过 AI 编程助手、对「上下文」「压缩」「子 agent」这些词半懂不懂的人，想用一局贪吃蛇的时间把它们玩明白；也有单纯想在手机上玩两分钟贪吃蛇的人。
- AI 素材清单：没有 AI 生成的图片、模型或声音；小黑煤球照作者自己的形象母版用代码重画；代码由人与 AI 协作完成。
